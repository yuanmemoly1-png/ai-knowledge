# 《AI 时代的产品经理》独立站 —— 写作规范与大纲（契约）

本文件是 `/pm/` 站内容的**唯一契约**。id / t / rel / qs 一律照抄，不得改动。

## 一、这个站是什么

把库里**已有的 PM 素材**（14 场 PM 访谈、2 个专题、1 份成长路线、1 门 AI PM 课程、教材第 16 章能力模型）蒸馏重组，再补上新收集的 PM 访谈与教学，做成一个**独立于「AI 面试站」的产品经理学习站**。

定位：**AI PM 为主线，但含通用 PM 基本功**（发现、优先级、定价、带团队）——因为面试会考通用方法论。

## 二、输出格式

每个写作单元输出一个 JS 文件 `pm/data/<key>.js`：

```js
// 《AI 时代的产品经理》· <范围>
window.PM_SECTIONS = window.PM_SECTIONS || {};
Object.assign(window.PM_SECTIONS, {
  "1.1": {
    id: "1.1",
    t: "代码被写掉，瓶颈移到决策",
    why: "为什么学这节（1-2 句，说清不学它会卡在哪）",
    learn: "学完的标志（可检验：能说出 / 能画出 / 能判断）",
    body: "...",
    keypoints: ["3-6 条必须记住的结论"],
    pitfalls: ["2-4 条最容易错的地方"],
    rel: ["yt/03-知识专题/00-知识总纲.md"],
    qs: ["pd-01"],
    ev: [],
  },
});
```

**字符串红线**：`body` 用模板字符串（反引号）；正文代码块用 `~~~` 围栏（禁三反引号）；不得出现裸反引号；不得出现 `${`（要写就写 `\${`）。

**正文写法（延续现有教材风格）**，四小节：
```
### 一句话说清      是什么 + 一个类比
### 展开讲          机制与关键点；末尾一句加粗的「这一节在全书里的位置」
### 动手看          可操作步骤 / 模板 / 代码（可选，但方法论类最好有）
### 什么时候不该用   边界与反例
```
篇幅：**500-800 汉字**（导航型短节 350-500）。

**中文写作红线（刚做过去 AI 味规范化，必须遵守）**：
- 破折号 `——` 全篇尽量不用（改用冒号、括号、逗号）
- 分号 `；` 少用，长分句之间用句号
- 不要整句加粗（加粗只给术语）
- 句长要有起伏：写完长句补一个短句
- 禁用：值得注意的是 / 综上所述 / 总而言之 / 换言之 / 由此可见 / 具有重要意义 / 彰显 / 体现了 / 不可或缺
- 不要「不是 X，而是 Y」对仗句

### 单元 PM-E · key = `pm-e` —— 新收集的 PM 访谈与教学

**目标**：从公开渠道补 **6-10 场/份**新的 PM 内容（访谈或教学），做成蒸馏笔记。

**来源建议**（`yt/01-博主与频道/01-博主总览与学习路线.md` 里已列好名单）：
- Lenny's Podcast（PM 第一大播客，官网有公开文字稿）
- Aakash Gupta（AI PM 头部，有公开 newsletter）
- Latent Space（AI Engineer 视角）
- The Product Experience / Mind the Product
- Product School
- Dan Olsen / Lean Product Meetup
- Shreyas Doshi、Teresa Torres、Julie Zhuo 等 PM 方法论文

**输出**：`pm/data/pm-extra.js`，结构：

```js
window.PM_EXTRA = {
  items: [
    {
      id: "lenny-xxx",
      kind: "interview",       // interview | course | article
      guest: "嘉宾/作者",
      role: "身份",
      channel: "来源（播客/频道/网站）",
      title: "标题",
      url: "公开链接",
      date: "YYYY-MM",
      lang: "en",
      distilled: "蒸馏出的核心内容（300-600 字，按你自己的话重组，不要翻译腔）",
      takeaways: ["3-6 条要点"],
      quotes: [{ zh: "中文", en: "英文原句" }],
      why: "为什么值得看（1-2 句）",
      tags: ["PM 方法论", "定价"],
    },
  ],
};
```

**硬性要求**：
- **必须真去取到公开文字内容**（用 `web_fetch` 取官网/文字稿/newsletter 页面），不许凭印象编造嘉宾说过的话
- 取不到逐字稿时，`distilled` 里要**如实说明来源是公开摘要/节目介绍**，不假装是原话
- `quotes` 的 `en` 必须是原文（可核对），中文是你的翻译
- 每条都要有**可点开的公开 url**
- 不编造数字、日期、头衔
