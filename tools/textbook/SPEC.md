# 《AI 应用开发与求职》教材 —— 写作规范与大纲（唯一契约）

本文件是教材写作的**唯一契约**。所有写作单元必须严格遵守：节 id、关联笔记路径、关联真题 id 一律照抄，不得改动、增删、意译。

---

## 第一部分 · 输出格式

### 1. 文件

每个写作单元输出**一个** JS 文件，路径 `interview/data/tb-<key>.js`（key 见大纲每章标注）。

文件骨架（原样使用，只替换 `...`）：

```js
// <篇名> · <范围> —— 教材正文
window.TB_SECTIONS = window.TB_SECTIONS || {};
Object.assign(window.TB_SECTIONS, {
  "1.1": {
    id: "1.1",
    t: "环境与包管理",
    why: "为什么学这一节",
    learn: "学完的标志",
    body: "...",
    keypoints: ["...", "..."],
    pitfalls: ["...", "..."],
    rel: ["04-Python/环境搭建与包管理.md"],
    qs: [],
    ev: [],
  },
});
```

### 2. section 字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | ✅ | 节编号，必须与大纲完全一致 |
| `t` | string | ✅ | 节标题，≤16 字 |
| `why` | string | ✅ | 为什么学这节。1-2 句，说清「不学它会卡在哪」 |
| `learn` | string | ✅ | 学完的标志。必须**可检验**（能做出来 / 能讲出来 / 能判断），不用「了解」「熟悉」这类模糊词 |
| `body` | string | ✅ | 讲义正文，Markdown，见第 4 节写作规范 |
| `keypoints` | string[] | ✅ | 3-6 条，本节必须记住的结论，每条一句完整判断 |
| `pitfalls` | string[] | ✅ | 2-4 条，本知识点最容易错/最容易被追问的地方 |
| `rel` | string[] | ✅ | 关联笔记路径，**照抄大纲** |
| `qs` | string[] | ✅ | 关联真题 id，**照抄大纲**，无则 `[]` |
| `ev` | array | ✅ | 访谈证据，**默认留空数组 `[]`**，只有大纲明确给出才写 |

### 3. 字符串写法（重要，防止语法错误）

- `body` 用 **JS 模板字符串**（反引号）包裹。
- 正文里的**代码块一律用三个波浪线 `~~~` 作为围栏**，禁止用三个反引号（会与模板字符串冲突）。
- 正文里如果出现 `${` 字符，必须写成 `\${`。
- 正文里不要出现裸的反引号（行内代码请改用 `**加粗**` 表达，或写成「函数 `xxx`」的等价说法——若必须用行内代码，请用 `\`` 转义）。

### 4. body 写作规范（核心）

1. **长度 400-800 字**（中文字符计）。写不下就压缩，不要灌水；宁可 400 字讲透，不要 900 字列点。
2. **固定结构**（用三级标题）：
   - `### 一句话说清` —— 给出的定义，一句话讲完，必须带比喻
   - `### 展开讲` —— 原理 / 机制 / 为什么这样设计，可以分小段
   - `### 动手看` —— 可选。能跑的最小代码或最小操作步骤
   - `### 什么时候不该用` —— 可选。边界与反例
3. **必须讲透，不是列点**：每个概念的展开要覆盖「是什么 / 为什么这么设计 / 怎么用 / 什么时候不该用」四问中至少三问。
4. **语言**：中文，口语化，短句。比喻优先（「像……」）。禁止「综上所述」「赋能」「闭环」这类空话。
5. **禁止**出现「本节将介绍」「如上文所述」「详见笔记」这类指代——每节正文必须自洽可独立阅读。
6. **代码**必须是能跑的真代码（Python 为主），关键行写中文注释。用 `~~~python` 围栏。
7. **对比优先用表格**（Markdown 管道表）。
8. **禁止编造**：不确定的数字、论文名、版本号不要写；必须写时加「约」。
9. 不要在正文里写「面试会问」之类的应试话术（那是 pitfalls 的活）。

### 5. 严禁事项

- 严禁改动大纲给定的 `id` / `t` / `rel` / `qs`。
- 严禁写入不属于自己单元的节。
- 严禁在 JS 文件里出现 `三反引号`、未转义的 `${`、未转义的裸反引号。
- 严禁把 `Object.assign` 写成其它形式（多个文件会合并到同一个 `window.TB_SECTIONS`）。
