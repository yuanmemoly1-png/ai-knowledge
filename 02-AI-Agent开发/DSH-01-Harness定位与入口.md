# DSH-01 · Harness 定位与入口

> [!note] 一句话定义
> **DeepSeek Harness（DSH）是一个用 Node.js 写的"Agent 脚手架"**：它把一堆插件（工具、技能、人设、沙箱……）拼装起来，套在一个大模型外面，开机后就成了一个会读文件、写代码、调工具、干活的编码 Agent。命令行里它的名字叫 `dsh`。

先回顾 [[Agent-Harness脚手架]] 那张比喻：模型是"有蛮力的马"，Harness 是"驾驭它的马具"。DSH 就是 DeepSeek 这边的一套具体"马具"。

## 它跟我（这个 Agent）是什么关系

你现在是在网页里跟我说话，这个网页叫 **Web GUI（本机 `127.0.0.1:3080`）**。这个网页背后，就是 DSH 在跑：

```
你打一句话
   │
   ▼
Web GUI（浏览器页面）── 转发 ──→ DSH（Node.js 进程）
                                    │
                                    ├─ 从 profile 加载插件（我的工具/技能/人设）
                                    ├─ 把话打包发给大模型
                                    ├─ 模型说"调用工具"→ 沙箱里执行 → 结果回传
                                    └─ 把答案送回网页
```

所以**"我" = 大模型 + DSH 给的那套工具和规则**。换个模型，还是这套脚手架；换套 preset（预设），工具和性格就变了——这正是 Harness 和模型的分离。

## 入口：`dsh` 命令

DSH 装好后就有一个命令行命令叫 `dsh`，它是所有事情的"开关"。它有几种开机方式：

| 命令 | 干什么 | 类比 |
| --- | --- | --- |
| `dsh --profile <名字>` | 启动指定 profile | 打开某栋楼的电闸 |
| `dsh --profile headless "任务"` | 开一个"无头"会话，跑完打印答案就退出 | 不开店面，后台直接把活干完 |
| `dsh web` | `--profile web` 的别名 | 打开网页版（你现在用的就是这个） |
| `dsh plugin --profile <名字> <pnpm 参数>` | 管理某个 profile 的插件 | 装修队进场，增删插座 |

> [!example] 命令怎么拆
> ```sh
> dsh --profile web --port 8080
> #   └─ dsh 自己的参数 ─┘ └─ 传给 web 应用自己的参数 ─┘
> ```
> 规律：**`dsh` 只认自己那串 flag，从它认不出的第一个词开始，后面全交给被启动的应用**。所以 `--profile web` 是启动器的事，`--port 8080` 是网页应用自己的事。

## profile 是什么（关键概念）

**profile（配置文件集）是"一套套餐清单"**：它规定了这次开机要拼哪些插件、按什么顺序、用户又改了哪些配置。一个 profile 是一个目录，里面最少有这几样：

| 文件 | 作用 |
| --- | --- |
| `package.json` | 记录"树外"（额外装进来）的插件依赖 |
| `dsh.profile` | profile 清单：按顺序列出一堆 bundle（插件组合包） |
| `cordis.patch.yml` | 你自己的"补丁层"，用来覆盖默认配置 |

不用死记，[[DSH-04-配置文件与Preset结构]] 会展开讲。这里先记住一句话：**profile 决定了"这栋楼里装哪些插座"。**

## 一个 session 是怎么"开机"的

把上面串起来，一次开机（启动一个会话）大致是：

```text
1. 你敲 dsh --profile web
        ↓
2. dsh 找到 profile 目录，读出 bundle 清单
        ↓
3. 从"空配置"开始，一层层把 bundle 的配置叠上去（叠层，见 DSH-04）
        ↓
4. 再叠上你自己的 cordis.patch.yml 补丁
        ↓
5. Cordis 按最终配置，逐个"点亮"插件（提供工具、注册技能、注入人设）
        ↓
6. 一个 Agent 诞生，开始听你说话
```

> [!tip] 一眼记住
> **开机 = 叠配置 + 点亮插件。** 模型是"电"，插件是"电器"，`dsh` 是"总开关"，profile 是"电路图"。
