# DSH-06 · 动态插件：运行时扩展

> [!note] 一句话定义
> 前面讲的插件都是**写在配置文件里、开机时加载**的。DSH 还支持一种更炫的玩法：**在运行过程中，不重启，临时"插上一个新插件"，用完再拔掉。** 这就是"动态 Cordis 插件"——DSH 的"自修改"能力，也是 `cordis` 预设比 `standard` 多出来的看家本领。

## 为什么需要它

想象你已经开着一栋楼，突然想临时加个"计时器"功能——正常得停机、改配置、重启。动态插件让你**边跑边加**：

- 想给"我"临时加个工具、挂个界面、听个事件，不用重启整个会话。
- 想修一个临时插件的 bug，不用推翻重来，而是"上新版本"。

> [!tip] 但记住：它不是默认选项
> 动态插件是**众多实现手段之一**，只在"结果就该是当前运行中的临时扩展"时才用它。普通需求先想：这事该不该写进配置文件（[[DSH-04-配置文件与Preset结构]]）。

## 五步生命周期

| 操作 | 干什么 | 类比 |
| --- | --- | --- |
| `define`（定义） | 写一段插件代码并登记，**只记录、不运行** | 画图纸，存档，但没开工 |
| `run`（运行） | 把某个版本激活，真正插上电 | 按图纸施工并通电 |
| `update`（更新） | 从当前版本切换到另一个版本 | 换新版图纸重装 |
| `stop`（停止） | 关掉当前运行，但保留图纸和版本 | 断电但图纸还在 |
| `undefine`（彻底删除） | 关掉并删光所有图纸/版本/授权 | 拆房并烧图纸 |

> [!warning] define ≠ 运行
> 新手最容易误以为"定义完就生效了"。**定义只是把代码存档**，必须再 `run` 才会真正执行。定义成功后，下一步永远是"运行或更新"。

## 四个 ID，别搞混

动态插件体系里有一串 ID，各管一摊：

| ID | 是什么 | 类比 |
| --- | --- | --- |
| `pluginId` | 插件的**稳定身份**，可长期修改升级 | 这栋房子的门牌号 |
| `packageId` | 一个**不可变版本**的代码 | 某一版图纸（画完就不可涂改） |
| `pluginRunId` | **一次激活尝试**的编号 | 一次"通电施工"的工单号 |
| `currentPackageId` | 最近一次**完全成功**的版本 | 正在住的最新版 |
| `nextPackageId` | 待审批 / 尝试中 / 刚失败的版本 | 下一版图纸 |

**要点**：改代码 = 定义**新 package**，永远不覆盖旧版本（旧图纸留着可回滚）。失败不会自动回滚，可 `run` 回滚到 current，或 `update` 重试 next。

## 审批机制：单勾 vs 双勾

动态插件（尤其带 CLIENT 界面代码的）可能需要你授权：

- **单勾 ✅**：只授权**当前这一个 package**。
- **双勾 ✅✅**：授权**同一个插件的未来所有版本**。
- 授权在技术失败后**依然有效**（不用重新批准）。
- 你**拒绝后，不要再次请求**同一件事。

## Host 代码 vs Client 代码

一个动态插件可以有两半代码，各干各的：

| | Host（Node.js 进程） | Client（浏览器页面） |
| --- | --- | --- |
| 适合 | 文件、网络、命令、会话、模型工具 | 主题、布局、页面状态、工具卡片、插槽 UI |
| 语言限制 | 纯 JavaScript | 纯 JavaScript（React 要写 `React.createElement`，**不能写 `<组件/>`**） |
| 通信 | 定义 `harness.handle(方法, 处理)` 供 Client 调 | 用 `host.call(方法, 参数)` 调 Host |

通信是**单向的 Client→Host**，只能传"无损 JSON"。

## 三条保命纪律

1. **写前先查**：先看当前有哪些 Service/Event/Slot（用 Inspect 查询），别瞎猜名字。
2. **纯 JavaScript**：Host/Client 代码不会被 TypeScript/JSX/打包器转换，别写 `import`、类型、`<JSX>`。
3. **副作用必须可撤销**：所有定时器、监听、UI、主题覆盖都要挂在 `ctx.effect` 里，保证 stop/update/undefine 时能干净拔掉（呼应 [[DSH-02-Cordis插件化思想]] 的铁律）。

> [!tip] 一眼记住
> **define 存档 → run 通电 → 失败就 inspect 诊断再定义新版本重试 → 不用就 stop、彻底不要才 undefine。** 动态插件是"给运行中的大楼临时加房间"，加完记得能拆。
