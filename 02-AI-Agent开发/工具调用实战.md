# 工具调用实战

工具调用（Function Calling）是 Agent 的最小闭环：模型不直接干活，而是输出结构化的「调用请求」，由你的代码真正执行，再把结果回传给模型。本文用 openai SDK 风格写一个完整 demo：计算器 + 查天气。概念背景见 [[FunctionCalling函数调用]]。

## 完整流程

```
用户提问 → 模型返回 tool_call → 你的代码执行函数 → 结果回传 → 模型生成最终回答
```

## 第一步：定义工具的 JSON Schema

每个工具要向模型描述「名字、干什么、参数格式」。schema 写得好坏直接决定模型会不会用对。

```python
tools = [
    {
        "type": "function",
        "function": {
            "name": "calculator",
            "description": "计算数学表达式，支持加减乘除和括号。当需要做精确算术时调用。",
            "parameters": {
                "type": "object",
                "properties": {
                    "expression": {
                        "type": "string",
                        "description": "要计算的数学表达式，如 '3.5 * (2 + 1)'"
                    }
                },
                "required": ["expression"]
            }
        }
    },
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "查询指定城市的实时天气。",
            "parameters": {
                "type": "object",
                "properties": {
                    "city": {"type": "string", "description": "城市名，如 '北京'"},
                    "unit": {"type": "string", "enum": ["celsius", "fahrenheit"],
                             "description": "温度单位，默认 celsius"}
                },
                "required": ["city"]
            }
        }
    }
]
```

## 第二步：实现真正的函数

```python
def calculator(expression: str) -> str:
    """安全地计算简单数学表达式（生产环境建议用 ast 白名单解析）。"""
    allowed = set("0123456789+-*/(). ")
    if not set(expression) <= allowed:
        return "错误：表达式含非法字符"
    try:
        return str(eval(expression))
    except Exception as e:
        return f"计算失败: {e}"


def get_weather(city: str, unit: str = "celsius") -> str:
    """伪实现：真实项目里替换为调用天气 API（如和风天气、OpenWeatherMap）。"""
    fake_data = {"北京": (25, "晴"), "上海": (30, "多云"), "广州": (33, "雷阵雨")}
    temp, desc = fake_data.get(city, (20, "未知"))
    if unit == "fahrenheit":
        temp = temp * 9 / 5 + 32
    return f"{city}当前 {temp}°{'C' if unit == 'celsius' else 'F'}，{desc}"


TOOL_FUNCS = {"calculator": calculator, "get_weather": get_weather}
```

> [!warning] 永远不要直接 eval 模型输出
> 上面的 `calculator` 做了字符白名单过滤，仍不够严谨。生产环境应使用 `ast.literal_eval` 或专门的表达式解析库。模型可能输出任意内容，执行前必须校验。

## 第三步：主循环——解析、执行、回传

```python
import json
from openai import OpenAI

client = OpenAI()  # 需设置 OPENAI_API_KEY 环境变量

def run_agent(user_question: str, max_steps: int = 5) -> str:
    messages = [
        {"role": "system", "content": "你是一个助手，可以用工具完成任务。算数必须调用 calculator，不要口算。"},
        {"role": "user", "content": user_question},
    ]
    for step in range(max_steps):
        resp = client.chat.completions.create(
            model="gpt-4o-mini", messages=messages, tools=tools,
        )
        msg = resp.choices[0].message
        messages.append(msg)  # 把模型的回复（含 tool_calls）加入历史

        # 模型没有再请求工具 → 得到最终答案
        if not msg.tool_calls:
            return msg.content

        # 逐个执行工具调用并回传结果
        for call in msg.tool_calls:
            name = call.function.name
            args = json.loads(call.function.arguments)
            print(f"[step {step}] 调用 {name}({args})")
            result = TOOL_FUNCS[name](**args)
            messages.append({
                "role": "tool",
                "tool_call_id": call.id,   # 必须与 tool_call 的 id 对应
                "content": result,
            })
    return "超过最大步数"


if __name__ == "__main__":
    print(run_agent("北京今天天气怎么样？气温乘以 3 是多少？"))
```

预期输出（trace 部分）：

```
[step 0] 调用 get_weather({'city': '北京'})
[step 1] 调用 calculator({'expression': '25 * 3'})
北京当前 25°C，晴。气温乘以 3 等于 75。
```

## 关键细节清单

- **`tool_call_id` 必须一一对应**：回传结果时靠它告诉模型「这是哪次调用的结果」，漏掉会报错。
- **模型回复要原样 append**：`messages.append(msg)` 保留了 `tool_calls` 字段，否则上下文断裂。
- **一次可能返回多个 tool_call**：模型可能并行请求多个工具，for 循环要全部处理完再问模型。
- **必须有 max_steps 兜底**：防止模型陷入反复调用，详见 [[Agent评估与调试]]。
- **description 是给模型看的 Prompt**：写清楚「什么时候该调用」，比如上面特意写了「当需要做精确算术时调用」。

## 无 API Key 也能练手

没有 key 时，可以用「模拟模型」跑通整个 loop——把 `client.chat.completions.create` 换成一个按规则返回 tool_call 的假函数，流程逻辑完全一样。理解了这个循环，再看任何 Agent 框架（[[LangChain入门]]、[[LangGraph状态图]]）都会发现它们内部做的就是这件事。
