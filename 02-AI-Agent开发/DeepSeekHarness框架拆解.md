# DeepSeek Harness 框架拆解（总览）

> [!note] 一句话定位
> **DeepSeek Harness（简称 DSH，命令 `dsh`）就是"我"（你眼前这个 AI 编码助手）脚下跑的那套脚手架**。它不是模型，而是套在模型外面的那层工程：负责给我装工具、塞技能、管记忆、设护栏、跑循环。你现在跟我对话，背后就是它在运转。

> [!tip] 为什么值得拆它
> 你库里的 [[真实Agent源码解剖]] 拆的是 Kimi Code CLI 和 Claude Code——那些是"别人的房子"。而 DSH 是**你自己机器上正在运行、我能读源码、你随时能 `dsh` 启动的那栋房子**。看懂它，等于把 [[Agent-Harness脚手架]] 从"概念"变成"你亲手摸过的实物"。

**核心思想就一句话：一切皆插件（Cordis）。** 我的工具、技能、人设、甚至"沙箱""审批"这些安全设施，全都是一个个"插件"，写在一个个 `cordis.yml` 配置文件里，像叠透明胶片一样叠起来，最后拼成"我"。

> [!important] 记忆口诀
> **`dsh` 开机 → profile 叠层 → Cordis 拼插件 → 两个平面分家 → 我（Agent）出生。**
> - **dsh**：命令行开关
> - **profile**：一组插件的"套餐清单"
> - **Cordis**：拼插件的积木底座
> - **两个平面**：公共设施(HOST) vs 自家装修(Preset)
> - **Agent**：拼完开机后，那个会调用工具、读技能、干活的"我"
