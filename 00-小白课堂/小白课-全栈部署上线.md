# 小白课：全栈部署上线（让全世界都能访问）

上一课：[[小白课-全栈前后端合体]]

> [!note] 这节课学什么
> 你的全栈应用现在只有你自己能看——`localhost` 的意思是"我这台电脑"。这节课搞懂**部署**：把店从你电脑搬到一台 24 小时开机的服务器上，让别人用网址就能访问。
> 这节课**偏概念、不动手**：搞懂本地 vs 公网 → 三类部署平台怎么选 → 部署的概念流程 → 什么时候才该学部署。
> 先把地图装进脑子，真要动手时照着 [[部署与上线]] 和 [[小白课-部署上线]] 走。

---

## 第 1 步：本地 vs 公网——为什么别人打不开你的店

你现在的情况：

- 店开在**你自己的电脑上**（`localhost:8000`）
- 你关机、合盖、`Ctrl + C`——店就没了
- 别人在网址栏输入 `localhost:8000`，访问的是**他自己电脑**的 8000 窗口，不是你的

**部署**就是解决这件事：把代码搬到一台**永远不关机、有公网地址**的电脑（服务器）上，让店 24 小时营业。

大白话对比：

| | 本地（localhost） | 公网（部署后） |
| --- | --- | --- |
| 门牌号 | `localhost:8000` | `www.xxx.com` 这类域名 |
| 谁能进 | 只有你自己 | 全世界任何人 |
| 营业时间 | 你开机才营业 | 24 小时 |
| 用途 | 开发、调试 | 正式给别人用 |

## 第 2 步：三类部署平台怎么选

不用记细节，先建立"各有分工"的印象：

**① Vercel / Netlify 这类托管平台**

- 适合：**前端为主**的项目（网页、带少量接口的小应用）
- 特点：**免费额度够用、连上 Git 仓库后推代码就自动上线**，还送一个现成的域名
- 大白话：拎包入住的精装房，家具（服务器运维）不用你管
- 局限：跑重型后端、长驻任务不方便

**② 云服务器（阿里云 / 腾讯云的 ECS、轻量应用服务器）**

- 适合：**什么都能跑**，FastAPI、数据库随便装
- 特点：一台完整租给你的远程电脑，按月付费（学生/新用户常有一两折）
- 大白话：自己买地皮盖房——自由，但刷墙通水电（装环境、配安全、防攻击）全得自己来
- 局限：要懂一点 Linux 和运维，新手容易踩坑

**③ 微信云托管 / 小程序云开发**

- 适合：做**微信小程序**的后端
- 特点：和微信生态打通，登录、支付这些不用自己造轮子
- 大白话：开在微信商场里的铺位，客流（微信能力）现成，但得守商场的规矩

> [!important] 新手第一选
> 第一个作品想给别人看，优先试 **Vercel 类平台**：免费、自动、不用管服务器。等你需要跑正经后端和数据库了，再考虑云服务器。

## 第 3 步：部署的概念流程（所有平台都一样）

不管选哪家，骨子里都是同三步：

**① 传代码**

把你的代码送到平台上。主流做法是用 Git：代码推到仓库，平台从仓库拉取。所以 [[小白课-Git存档术]] 是部署的前置课。

**② 构建 + 启动**

平台拿到代码后**自动干活**：装依赖（相当于替你跑 `pip install`）、按约定命令启动你的应用（相当于替你跑 `uvicorn main:app`）。干完你的店就在平台的服务器上开张了。之后你每次推新代码，它自动重新部署——这叫"持续部署"。

**③ 绑定域名**

平台先送你一个免费域名（比如 `你的项目.vercel.app`），到这一步**就已经能发给别人访问了**。想要 `www.你的名字.com` 这种自己的域名，需要另外购买域名（一年几十块钱），再在平台后台绑定。

一句话串起来：**你把代码推上去 → 平台自动装好跑起来 → 全世界通过域名找到你的店。**

## 第 4 步：上线前后的常识（避坑用）

- **Key 和密钥绝对不能上线**：`.env` 里的 API Key 要用平台提供的"环境变量"功能配置，别把 `.env` 传进仓库，原理见 [[小白课-实战API第一课]]
- **本地能跑 ≠ 线上能跑**：依赖版本、文件路径大小写都可能出幺蛾子，上线后第一件事是亲自把每个功能点一遍
- **免费额度有边界**：流量大了、跑久了会收费或限速，正式用之前看一眼平台的计费页
- **国内访问**：面向国内用户、用国内服务器，域名通常需要**备案**（流程以周计），这是选平台时要提前想的

## 第 5 步：什么时候才该学部署

**不是现在。** 给你一个诚实的判断标准：

- 还在跟着教程敲代码、页面天天大改 → **本地就够**，部署是纯负担
- 做出了一个**想发给朋友/面试官看**的完整小作品 → 这时学 Vercel 类平台，半天就能上线
- 要做小程序、要接支付、要存用户数据 → 这时再深入研究云服务器或微信云托管

部署是"发布"环节的技能，**先有作品，再学发布**。具体动手步骤到时候看 [[小白课-部署上线]]。

## 最关键的一句

> [!important]
> **部署 = 把店从你电脑搬到 24 小时开机的服务器：传代码（Git）→ 平台自动构建启动 → 域名收客；新手先记住地图，做出想给人看的作品时再动手。**
