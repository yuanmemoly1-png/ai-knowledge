# 小白课：Prompt 提示词（慢速版）

上一课：[[小白课-Token与计费]]

> [!note] 这节课学什么
> 你递给接话人的纸条，就叫 **Prompt（提示词）**。这节课三件事：
> - 一次对话其实是**一叠纸条**，分 system / user / assistant 三种角色，逐个拆
> - 用 Python 把这叠纸条**真跑一遍**
> - 写好提示词的**三口诀** + 坏写法对照
>
> 三种角色是后面所有 Agent 课的地基，务必看懂。

---

## 第 1 步：一次对话其实是一叠纸条

很多人以为对话是"我说一句、他回一句"。但在程序里（用 API 调用时），**每次请求都是把一叠纸条整个递过去**，每张纸条上标着"这是谁说的"。

这一叠纸条在代码里就是一个**列表**，每张纸条是一个**字典**——就是你在 [[小白课-Python列表与字典]] 学过的那两个容器。格式长这样：

```python
{"role": "谁说的", "content": "说了什么"}
```

`role` 只有三种取值，下面一步拆一个。

## 第 2 步：system —— 老板定的规矩

一句大白话：**system 是"入职培训"，定全程的规矩**。

```python
{"role": "system", "content": "你是一个耐心的老师，回答不超过三句话。"}
```

它排在这叠纸条的**最前面**，全程有效。模型会一直照着它做，但不会"复述"它。你在网页版里看到的"设定角色/人格"，背后就是塞了一张 system 纸条。

## 第 3 步：user —— 你说的话

```python
{"role": "user", "content": "什么是黑洞？"}
```

就是你在输入框里敲的每一句。没什么玄机，但记住：**在程序眼里，你的话只是列表里的一张普通字典**。

## 第 4 步：assistant —— 他回过的话

```python
{"role": "assistant", "content": "黑洞是引力大到光都逃不出来的天体。"}
```

为什么要把**他自己以前的回答**也塞进去？回忆前两课：他没有记忆，每轮都要全量重发——**连他自己说过的话也得重发给他看**，他才知道"聊到哪了"。这就是滚雪球里雪球的一部分。

## 第 5 步：真跑一遍这叠纸条

把三种角色装进一个列表，挨个打印：

```python
messages = [
    {"role": "system", "content": "你是一个耐心的老师，回答不超过三句话。"},
    {"role": "user", "content": "什么是黑洞？"},
    {"role": "assistant", "content": "黑洞是引力大到光都逃不出来的天体。"},
    {"role": "user", "content": "那它会消失吗？"},
]
for m in messages:
    print(m["role"], "→", m["content"])
```

输出：

```text
system → 你是一个耐心的老师，回答不超过三句话。
user → 什么是黑洞？
assistant → 黑洞是引力大到光都逃不出来的天体。
user → 那它会消失吗？
```

**每次调 API，发的就是这样一个 messages 列表**。模型读完整个列表，接着生成下一张 assistant 纸条。看懂了这五行输出，你就看懂了所有聊天产品的底层。

> [!warning] 常见报错预告
> 纸条里的键名是固定的：`role` 和 `content`，大小写敏感。写成 `m["Role"]` 会报 `KeyError: 'Role'`。遇到了去查 [[新手报错速查]]。

## 第 6 步：写好提示词的三口诀

知道了纸条长什么样，下一个问题是：纸条怎么写他才好好答？三口诀：

1. **给角色**："你是一个资深 Python 老师"——先告诉他用谁的身份说话
2. **给任务**："把这段代码改成……"——动词开头，一件事说清楚
3. **给格式**："分三点回答，每点不超过 20 字"——告诉他答案长什么样

对照感受一下：

| 坏写法 ❌ | 好写法 ✅ |
| --- | --- |
| 讲讲黑洞 | 用小学生能懂的话解释黑洞，不超过 100 字 |
| 帮我写代码 | 用 Python 写一个统计文件行数的函数，只给代码和注释 |
| 这个报告怎么样 | 你是挑剔的编辑，指出这份报告的 3 个逻辑问题 |

规律一眼就能看出来：**坏写法缺角色、缺任务边界、缺输出格式；好写法三样都有。**

> [!warning] 容易误会的点
> 提示词不是咒语，**堆礼貌用语（"求求你""拜托了"）没用**。有效的是信息：角色、任务、格式。另外提示词管不了"他不知道的事"——那是 [[小白课-RAG开卷考试]] 要解决的。

## 最关键的一句

> [!important]
> **一次对话 = 一叠纸条：system 定规矩、user 是你、assistant 是他回过的，每轮全量重发；写好提示词 = 给角色、给任务、给格式。**

## 检查一下

1. messages 列表里每个元素是什么数据类型？里面必有的两个键是什么？
2. 为什么 assistant 以前说过的话也要塞进 messages？
3. system 纸条和 user 纸条的区别是什么？
4. 把"讲讲减肥"改成一条好提示词。

<details>
<summary>点我看答案</summary>

1. 字典；`role` 和 `content`。
2. 因为模型没有记忆，每轮都要全量重发，不塞进去他就不知道自己说过什么。
3. system 定全程的规矩（角色、约束），排在最前；user 是这一轮的具体问题。
4. 示例："你是健身教练，给完全没运动过的上班族一份减肥建议，分饮食和运动两块，各列 3 条。"（有角色、有任务、有格式即可）
</details>
