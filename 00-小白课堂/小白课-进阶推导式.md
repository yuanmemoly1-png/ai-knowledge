# 小白课：进阶推导式（慢速版）

上一课：[[小白课-进阶切片]]

> [!note] 这节课学什么
> AI 写的代码里有一种"把 for 循环压成一行"的写法，叫**列表推导式**，长得像这样：`[x * x for x in nums]`。第一次见绝对懵，其实它就是你已经会的东西换了个写法。
>
> 达标线：**给你一行推导式，你能拆回 3 行的 for 循环**。这节课先会读，不急着会写。

---

## 第一部分：从 for 循环"压缩"成一行

### 第 1 步：先看你会写的版本

想"把每个数平方，装进一个新列表"，用你已经学过的写法是 3 行：

```python
nums = [1, 2, 3, 4]

squares = []              # 1. 造个空列表
for x in nums:            # 2. 挨个来
    squares.append(x * x) # 3. 加工后塞进去

print(squares)
```

输出：

```text
[1, 4, 9, 16]
```

### 第 2 步：推导式——同样的事，一行

```python
squares2 = [x * x for x in nums]
print(squares2)
```

输出：

```text
[1, 4, 9, 16]
```

结果一模一样。拆开看这行的三个零件，和上面 3 行一一对应：

| 零件 | 对应原来哪行 | 意思 |
| --- | --- | --- |
| `x * x` | `append(x * x)` | 每个东西加工成什么样 |
| `for x in nums` | `for x in nums:` | 挨个来 |
| 外面的 `[ ]` | `squares = []` | 结果装进一个新列表 |

读法口诀：**"对每个 x（来自 nums），算一个 x*x，全部收进新列表"**。

> [!important] 读到推导式别慌
> 看到 `[ ... for ... in ... ]`，就在心里把它拆回 3 行 for 循环。拆得开，你就读懂了。**这节课不要求你会写，只要求你拆得开。**

## 第二部分：加一个条件 `if`

### 第 1 步：还是会写的版本

"只保留及格的成绩"：

```python
scores = [90, 45, 78, 55]

passed = []
for s in scores:
    if s > 60:
        passed.append(s)

print(passed)
```

输出：

```text
[90, 78]
```

### 第 2 步：推导式版本——条件写在最后

```python
passed2 = [s for s in scores if s > 60]
print(passed2)
```

输出：

```text
[90, 78]
```

读法：**"对每个 s（来自 scores），如果 s > 60，就把 s 收进新列表"**。规律：`if` 写在行尾，表示"不符合的直接丢掉"。

> [!warning] 别写太长
> 推导式可以塞得很复杂（嵌套好几层），但那样神仙也读不动。好代码里它一般只有一行、一个条件。看到超过一行的推导式，直接跳过细节、当成"造了一个列表"就行。

## 第三部分：字典推导式（点到为止）

把方括号换成花括号、加上 `名字: 内容`，造出来的就是字典：

```python
names = ["小明", "小红"]

d = {name: len(name) for name in names}
print(d)
```

输出：

```text
{'小明': 2, '小红': 2}
```

读法还是一样的："对每个 name，造一格 `name: 名字长度`"。见到能认出来是"快速造了个字典"就够了，不用深究。

## 最关键的一句

> [!important]
> **推导式 = 被压成一行的 for 循环：`[加工 for x in 列表 if 条件]`。看到它，在心里拆回 3 行 for 循环，你就读懂了。**

## 大白话翻译表

| 术语 | 大白话 |
| --- | --- |
| 列表推导式 | 一行写出"挨个加工，装进新列表" |
| `[x * x for x in nums]` | 每个数平方，收进新列表 |
| 行尾的 `if` | 过滤器，不符合的丢掉 |
| 字典推导式 | 同样的一行写法，造出来的是字典 |

## 检查一下

1. `[n + 1 for n in [1, 2, 3]]` 结果是多少？先拆成 3 行 for 循环再想。
2. `[s for s in [90, 45, 78] if s >= 60]` 里，`if` 起什么作用？结果是多少？
3. 推导式和 3 行 for 循环，算出来的结果有区别吗？
4. 看到一行很长、读不懂的推导式，这节课建议你怎么对待它？

<details>
<summary>点我看答案</summary>

1. `[2, 3, 4]`。拆开：`result = []` → `for n in [1,2,3]:` → `result.append(n + 1)`。
2. `if` 是过滤器，只留及格（>=60）的；结果 `[90, 78]`。
3. 没有区别，只是写法不同。所以读不懂时拆回 for 循环就行。
4. 跳过细节，当成"这里造了一个新列表"继续往下读——别在一行上卡死。
</details>
