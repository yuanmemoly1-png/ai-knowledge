# 小白课：全栈 CSS 装修（给网页化妆）

上一课：[[小白课-全栈HTML第一页]]

> [!note] 这节课学什么
> 上节课的网页是"毛坯房"：黑白字、全靠左。这节课用 **CSS 给它装修**：换颜色、改大小、排整齐。
> 按 5 步走：内联 style 上色 → `<style>` 标签统一管理 → 类选择器精准装修 → 盒模型 → Flex 一排摆开。
> 还是不用装任何东西，接着用上节课的 `hello.html` 就行。

---

## 第 0 步：CSS 是个啥

上节课说了 HTML 是**骨架**，那 CSS 就是**装修队**：刷墙（颜色）、换地板（背景）、摆家具（布局）。

一句话分工：**HTML 管"有什么"，CSS 管"长什么样"**。详见 [[HTML与CSS入门]]。

## 第 1 步：内联 style——最快见效的装修

打开 `hello.html`，把 `<h1>` 那行改成这样，保存，`F5` 刷新：

```html
<h1 style="color: blue; font-size: 40px;">你好，世界！</h1>
```

✅ 看到这个就对了：大字变成**蓝色**，而且更大了。

读法：`style="属性: 值; 属性: 值;"`，每条之间用分号隔开。

**实验指令**：把 `blue` 改成 `red`、`green`、`orange` 各刷一次看效果；把 `40px` 改成 `60px` 再看看。`px` 是像素，屏幕上的大小单位。

## 第 2 步：`<style>` 标签——一处装修，全屋生效

内联 style 写在一个个标签里，十个标题就得写十遍，太累。装修队的正规做法是**在 `head` 里贴一张总装修单**。

在 `<head>` 里、`</head>` 之前加这段：

```html
    <style>
        body {
            background-color: #f0f8ff;
            font-family: "Microsoft YaHei", sans-serif;
        }
        h1 {
            color: darkblue;
            text-align: center;
        }
        p {
            color: #333333;
        }
    </style>
```

保存，刷新。

✅ 看到这个就对了：整个页面变成淡淡的蓝色背景，大标题居中、深蓝色，段落变成深灰。

读法：`标签名 { 属性: 值; }` —— **对所有这个标签统一生效**。现在可以把第 1 步加在 `<h1>` 上的内联 style 删掉了，它已经归总装修单管。

**实验指令**：把 `background-color` 后面的 `#f0f8ff` 改成 `pink` 刷新看看；把 `text-align: center` 改成 `right` 看看标题跑哪去了。

## 第 3 步：类选择器——只装修指定的那一间

问题：页面上有两个 `<h2>`，只想让其中一个变红怎么办？答案是**给它贴个名牌（class）**，装修单按名牌点名。

改两处。先给某个 `<h2>` 贴名牌：

```html
<h2 class="warning">下面是一个按钮</h2>
```

再在 `<style>` 里加一条（注意前面的**点**）：

```css
        .warning {
            color: red;
            border: 2px solid red;
        }
```

保存，刷新。

✅ 看到这个就对了：只有贴了名牌的那个 `<h2>` 变红还带红框，另一个 `<h2>` 纹丝不动。

规律：**`标签名` 管一类，` .名牌` 管贴了牌的**。名牌自己随便起，英文就行。

## 第 4 步：盒模型——每个零件都是快递盒

CSS 里**每个零件都是一个盒子**，从里到外四层：

- **content**：盒子里的货（文字本身）
- **padding**：货和盒壁之间的泡沫填充（内边距）
- **border**：盒壁（边框）
- **margin**：盒子和邻居之间的距离（外边距）

在 `<style>` 里加一条，亲眼看看这四层：

```css
        button {
            background-color: gold;
            padding: 15px;
            border: 3px solid black;
            margin: 30px;
        }
```

保存，刷新。

✅ 看到这个就对了：按钮变成金色、里面空旷了（padding）、黑框变粗（border）、和周围东西拉开了距离（margin）。

**实验指令**：把 `padding` 改成 `30px` 看按钮变大；把 `margin` 改成 `0` 看按钮贴回去。

## 第 5 步：Flex——把东西一排摆开

默认情况下零件是**从上往下**排的。想横着排成一排？用一个父盒子装起来，对它说一句 `display: flex`。

在 `</body>` 前加三个盒子，外面再套一个父盒子：

```html
    <div class="row">
        <button>首页</button>
        <button>作品</button>
        <button>联系我</button>
    </div>
```

`<div>` 是"啥也不是的纯盒子"，专门用来分组。然后在 `<style>` 里加：

```css
        .row {
            display: flex;
            gap: 10px;
            justify-content: center;
        }
```

保存，刷新。

✅ 看到这个就对了：三个按钮**横着排成一排**，间距均匀，整体居中。

**实验指令**：把 `justify-content: center` 改成 `flex-start`（靠左）、`space-between`（两头对齐）各刷一次；把 `gap` 改成 `50px` 看间距。

## 报错救援表

| 情况 | 原因 | 解法 |
| --- | --- | --- |
| 样式完全没生效 | `<style>` 写进了 `body` 或忘了保存刷新 | `<style>` 放 `head` 里；`Ctrl + S` + `F5` |
| 类选择器不生效 | 名牌对不上 | HTML 里 `class="warning"` 和 CSS 里 `.warning` 必须一字不差（CSS 里带点，HTML 里不带） |
| 冒号写成分号、少括号 | 语法断了 | `属性: 值;` 用冒号赋值、分号结尾，整段包在 `{}` 里 |
| 改了一个 `h2` 全都变了 | 用的是标签选择器 | 想只改一个就用第 3 步的 class 名牌 |

更多排查套路见 [[新手报错速查]]。

## 最关键的一句

> [!important]
> **CSS 三句话：`标签 {}` 管一类、`.名牌 {}` 管点名、每个零件都是"内容-内边距-边框-外边距"四层盒子，横排就用 `display: flex`。**

## 大白话翻译表

| 术语 | 大白话 |
| --- | --- |
| CSS | 装修队，管网页长什么样，详见 [[HTML与CSS入门]] |
| 选择器 | 装修单上的"点名方式" |
| class | 给零件贴的名牌 |
| 盒模型 | 快递盒：货、泡沫、盒壁、盒间距 |
| `padding` / `margin` | 盒内泡沫厚度 / 盒子和邻居的距离 |
| Flex | 一句话让零件横着排队的魔法 |
| `<div>` | 啥也不是的纯盒子，用来分组 |

2. CSS 里 `.warning` 前面的点是什么意思？HTML 里对应写什么？
3. 想让按钮里面的文字离边框远一点，调 `padding` 还是 `margin`？
4. 三个按钮想横着排成一排，关键的一句 CSS 是什么？

<summary>点我看答案</summary>

1. HTML 管"有什么"（骨架），CSS 管"长什么样"（装修）。
2. 点表示"按 class 名牌点名"；HTML 里写 `class="warning"`（不带点）。
3. `padding`（内边距，盒子里面的空间）；`margin` 是盒子和外面邻居的距离。
