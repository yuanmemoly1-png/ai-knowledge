# 小白课：Python 变量与 print（慢速版）

上一课：[[小白课堂总览]]

> [!note] 这节课学什么
> 这是 Python 的第一课，只学两件事：
> - **变量**：一个装东西的盒子，贴上名字，随取随换
> - **print**：让程序把东西"说"出来，显示在屏幕上
>
> 盒子这个比喻点到为止——重点是跟着敲下面的每一步，看真实输出。

---

## 第 1 步：造一个变量

```python
name = "小明"
print(name)
```

输出：

```text
小明
```

发生了什么：

1. `name = "小明"` —— 造一个盒子，贴上名字 `name`，装进文字 `"小明"`。这个动作叫**赋值**
2. `print(name)` —— 把盒子里的东西打印出来

> [!warning] 两个容易踩的坑
> - `=` 两边的东西**别写反**：是 `name = "小明"`（名字在左），不是 `"小明" = name`
> - 文字**必须加引号** `"小明"`。不加引号的 `小明` 会被当成另一个盒子名，报 `NameError`——遇到去查 [[新手报错速查]]

## 第 2 步：换掉盒子里的内容

同一个名字的盒子，可以反复装新东西：

```python
age = 18
age = 19
print(age)
```

输出：

```text
19
```

第二行 `age = 19` 把旧内容 18 **直接扔掉**，装进 19。打印出来的是**最新**的内容。变量之所以叫"变"量，就是因为内容随时能换。

## 第 3 步：一次打印好几样东西

`print` 里可以放好几个东西，用**英文逗号**隔开：

```python
name = "小明"
age = 18
print("我叫", name, "，今年", age, "岁")
```

输出：

```text
我叫 小明 ，今年 18 岁
```

注意：print 会**自动在每项之间加一个空格**，所以"我叫"和"小明"之间多了个空格。想精确控制格式，下节课的 f-string 会解决它。

## 第 4 步：问一句"你是什么类型"（type）

盒子里可以装不同种类的东西。用 `type()` 问一问：

```python
print(type(18))
print(type("小明"))
print(type(3.14))
```

输出：

```text
<class 'int'>
<class 'str'>
<class 'float'>
```

三种最常见的类型：

| 类型 | 名字 | 长什么样 |
| --- | --- | --- |
| `int` | 整数 | `18`、`-3`、0（不加引号） |
| `str` | 字符串（文字） | `"小明"`、`"18"`（**加引号**） |
| `float` | 小数 | `3.14` |

现在不用背，下一步你就知道为什么要分了。

## 第 5 步：重点！数字的加法和文字的"加法"不一样

```python
print("1" + "2")
print(1 + 2)
```

输出：

```text
12
3
```

- `1 + 2`：两个**数字**相加，是算术，等于 3
- `"1" + "2"`：两段**文字**拼接，是"粘在一起"，等于 `"12"`

引号决定一切。**`"1"` 不是数字 1，它是个文字。**

那把文字和数字混在一起加呢？

```python
print("1" + 2)
```

```text
TypeError: can only concatenate str (not "int") to str
```

直接报错：文字和数字不能相加。以后看到 `TypeError` 先想：**是不是把引号加错地方了？** 详解在 [[新手报错速查]]。

## 最关键的一句

> [!important]
> **变量是贴了名字的盒子，`=` 装东西进去，`print()` 拿出来看。加引号是文字，不加是数字——`"1"+"2"` 得 `"12"`，`1+2` 才得 3。**

## 大白话翻译表

| 术语 | 大白话 |
| --- | --- |
| 变量 variable | 贴了名字的盒子 |
| 赋值 `=` | 把东西装进盒子 |
| `print()` | 让程序说出来 |
| `type()` | 问盒子里装的是哪类东西 |
| `int` / `float` | 整数 / 小数 |
| `str` | 字符串，就是"一段文字"，必须加引号 |
| `TypeError` | 类型搞混了，比如文字加数字 |

## 检查一下

1. `name = "小明"` 这一行做了什么？
2. `age = 18` 之后又写 `age = 20`，`print(age)` 输出几？
3. `print("2" + "3")` 和 `print(2 + 3)` 输出分别是什么？
4. `print(type("3.14"))` 输出是 `int`、`float` 还是 `str`？

<details>
<summary>点我看答案</summary>

1. 造了一个叫 `name` 的变量，装进文字 `"小明"`（赋值）。
2. 20——变量里永远是最新装进去的内容。
3. 第一个输出 `23`（文字拼接），第二个输出 `5`（数字加法）。
4. `str`——只要加了引号就是字符串，哪怕里面长得像小数。
</details>
