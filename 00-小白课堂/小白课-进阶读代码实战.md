## 第一部分：装饰器 `@`——给函数套个壳

看到函数头顶顶着一个 `@xxx`：

```python
import time

def timer(func):            # 造壳的函数：收一个函数，还一个新函数
    def wrapper():
        start = time.time()
        func()              # 真正干活的还是原来那个函数
        print(f"耗时 {time.time() - start:.2f} 秒")
    return wrapper

@timer                      # ← 给下面的 work 套上"计时壳"
def work():
    time.sleep(0.5)
    print("干活中...")

work()
```

输出：

```text
干活中...
耗时 0.50 秒
```

`@timer` 做的事：**work 还是原来那个 work，但每次调用它，都会自动多跑"计时"这层壳**。函数本身一行没改，功能被增强了。

> [!important] 见到 `@` 怎么读
> 读作"**这个函数被套了一层壳，壳会额外干点事**"。常见的壳：计时、记日志、检查登录。具体壳里干嘛，用到再看。以后读 AI 项目（比如 [[工具调用实战]] 里注册工具）会大量见到 `@`，别慌。

## 第二部分：`yield`——一句话概念

```python
def countdown(n):
    while n > 0:
        yield n        # 产出一个数，然后"暂停"在这
        n = n - 1

for x in countdown(3):
    print(x)
```

输出：

```text
3
2
1
```

`return` 是"一次性把结果全给你，函数结束"；`yield` 是"**给一个、暂停、下次接着给**"。函数里有 `yield`，它就成了一个"能慢慢产出东西"的机器，`for` 每转一圈找它要一个。

见到认识即可：**`yield` = 分批交货**。什么时候该深入？等你真遇到再说（比如读流式输出代码时），现在知道这个词够了。

## 第三部分：读陌生代码的五步法

拿到一段没见过的代码，按这个顺序读，不要从第一行死磕到最后一行：

1. **先找主流程**：找到"程序从哪开始跑"（通常在文件最下面，或 `if __name__ == "__main__":` 附近），先搞懂整体在干嘛
2. **认容器**：圈出 `[ ]` 和 `{ }`——这程序手里有哪些列表、哪些字典，数据长什么样
3. **认流程**：圈出 `for` / `while` / `if`——循环在哪转、岔路在哪分
4. **猜函数名**：`def get_weather(...)` 八成就是查天气，**先按名字猜，猜对了就不用读里面**
5. **跑起来改一改**：复制到编辑器里跑，改个数字、加个 `print`，看输出怎么变——跑通的代码才是读懂的代码

## 第四部分：实战——逐行读"迷你 Agent 循环"

下面这段就是 [[小白课-Agent传纸条循环]] 讲的那件事的代码版：**循环 → 接到指令 → 查工具表 → 执行 → 记下来**。先用五步法扫一眼结构（一个 while、一个字典、两个 if），再逐行读：

```python
# 工具表：字典，名字 → 这个工具实际干的事
tools = {
    "查天气": lambda: "北京今天 25°C 晴",   # lambda：一句话函数
    "算加法": lambda: "1 + 1 = 2",
}

memory = []          # 记忆本：空列表，每步的结果存进来
step = 0             # 步数计数器
orders = ["查天气", "算加法", "unknown", "quit"]   # 假装这是陆续收到的指令

while step < 10:     # 主循环：最多转 10 圈，防死循环
    order = orders[step]      # 取这一步的指令
    step = step + 1           # 步数 +1（让 while 趋向停止的关键行）

    if order == "quit":       # 岔路 1：收到退出指令
        print("收到退出指令，循环结束")
        break                 # break：直接跳出循环

    if order in tools:        # 岔路 2：工具表里有这个名字吗？
        result = tools[order]()   # 有 → 从字典里取出工具，加括号执行
    else:
        result = f"没有叫「{order}」的工具"   # 没有 → 给个说法

    memory.append(result)     # 这步的结果记进记忆本
    print(f"第 {step} 步：{result}")

print("记忆本：", memory)
```

运行，输出：

```text
第 1 步：北京今天 25°C 晴
第 2 步：1 + 1 = 2
第 3 步：没有叫「unknown」的工具
收到退出指令，循环结束
记忆本： ['北京今天 25°C 晴', '1 + 1 = 2', '没有叫「unknown」的工具']
```

回看五步法在这段代码上怎么用：

- 主流程：底部没有多余代码，主体就是中间那个 `while`——"不停地接指令干活"
- 容器：`tools` 是字典（工具表）、`memory` 是列表（记忆本）、`orders` 是列表（指令队列）
- 流程：一个 `while` 负责转圈，两个 `if` 负责"退出吗？""有这工具吗？"
- 函数名：没有 `def`，但 `查天气`、`算加法` 看名字就知道干嘛
- 跑起来改一改：把 `orders` 里加一条 `"查天气"`，重跑，看多转一圈

> [!important] 这段代码值得抄下来跑三遍
> 真实的 Agent（包括你在 [[Agent开发总览]] 会读到的那些）核心就是这么个循环，只是工具更多、指令来自大模型。读懂这 20 行，你就摸到了 Agent 的骨头。

## 最关键的一句

> [!important]
> **读陌生代码别从第一行死磕：先找主流程、认容器、认流程、猜函数名、跑起来改一改。`@` 是给函数套壳，`yield` 是分批交货——见到认识即可。**

## 大白话翻译表

| 术语 | 大白话 |
| --- | --- |
| 装饰器 `@xxx` | 给函数套一层壳，壳额外干点事（计时、记日志等） |
| `yield` | 分批交货：给一个、暂停、下次接着给 |
| `break` | 立刻跳出循环 |
| `order in tools` | 查字典里有没有这个名字 |
| 主流程 | 程序真正开始跑的那条主线 |
