# 小白课：Python 条件与循环（慢速版）

上一课：[[小白课-Python列表与字典]]

> [!note] 这节课学什么
> 到目前为止，你的代码都是"从上往下，每行都执行"。这节课让程序长脑子：
> - **条件 if**：看情况决定执不执行（岔路口）
> - **循环 for / while**：把一件事重复做（转圈圈）
>
> 学完这节课，你就集齐了"写一个完整程序"的全部积木。每一步都有代码和真实输出。

---

## 第一部分：if —— 看情况办事

### 第 1 步：最小的 if

```python
age = 20

if age >= 18:
    print("成年了")
```

输出：

```text
成年了
```

三个要点，一个都不能少：

1. `if` 后面是**条件**（一个"是/否"问题：`age >= 18` 成立吗？）
2. 条件结尾有**冒号 `:`**
3. 属于 if 的代码**前面空 4 格**（这叫**缩进**）——缩进表示"这行归 if 管"

把 age 改成 15 再跑：**什么都不输出**——条件不成立，缩进那行被跳过。

### 第 2 步：条件怎么写（比较符号表）

| 写法 | 意思 |
| --- | --- |
| `a == b` | a 等于 b（**两个等号**！） |
| `a != b` | a 不等于 b |
| `a > b` / `a < b` | 大于 / 小于 |
| `a >= b` / `a <= b` | 大于等于 / 小于等于 |

> [!warning] 最容易犯的错
> `=` 是"装东西"（赋值），`==` 才是"比较"。`if age = 18:` 会直接报 `SyntaxError`。**比较用两个等号。**

### 第 3 步：加一条"否则"（else）

```python
age = 15

if age >= 18:
    print("成年了")
else:
    print("未成年")
```

输出：

```text
未成年
```

`else` = "否则"。条件成立走 if 的路，不成立走 else 的路，**两条路必走一条**。

### 第 4 步：多个岔路（elif）

```python
score = 75

if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

输出：

```text
及格
```

`elif` = "否则如果"，可以接好几个。Python 从上往下检查，**走第一个成立的，后面的直接跳过**。

## 第二部分：for —— 把一排格子挨个看一遍

### 第 1 步：最小 for 循环

```python
fruits = ["苹果", "香蕉", "橘子"]

for f in fruits:
    print(f)
```

输出：

```text
苹果
香蕉
橘子
```

读法：**"对 fruits 里的每一个（叫它 f），都执行一遍缩进的代码"**。列表有 3 格，缩进那行就跑了 3 次，每次 f 自动换成下一格的东西。

### 第 2 步：for + 计数（range）

想"重复 5 次"但手头没有列表？用 `range(5)` 现场造一串号码：

```python
for i in range(5):
    print(f"第 {i} 次")
```

输出：

```text
第 0 次
第 1 次
第 2 次
第 3 次
第 4 次
```

`range(5)` = 造出 0,1,2,3,4 这 5 个号码（**又是从 0 开始**，到 5 为止但不包含 5）。

### 第 3 步：for + if 合体（真正的程序感）

```python
scores = [90, 45, 78, 55]

for s in scores:
    if s >= 60:
        print(f"{s} 及格")
    else:
        print(f"{s} 不及格")
```

输出：

```text
90 及格
45 不及格
78 及格
55 不及格
```

**循环负责"挨个来"，if 负责"看情况"**——90% 的程序都是这个组合。

## 第三部分：while —— 转到条件不成立为止

```python
n = 1

while n <= 3:
    print(f"第 {n} 圈")
    n = n + 1        # 关键！每圈把 n 加 1
```

输出：

```text
第 1 圈
第 2 圈
第 3 圈
```

读法：**"只要条件还成立，就再转一圈"**。和 for 的区别：

- `for`：知道要转几次（列表有几格 / range 到几）
- `while`：不知道转几次，只知道"什么时候停"

> [!warning] 死循环警告
> 如果忘了写 `n = n + 1`，n 永远是 1，条件永远成立，程序**永远转下去**（只能按 `Ctrl+C` 强停）。写 while 先问自己：**"哪一行在让条件趋向不成立？"**

## 最关键的一句

> [!important]
> **if 看情况、for 挨个来、while 转到停。三个都要：条件后有冒号，归属的代码缩进 4 格。**

## 大白话翻译表

| 术语 | 大白话 |
| --- | --- |
| 条件 condition | 一个是/否问题，如 `age >= 18` |
| 缩进 indent | 行首空 4 格，表示"这行归谁管" |
| `if / elif / else` | 如果 / 否则如果 / 否则 |
| `for x in 列表` | 挨个来，x 自动换成下一个 |
| `range(n)` | 造一串号码 0 到 n−1 |
| `while 条件` | 条件成立就再转一圈 |

## 检查一下

1. `if age = 18:` 哪里错了？
2. `for x in ["a", "b"]:` 缩进里的代码会执行几次？每次 x 是什么？
3. `range(3)` 产生哪几个数？
4. while 循环忘了写让条件变化的那一行，会发生什么？

<details>
<summary>点我看答案</summary>

1. 应该是 `==`（比较），不是 `=`（赋值）。
2. 2 次；第一次 `x` 是 `"a"`，第二次是 `"b"`。
3. 0、1、2（到 3 为止但不包含 3）。
4. 死循环——程序永远转下去，要按 Ctrl+C 强停。
</details>
