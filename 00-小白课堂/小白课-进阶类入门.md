# 小白课：进阶类入门（慢速版）

上一课：[[小白课-进阶参数与lambda]]

> [!note] 这节课学什么
> 到现在为止，你用过 Python 自带的"东西"：数字、字符串、列表、字典。但真实程序要装的东西千奇百怪——一只狗、一个用户、一个 Agent。装不下怎么办？**自己造一种新"东西"**，这就是 `class`（类）。
>
> 达标线非常明确：**读得懂别人写的类**。AI 写的项目代码几乎全是类，你能看懂结构就赢了；不要求你会设计。

---

## 第一部分：类是"图纸"，对象是"成品"

一句话关系：

- **类（class）= 图纸**：规定"这种东西有名字、会叫"
- **对象（object）= 照图纸造出来的成品**：旺财是一只狗，来福是另一只

图纸画一张，能造无数个成品。看代码：

```python
class Dog:                      # 画图纸：造一种叫 Dog 的东西
    def __init__(self, name):   # 出厂设置：造的时候必须给个名字
        self.name = name        # 把名字贴在这只狗自己身上

    def bark(self):             # 它会做的事：叫
        print(f"{self.name}：汪汪！")
```

先别管细节，认一下长相：`class` 开头，里面装着几个缩进的 `def`。图纸里写的 `def` 就是"这种东西会做的事"。

## 第二部分：照图纸造东西、用东西

```python
d1 = Dog("旺财")     # 照图纸造一只狗，名字"旺财"
d2 = Dog("来福")     # 同一张图纸，再造一只

print(d1.name)       # 看 d1 身上贴的名字
print(d2.name)
d1.bark()            # 让 d1 叫
d2.bark()
```

输出：

```text
旺财
来福
旺财：汪汪！
来福：汪汪！
```

注意三点读法：

1. **造东西**：`Dog("旺财")` —— 类名后面加括号，像调函数一样，造出一个对象
2. **看属性**：`d1.name` —— 点号表示"它身上的"
3. **让它做事**：`d1.bark()` —— 点号加括号，"让 d1 执行 bark"

## 第三部分：三个怪零件，逐个翻译

### 零件 1：`__init__` —— 出厂设置

名字前后各两根下划线，念"init"。它是**造对象那一刻自动跑**的函数：`Dog("旺财")` 一执行，`__init__` 自动被调用，`"旺财"` 自动传给 `name` 参数。

读法：**"造这种东西的时候，要准备什么材料、做什么准备"**。

### 零件 2：`self` —— "我自己"

`self.name = name` 的意思是：把传进来的 `name`，贴到**我自己**身上，存成 `self.name`。以后这句就是"我的名字"。

为什么每个 `def` 的第一个参数都是 `self`？因为 `d1.bark()` 跑的时候，Python 得知道是**哪只狗**在叫——`d1` 会被悄悄塞给 `self`。所以：

- 图纸里写 `self.name` → 读作"（这只狗）自己的名字"
- 用的时候写 `d1.name` → 读作"d1 的名字"

**`self` 在图纸里代表"将来的某一个具体成品"。**

### 零件 3：属性 vs 方法

- **属性**：对象身上存的数据，如 `self.name`（"它有什么"）
- **方法**：对象会做的动作，如 `bark()`（"它会干嘛"）

一个类 = 属性 + 方法，装在一个图纸里。

## 第四部分：以后你会在哪里见到它

AI 项目里，一段典型代码长这样：

```python
agent = Agent(model="kimi", tools=[search, calc])
agent.run("帮我查天气")
```

现在你读得懂了：`Agent` 是图纸，`agent` 是照图纸造的一个对象，`run` 是它的方法。你在 [[Agent开发总览]] 里看到的框架，全都是这个结构。

> [!warning] 别被大文件吓到
> 真实项目里一个类可能有几十行、十几个方法。读法不变：先找 `class` 名字（这是什么东西）→ 找 `__init__`（造它要给什么）→ 找方法名（它会干嘛）。细节用到再看。

## 最关键的一句

> [!important]
> **类是图纸、对象是成品；`__init__` 是造对象时自动跑的出厂设置；`self` 在图纸里代表"我自己"；`对象.属性` 看它有什么，`对象.方法()` 让它做事。**

## 大白话翻译表

| 术语 | 大白话 |
| --- | --- |
| 类 class | 图纸，定义一种新"东西" |
| 对象 object / 实例 | 照图纸造出来的一个具体成品 |
| `__init__` | 出厂设置，造对象时自动跑 |
| `self` | 图纸里的"我自己"（将来的某个成品） |
| 属性 attribute | 对象身上存的数据 |
| 方法 method | 对象会做的动作（图纸里的函数） |

## 检查一下

1. `Dog("旺财")` 这一行执行时，哪个函数被自动调用了？`"旺财"` 去了哪个参数？
2. `self.name = name` 里，等号左右的两个 `name` 各是什么？
3. `d1.bark()` 里的 `d1`，在图纸里对应哪个名字？
4. 看到一个陌生类，建议先找哪三样东西？

<details>
<summary>点我看答案</summary>

1. `__init__` 被自动调用；`"旺财"` 传给 `name` 参数。
2. 右边的 `name` 是传进来的材料；左边的 `self.name` 是贴在对象自己身上、长期保存的那份。
3. `self`——`d1.bark()` 跑的时候，`d1` 被悄悄塞给 `self`。
4. `class` 的名字（这是什么东西）、`__init__`（造它要给什么）、方法名（它会干嘛）。
