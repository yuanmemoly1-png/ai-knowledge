# 小白课：Python 列表与字典（慢速版）

上一课：[[小白课-Python字符串]]

> [!note] 这节课学什么
> 到目前为止，你的变量一次只能装**一个**东西（一个名字、一个数字）。但现实中数据都是"一堆"：一张购物清单、一份成绩单。这节课学两个装"一堆东西"的容器：
> - **列表 list**：一排有编号的格子，按**号码**取东西
> - **字典 dict**：一排贴名字的格子，按**名字**取东西
>
> 全程只用 4 个动作：**造、取、改、增**。每一步都有代码和真实输出，跟着敲。

---

## 第一部分：列表（list）

### 第 1 步：造一个列表

用方括号 `[ ]`，东西之间用英文逗号隔开：

```python
fruits = ["苹果", "香蕉", "橘子"]
print(fruits)
```

输出：

```text
['苹果', '香蕉', '橘子']
```

好了，你造出了一排 3 个格子。记住它的长相：**方括号 + 逗号**。

### 第 2 步：取东西（重点！号码从 0 开始）

取东西用 `列表名[号码]`。但有个全世界新手都会绊一下的规则：**第一个格子的号码是 0，不是 1**。

```python
fruits = ["苹果", "香蕉", "橘子"]
#          0号      1号      2号      ← 号码是这样排的

print(fruits[0])    # 输出：苹果  （第 1 个，号码 0）
print(fruits[2])    # 输出：橘子  （第 3 个，号码 2）
```

> [!important] 为什么是 0 不是 1？
> 把号码理解成"从起点**走了几步**"：站在起点一步没走就是第 1 个（0），走 1 步到第 2 个（1）。不用深究，记住就行：**号码 = 位置 − 1**。

再送一个常用技巧：**号码写 -1 表示"最后一个"**：

```python
print(fruits[-1])   # 输出：橘子  （倒数第 1 个）
```

### 第 3 步：数有几个格子

用上一部分学过的 `len()`：

```python
print(len(fruits))    # 输出：3
```

### 第 4 步：改掉某个格子里的东西

```python
fruits[1] = "西瓜"      # 把 1 号格子的"香蕉"换成"西瓜"
print(fruits)
```

输出：

```text
['苹果', '西瓜', '橘子']
```

格式：**`列表[号码] = 新东西`**。

### 第 5 步：加一个格子（append）

```python
fruits.append("葡萄")    # 在末尾加一个格子，装进"葡萄"
print(fruits)
```

输出：

```text
['苹果', '西瓜', '橘子', '葡萄']
```

`append` 就是"追加"，**只能加在末尾**。这是列表最常用的方法，没有之一。

### 第 6 步：删掉一个东西（remove）

```python
fruits.remove("苹果")    # 把"苹果"拿走（按内容删，不是按号码）
print(fruits)
```

输出：

```text
['西瓜', '橘子', '葡萄']
```

> [!warning] 常见报错预告
> 如果你写 `fruits[9]`（根本没有 9 号格子），会报 `IndexError: list index out of range`——"号码超出范围"。遇到了去查 [[新手报错速查]]。

## 第二部分：字典（dict）

列表按号码找东西。但很多时候，数据是"有名字"的——成绩单上写着"语文：90 分"，你不会说"第 1 个成绩"。这时候用**字典**。

### 第 1 步：造一个字典

用花括号 `{ }`，每格是 `名字: 内容`：

```python
scores = {"语文": 90, "数学": 85}
print(scores)
```

输出：

```text
{'语文': 90, '数学': 85}
```

记住长相：**花括号 + 冒号**。名字有个正式叫法——**键（key）**，内容叫**值（value）**。

### 第 2 步：取东西（按名字）

```python
print(scores["语文"])    # 输出：90
```

和列表的写法几乎一样，只是 `[ ]` 里放的是**名字（记得加引号，它是文字）**。

### 第 3 步：改和增——是同一行代码！

字典有个省心的地方：**改和新增是同一个写法**：

```python
scores["数学"] = 95    # "数学"格子已存在 → 改成 95（改）
scores["英语"] = 88    # "英语"格子不存在 → 新加一个（增）
print(scores)
```

输出：

```text
{'语文': 90, '数学': 95, '英语': 88}
```

规则一句话：**名字已存在就改，不存在就加。**

### 第 4 步：删掉一格（del）

```python
del scores["语文"]
print(scores)
```

输出：

```text
{'数学': 95, '英语': 88}
```

> [!warning] 常见报错预告
> 取一个字典里没有的名字，比如 `scores["物理"]`，会报 `KeyError: '物理'`——"没这个标签"。遇到了去查 [[新手报错速查]]。

## 列表还是字典？30 秒选型

| 你的数据长这样             | 用这个      |
| ------------------- | -------- |
| 一串有顺序的东西（购物清单、聊天记录） | 列表 `[ ]` |
| 每个东西都有名字（成绩单、用户信息）  | 字典 `{ }` |

真实例子——以后写 AI 程序，一条消息就是字典：

```python
msg = {"role": "user", "content": "你好"}
print(msg["content"])    # 输出：你好
```

这就是给大模型递"纸条"时的格式，你在 [[小白课-Prompt提示词]] 已经见过它了。

## 最关键的一句

> [!important]
> **列表按号码取（`fruits[0]`，从 0 数起），字典按名字取（`scores["语文"]`，名字加引号）。**

## 大白话翻译表

| 术语 | 大白话 |
| --- | --- |
| 列表 list | 一排编号的格子，方括号 `[ ]` |
| 字典 dict | 一排贴名字的格子，花括号 `{ }` |
| 索引 index | 格子号码，从 0 开始，-1 是最后一个 |
| 键 key / 值 value | 格子名字 / 格子里的内容 |
| `append()` | 列表末尾加一格 |
| `remove()` | 按内容删掉一个 |
| `del` | 字典里拆一格 |

## 检查一下

1. `a = ["猫", "狗", "兔"]`，`a[1]` 和 `a[-1]` 分别是什么？
2. `d = {"name": "小明"}`，想取出"小明"写哪一行？
3. `a.append("桃子")` 之后，`len(a)` 是几？
4. `d["age"] = 18` 这一行是"改"还是"增"？

<details>
<summary>点我看答案</summary>

1. `a[1]` 是 `"狗"`（号码从 0 数）；`a[-1]` 是 `"兔"`（最后一个）。
2. `d["name"]`。
3. 4（原来 3 格，append 加 1 格）。
4. 是"增"——因为 `age` 这个名字之前不存在。名字已存在才是改。
</details>
