# 小白课：Token 与计费（慢速版）

上一课：[[小白课-LLM大语言模型]]

> [!note] 这节课学什么
> 用 API 调用大模型是要花钱的。钱花在哪、怎么算，只需懂一件事：**token**。
> - 话要先**切成小碎块**，这个碎块就是 token
> - **中文和英文切法不一样**（直接影响你的钱）
> - **按块收费**，而且输出比输入贵
> - 聊天会**滚雪球**，越聊越贵
>
> 每一步都有能跑的小算账代码，跟着敲。

---

## 第 1 步：话要先切成小碎块

一句大白话定义：**token 就是 LLM 眼里话的最小单位**。你看的是字和词，他看的是一块一块的 token。

为什么要切？因为电脑不认字，只认数。切块的目的是把每个小块编上号码，他才能处理。就像快递不按"你寄了个啥"收费，而是先放秤上称——**token 就是那杆秤**。

## 第 2 步：中文和英文，切法差很多



切法不是"一个字一块"也不是"一个词一块"，而是按他学到的**常见组合**。大概的规律：

| 语言 | 大概行情 | 例子 |
| --- | --- | --- |
| 英文 | 1 个常见单词 ≈ 1 个 token | `hello` ≈ 1 块 |
| 中文 | 1 个汉字 ≈ 1~2 个 token | `你好` 可能 2~4 块 |

> [!warning] 容易误会的点
> "一句话 10 个字 = 10 个 token"？不对。**字数和 token 数没有固定换算**，只能估个大概。精确数字要用官方工具数（OpenAI 有在线 tokenizer 页面）。平时心算按"中文 1 字 ≈ 1.5 token、英文 1 词 ≈ 1.3 token"估，够了。

亲手估一下，感受"字数"和"块数"的差别：

```text
"Hello world"   → 2 个词 → 约 2~3 个 token
"你好，世界"     → 4 个汉字 + 1 个标点 → 约 5~8 个 token
```

同一个意思，**中文往往比英文费 token**——所以中文对话的账单常常比英文略高一点。另外，token 这把尺后面还会用到：讲"上下文窗口"（[[小白课-幻觉与上下文窗口]]）时，窗口大小也是按 token 算的。

## 第 3 步：按块收费，而且是两份钱

调 API 的账单分两行：

- **输入 token**：你递进去的纸条（你的问题 + 系统提示 + 历史记录）
- **输出 token**：他写出来的回答

跑一个小算账程序感受一下量级（单价是随便编的示例价，真实的查官网）：

```python
输入tokens = 1200
输出tokens = 300
输入单价 = 2   # 每百万 token 2 元（示例价）
输出单价 = 8   # 每百万 token 8 元（示例价）
花费 = 输入tokens / 1000000 * 输入单价 + 输出tokens / 1000000 * 输出单价
print("这次问答花费：", round(花费, 6), "元")
```

输出：

```text
这次问答花费： 0.0048 元
```

一次问答不到半分钱——**个人学习随便用，真正烧钱的是批量跑和超长聊天**（第 5 步）。

> [!tip] 各家价格差很多
> 不同模型、不同厂商的单价能差出好几倍；开源模型还能自己部署，只出机器钱——那是 [[小白课-部署上线]] 的话题。用之前去官网看一眼价目表，单位都是"每百万 token"。

## 第 4 步：为什么输出比输入贵？

看上面的示例价：输入 2 元，输出 8 元，差了 4 倍。这是普遍现象，原因一句话：

**读是"一眼扫完"，写是"一个字一个字蹦"。**

- **输入**：你的 1200 个 token，他可以**并行**一口气读完
- **输出**：他的 300 个 token，必须**串行**——蹦出第 1 个，才能算第 2 个，再算第 3 个……每个都要全模型跑一遍

写比读慢得多，占用机器的时间长得多，所以贵。省钱的直接推论：**让他"简短回答"就是真金白银的省钱。**

## 第 5 步：聊天会滚雪球（最容易被忽略的烧钱点）

回忆上一课：他没有记忆，**每轮对话都要把全部历史重新发一遍**。也就是说，第 10 轮对话时，前 9 轮的话全部算进"输入 token"再收一次钱。用代码模拟一下：

```python
history = []
history.append("你好")
history.append("你好！有什么可以帮你？")
print("第 1 轮，要重发的总字数：", sum(len(m) for m in history))
history.append("我上一句说了什么？")
history.append("你说的是：你好。")
print("第 2 轮，要重发的总字数：", sum(len(m) for m in history))
history.append("我最开始说了什么？")
print("第 3 轮，要重发的总字数：", sum(len(m) for m in history), "（还在涨）")
```

输出：

```text
第 1 轮，要重发的总字数： 13
第 2 轮，要重发的总字数： 30
第 3 轮，要重发的总字数： 39 （还在涨）
```

**聊得越久，每轮的输入越大，同一个窗口聊一天，账单是滚雪球的。**所以长聊天该开新窗口就开新窗口（顺便也省钱）。

## 最关键的一句

> [!important]
> **token 是计费的最小单位：输入输出分开收，输出贵好几倍，而且每轮对话历史全量重发——聊得越久越贵。**

## 检查一下

1. 为什么中文 10 个字不一定是 10 个 token？
2. 账单上"输入"和"输出"分别指什么？
3. 输出为什么比输入贵？
4. 一个聊了 50 轮的窗口，为什么第 50 轮特别贵？

<details>
<summary>点我看答案</summary>

1. 因为切分按"常见组合"不按字数，1 个汉字可能占 1~2 个 token，没有固定换算。
2. 输入 = 你发过去的内容（问题+历史）；输出 = 模型生成的回答。
3. 输入可以并行一口气读完；输出必须一个 token 一个 token 串行生成，慢得多。
4. 因为没有记忆，每轮都要把前 49 轮的全部记录重发一遍，输入 token 滚雪球。
</details>
