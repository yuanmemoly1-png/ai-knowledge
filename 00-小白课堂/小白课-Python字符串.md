# 小白课：Python 字符串（慢速版）

上一课：[[小白课-Python变量与print]]

> [!note] 这节课学什么
> 字符串就是"一段文字"（加引号的那种）。以后和 AI 打交道，发的每一句话、收的每一段回答，全是字符串。这节课学 4 组操作：
> - **拼接和重复**：`+` 和 `*`
> - **f-string**：往文字里挖洞填变量（本课最重要）
> - **len**：数字数
> - **split / join / replace**：切开、粘上、替换

---

## 第 1 步：拼接（+）和重复（*）

```python
print("你好" + "，世界")
print("哈" * 3)
```

输出：

```text
你好，世界
哈哈哈
```

- `+` 把两段文字**粘**成一段
- `*` 把一段文字**复制**几遍

上节课说过：文字只能和文字 `+`，`"1" + 2` 会报 `TypeError`。

## 第 2 步：f-string —— 往文字里挖洞（重点）

拼接变量很累：`"我叫" + name + "，今年"`…… f-string 让你直接在文字里**挖洞 `{}` 填东西**。写法：引号前加一个字母 `f`：

```python
name = "小明"
age = 18
print(f"我叫{name}，今年{age}岁")
```

输出：

```text
我叫小明，今年18岁
```

洞里不只能放变量，**还能放算式**，Python 会先算完再填进去：

```python
age = 18
print(f"明年我就{age + 1}岁了")
```

输出：

```text
明年我就19岁了
```

> [!warning] 最容易犯的错
> 忘了写引号前的 `f`，`"我叫{name}"` 会原样打印出 `{name}`。**看到大括号原样输出，先检查 f 写没写。**

## 第 3 步：数字数（len）

```python
print(len("hello"))
print(len("你好世界"))
```

输出：

```text
5
4
```

`len()` 数的是**字符个数**。中文一个字算一个，所以 `"你好世界"` 是 4。这个函数以后天天用——比如判断"这段话是不是超过 token 预算了"的简化版。

## 第 4 步：切开（split）

`split("切刀")` 按指定的符号把文字切成**列表**（列表下节课细讲，现在只要认得方括号的样子）：

```python
s = "苹果,香蕉,橘子"
print(s.split(","))
```

输出：

```text
['苹果', '香蕉', '橘子']
```

读法：**"用逗号当刀，把 s 切开"**。切完得到 3 块。

## 第 5 步：粘回去（join）

join 是 split 的逆操作，但写法有点怪——**胶水写在前面**：

```python
words = ["苹果", "香蕉", "橘子"]
print("、".join(words))
```

输出：

```text
苹果、香蕉、橘子
```

读法：**"用顿号当胶水，把 words 粘成一段"**。`"胶水".join(一堆东西)`，这个怪格式背下来就行。

## 第 6 步：替换（replace）

```python
print("我有 1 个苹果".replace("1", "2"))
```

输出：

```text
我有 2 个苹果
```

`文字.replace("旧的", "新的")`：把所有"旧的"换成"新的"。

## 中文标点坑（每个新手必踩）

Python 只认**英文符号**。下面左边全对，右边全错：

| 能用的（英文） | 会报错的（中文） |
| --- | --- |
| `"你好"` | `“你好”`（弯引号） |
| `split(",")` | `split("，")` ← 想切英文逗号却打了中文逗号 |
| `print("a", "b")` | `print("a"，"b")` |

中文引号、中文逗号混进代码，报的是 `SyntaxError`，还很难看出来。**写代码时把输入法切成英文。** 遇到了去查 [[新手报错速查]]。

## 最关键的一句

> [!important]
> **f-string 最常用：`f"文字{变量}文字"`，引号前别忘 f。切用 split、粘用 join（胶水在前）、换用 replace。**

## 大白话翻译表

| 术语 | 大白话 |
| --- | --- |
| 字符串 str | 一段文字，加引号 |
| f-string | 挖洞填东西的文字模板，`{}` 是洞 |
| `len()` | 数字数，中文一个字算一个 |
| `split("刀")` | 按刀切开，得到一列（列表） |
| `"胶水".join(列表)` | 用胶水把一列粘成一段 |
| `replace("旧", "新")` | 旧的全部换成新的 |
| `SyntaxError` | 代码写得不合语法，常因中文标点 |
