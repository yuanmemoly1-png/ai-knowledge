# 小白课：DeepSeek Harness 一栋大楼（慢速版）

上一课：[[小白课-MCP万能插座]]

> [!note] 这节课学什么
> 前面几课你亲手搭过最小 Agent、玩过 MCP 插座——那都是"零件"。这节课把视角拉高，看一个**真实框架**是怎么把这些零件装成"一整栋会思考的大楼"的。
> 这栋楼叫 **DeepSeek Harness（DSH）**，就是"我"（你现在对话的这个 AI）脚下正在跑的那套脚手架。全程一个比喻用到底：**DSH 是一栋会思考的大楼**。

---

## 第 1 步：这栋楼是什么——套在大模型外面的"壳"

回忆 [[小白课-Agent传纸条循环]]：LLM 是关在房间里、只会接话的人，出不了门。你光有他，啥也干不了。

**DSH 就是给这个接话人盖的"楼"**：楼里有手脚（工具）、有手册（技能）、有门禁（沙箱/审批）、有循环电梯（Agent loop）。接话人住进来，就变成了会干活的 Agent。

> [!important] 一句话
> **模型是"大脑"，DSH 是"身体 + 家"。** 换个模型，还是这栋楼；换个预设（楼里的装修），手脚和性格就变了。

## 第 2 步：楼里的一切都是"插件"

走进这栋楼，你会发现**没有一样东西是焊死的**——台灯、电扇、充电器，全都是"插在插线板上的电器"：

- 会读文件的"手" = 一个插件
- 会查网页的"手" = 另一个插件
- 我的人设（"我是谁"）= 又一个插件
- 连"沙箱""审批"这种保安 = 也是插件

这根"插线板"叫 **Cordis**。它只干一件事：**把很多小插件接进同一个运行时，让它们互相借力、又不打架。**

> [!tip] 所以 DSH 的能力是"配"出来的，不是"写死"的
> 想给我加个"查天气"的能力？往配置文件里加一行插件。想关掉？删掉那行。**一行 = 一个能力。**

## 第 3 步：楼分两块——公共设施 vs 自家装修

楼里有两类东西，必须分清楚（这步最重要）：

| | 公共设施（HOST） | 自家装修（Preset） |
| --- | --- | --- |
| 比喻 | 水管、电梯、门禁 | 你家的沙发、墙纸 |
| 谁管 | 物业，全楼一份 | 每家自己买 |
| 举例 | 沙箱、审批、记忆仓库、模型选择 | 我的工具、我的技能、我的人设 |

**判断口诀：问一句"除了我，还有谁会用它？"** 别人也会用 → 公共设施(HOST)；只有我这户用 → 自家装修(Preset)。

> [!warning] 新手最常搞错的点
> "会**提供**服务"的东西，不能光溜溜地塞进自家装修——得放进一个叫 `isolate` 的"隔间"里，否则隔壁住户装修同名东西就会撞车。就像两户不能共用同一台电视，得各买各的、各放各屋。

## 第 4 步：开机——叠透明胶片

这栋楼是怎么"开机"的？不是一键变出来，而是**像叠透明胶片一样，一层层把配置叠上去**：

```text
 ┌─────────────────────────┐
 │ 5. 命令行临时改一下        │ ← 最高优先级
 ├─────────────────────────┤
 │ 4. 你的全局偏好            │
 ├─────────────────────────┤
 │ 3. 这个套餐的偏好           │
 ├─────────────────────────┤
 │ 2. 套餐自带的插件包         │
 ├─────────────────────────┤
 │ 1. 一张白纸               │
 └─────────────────────────┘
```

开机命令叫 `dsh`。它按一张"套餐清单"（叫 **profile**）把胶片叠好，然后 Cordis 逐个"点亮"插件——灯亮了、工具上线了、人设注入完毕——**一个 Agent 就出生了**。

> 一句话：**开机 = 叠胶片 + 点亮插件。** `dsh` 是总开关，profile 是电路图。

## 第 5 步：楼里的三种"家具"——手、手册、挂钩

住进来后，我在楼里用得到三种家具：

| 家具 | 术语 | 比喻 |
| --- | --- | --- |
| 手 | Tool（工具） | 我干活的手，模型说"读文件"就动手 |
| 手册 | Skill（技能） | 用时才翻的操作手册（比如"写组合前必读"） |
| 挂钩 | Slot（插槽） | 墙上预留的钩子，给网页界面挂按钮、面板 |

它们全是插件提供的——又回到第 2 步：**一切皆插件。**

## 第 6 步：边住边加房间——动态插件

最炫的一招：这栋楼**不用拆了重盖，就能临时加个房间**。这就是"动态插件"：

1. **define** 画图纸（存档，还没动工）
2. **run** 按图纸施工并通电
3. 不用了就 **stop**（断电，图纸还在）
4. 彻底不要才 **undefine**（拆房烧图纸）

改 bug 也不是推翻重来，而是"画张新图纸"（新版本），旧图纸留着随时回滚。

> [!tip] 但记住：这是"临时加盖"，不是日常装修
> 普通能力该写进配置文件（第 4 步的胶片），只有"运行中临时扩展"才用动态插件。

## 最关键的一句

> [!important]
> **DSH = 插线板(Cordis) + 一堆电器(插件) + 电路图(配置文件)。** 公共设施归物业(HOST)，自家装修归住户(Preset)；开机就是叠胶片、点亮插件；住进去，接话人就有了手脚、手册和门禁，变成能干活的 Agent。

## 检查一下

1. 为什么说"模型是大脑，DSH 是身体+家"？模型自己缺什么？
2. 楼里"会读文件的手"和"我的人设"有什么共同点？
3. 判断一个能力该放公共设施(HOST)还是自家装修(Preset)，口诀是什么？
4. 开机时，配置是按什么顺序叠起来的？哪层优先级最高？
5. define 和 run 的区别是什么？

<details>
<summary>点我看答案</summary>

1. 模型（LLM）只会"接话"，碰不到文件、网络、真实世界。DSH 提供了手脚（工具）、手册（技能）、门禁（沙箱/审批）和循环，让模型变成能干活的 Agent。
2. 它们都是"插件"——DSH 里一切能力都是插件，一行配置 = 一个能力。
3. 问"除了我，还有谁会用它？"别人也会用 → HOST；只有我这户用 → Preset。
4. 从"一张白纸"开始，依次叠：套餐插件包 → 套餐偏好 → 你的全局偏好 → 命令行临时覆盖。最上面（命令行）优先级最高。
5. define 只是画图纸存档、不运行；run 才是真正施工并通电。
</details>
