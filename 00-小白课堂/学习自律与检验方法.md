# 学习自律与检验方法（科学版，不靠意志力）

> [!note] 一句话
> 不自律不是性格缺陷，是**方法问题**：被动重读制造"学会了的错觉"，缺少检验就缺少反馈，缺少反馈就坚持不下去。解法 = 主动回忆 + 间隔重复 + 费曼检验 + 最小剂量，全部装进了 [[#🎓 费曼学检场|费曼学检场]]。

## 一、为什么你"学过 = 没学会"

| 假象 | 真相 |
| --- | --- |
| 刚看完笔记觉得"很清晰" | 短期记忆的熟悉感 ≠ 掌握（**能力的错觉**，illusion of competence） |
| 反复读例题觉得"我会了" | 处理流畅性骗了大脑——独立做题就卡壳 |
| 看教程时狂点头 | 邓宁-克鲁格效应：越新手越自信 |

**学习金字塔**（留存率）：听讲 5% < 阅读 10% < **讨论 50%** < **实践 75%** < **教别人 90%**。费曼学习法 = 直接用 90% 那一档。

## 二、四大科学武器

### 1. 主动回忆（Active Recall）—— 最强
合上资料，硬想。**提取的痛苦本身就在强化神经连接**（测试效应，testing effect）。实战三招：
- **Blurting 法**：合书 → 白纸默写所有记得的 → 对照补漏
- 闪卡：先说答案再翻面
- 做题：不看答案先做

### 2. 间隔重复（Spaced Repetition）—— 对抗遗忘曲线
学后 20 分钟忘 42%，1 天忘 74%，不复习 7 天只剩 23%。在**快忘掉的临界点**复习，一次顶十次：

```text
当天 → 第 1 天 → 第 3 天 → 第 7 天 → 第 15 天 → 第 30 天
（学检场自动按这个节奏排期，低分短间隔重来，高分拉长）
```

### 3. 费曼学习法 —— 检验理解的照妖镜
四步：①用自己的话讲给小白 ②找卡壳/讲漏的地方 ③回去重学 ④简化+打比方再讲。**讲不出来 = 没学会**，详见 [[费曼学习法]]。

### 4. 交叉练习（Interleaving）—— 防机械化
混着练（今天 RAG + 昨天 Agent + 前天 Python），比集中刷一个主题记得牢——学检场的"今日到期队列"天然就是混排的。

## 三、防不自律的机制（学检场怎么帮你）

| 痛点 | 机制 |
| --- | --- |
| 不知道今天学什么 | 打开就是"今日该做的"——到期复习自动排好，**零决策** |
| 完美主义拖着不开始 | **最小剂量**：再没时间，2 分钟做一次盲讲也算打卡（连击不断） |
| 没反馈坚持不下去 | XP / 等级 / 🔥连击 / 徽章（冒险岛同款，已验证有效） |
| 自我感觉良好 | 强制**合上原文盲讲**，错觉当场戳破 |
| 学完就忘 | 间隔重复队列自动追着你复习 |

> [!tip] 习惯叠加
> 把学检场挂在 [[每日学习清单]] 的 **③ 费曼复述 5 分钟** 那一格——学完当日内容顺手开一次检验，一个动作两件事。卡 20 分钟就停（不算学习算内耗，见 [[零基础防卡指南]]）。

## 四、每日最小流程（保底版）

```text
1. 打开学检场（双击 feynman/index.html）
2. 做"今日到期"里 1 篇复习（没有就发起一次新检验）
3. 四步走完（盲讲 → 找差 → 简讲 → 出关自评）
4. 完事。连击 +1，明天见
```
