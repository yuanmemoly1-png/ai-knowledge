# 小白课：全栈 HTML 第一页（你的第一个网页）

上一课：[[小白课-实战RAG迷你版]]

> [!note] 这节课学什么
> 从这节课开始进入**全栈篇**：亲手做一个能在浏览器里打开的网页。
> 按 5 步走：新建 `hello.html` → 写上网页骨架 → 逐个加标题、段落、按钮、输入框 → 双击用浏览器打开 → 改字刷新看变化。
> 不用装任何东西，记事本就能写，跟着做完你就有人生中第一个网页。

---

## 第 0 步：先搞懂 HTML 是个啥

HTML 就是**网页的骨架**。你在浏览器里看到的每个网页，底下都是一个 `.html` 文件，里面写着"这里有个标题""这里有个按钮"。

大白话：**HTML 是写给浏览器看的说明书**，浏览器照着它把页面画出来。详见 [[小白课-前端与后端]]。

## 第 1 步：新建 hello.html

1. 在桌面（或任意文件夹）右键 → **新建 → 文本文档**
2. 把文件名改成 `hello.html`——**连后缀一起改**，从 `.txt` 改成 `.html`
3. Windows 会弹窗问"确定要更改扩展名吗"，点**是**

> [!warning] 看不到 .txt 后缀怎么办
> 打开文件夹，点顶部菜单 **查看 → 显示 → 文件扩展名**，勾上。不勾的话你改完可能变成 `hello.html.txt`，那就白改了。

有 VS Code 的话更方便：右键文件 → **打开方式 → VS Code**，它会帮你给代码上色。

## 第 2 步：写上网页骨架

用记事本或 VS Code 打开 `hello.html`，整段复制进去，保存（`Ctrl + S`）：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>我的第一个网页</title>
</head>
<body>
    <h1>你好，世界！</h1>
    <p>这是我亲手写的第一个网页。</p>
</body>
</html>
```

拆开看（不用背，混个眼熟）：

- `<!DOCTYPE html>` —— 告诉浏览器："这是现代网页，按新标准来"
- `<html>` —— 整个网页的最外层大盒子
- `<head>` —— 网页的"档案袋"：编码、标题这些**不显示在页面上**的信息
- `<meta charset="UTF-8">` —— 让中文不乱码，**照抄就行**
- `<title>` —— 浏览器**标签页上**显示的名字
- `<body>` —— 页面上**看得见的东西**都写在这里

## 第 3 步：双击打开，你会看到什么

回到文件夹，**双击 `hello.html`**，它会用默认浏览器打开。

✅ 看到这个就对了：

- 浏览器**标签页**上写着"我的第一个网页"
- 页面左上角有一行**大大的粗体字**："你好，世界！"
- 它下面一行小字："这是我亲手写的第一个网页。"
- 地址栏显示的是 `file:///C:/Users/.../hello.html`——这是**本地文件**，不是网址，只有你能看到

> [!warning] 双击后中文变成乱码
> 检查第 2 步的 `<meta charset="UTF-8">` 有没有照抄。还不行就是记事本保存时编码不对：记事本里 **文件 → 另存为**，底部"编码"选 **UTF-8**，覆盖保存。

## 第 4 步：逐个加零件

在 `<body>` 里、`</body>` 之前，加上这几行（加完保存）：

```html
    <h2>下面是一个按钮</h2>
    <button>点我</button>
    <h2>下面是一个输入框</h2>
    <input type="text" placeholder="在这里输入你的名字">
```

保存后**回到浏览器按 `F5` 刷新**。

✅ 看到这个就对了：原来两行字下面，多出一个能点的按钮和一个能打字的白框框。

几个常用零件，以后天天见：

| 标签 | 大白话 |
| --- | --- |
| `<h1>` ~ `<h2>` | 大标题、小标题 |
| `<p>` | 一段话 |
| `<button>` | 按钮（现在点了没反应，下下节课让它动起来） |
| `<input>` | 输入框，`placeholder` 是灰色的提示字 |

规律看出来了没：**每个零件都是 `<标签>内容</标签>`，一对尖括号包住内容**。

## 第 5 步：改字刷新看变化

这才是学网页的正确姿势——**瞎改**：

1. 把 `<h1>你好，世界！</h1>` 里的字改成你的名字，保存，`F5` 刷新 → 大字变了
2. 把 `<title>` 里的字改掉，刷新 → 浏览器标签页的名字变了
3. 把按钮上的"点我"改成"别点我"，刷新 → 按钮上的字变了

> [!important] 改代码 → 保存 → 浏览器刷新，这三连以后要做一万遍，今天就养成肌肉记忆。

## 报错救援表

| 情况 | 原因 | 解法 |
| --- | --- | --- |
| 双击打开是记事本不是浏览器 | 系统把 `.html` 关联错了 | 右键文件 → 打开方式 → 选浏览器 |
| 页面全是英文尖括号原文 | 文件其实还是 `.txt` | 开"文件扩展名"显示，确认名字是 `hello.html` |
| 中文乱码 | 编码不对 | 检查 `<meta charset="UTF-8">`；另存为时选 UTF-8 |
| 改了代码页面没变化 | 没保存或没刷新 | `Ctrl + S` 保存，回浏览器 `F5` |

更多排查套路见 [[新手报错速查]]。

## 最关键的一句

> [!important]
> **HTML 是写给浏览器的说明书：`<标签>内容</标签>` 一个零件，`body` 里放看得见的，改完"保存 + F5"就能看效果。**

## 大白话翻译表

| 术语 | 大白话 |
| --- | --- |
| HTML | 网页的骨架 / 说明书，详见 [[HTML与CSS入门]] |
| 标签（tag） | 一个零件的名字，如 `<button>` |
| `<head>` | 档案袋，装不显示的信息 |
| `<body>` | 舞台，看得见的东西都在这 |
| 浏览器 | 看说明书画页面的工人 |

## 检查一下

1. 网页上看得见的内容写在哪个标签里？
2. 为什么文件改名叫 `hello.html.txt` 就不行？
3. 改了代码之后浏览器里没变化，最可能忘了哪两步？
4. `<meta charset="UTF-8">` 是干嘛的？

<details>
<summary>点我看答案</summary>

1. `<body>` 里。
2. 它其实还是文本文件，浏览器不会当网页打开。开"文件扩展名"显示，把 `.txt` 去掉。
3. 忘了保存（`Ctrl + S`）或忘了刷新（`F5`）。
4. 告诉浏览器用 UTF-8 解码，防止中文乱码。
</details>
