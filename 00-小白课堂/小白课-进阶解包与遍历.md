# 小白课：进阶解包与遍历（慢速版）

上一课：[[小白课-进阶推导式]]

> [!note] 这节课学什么
> 你在字典那节课写循环时，可能别扭过：`for name in scores:` 拿到的只有**名字**，想拿分数还得再写 `scores[name]`。这节课的 `.items()` 就是这个困惑的**终极答案**——循环时名字和分数**一次都给你**。
>
> 核心概念叫**解包**：一个变量名装不下，就用一排变量名同时接。达标线：看到 `a, b = b, a`、`for k, v in d.items():`、`for i, x in enumerate(...)` 能说出它在干嘛。

---

## 第一部分：解包——一排变量同时接东西

### 第 1 步：一次装两个变量

```python
a, b = 1, 2
print(a, b)
```

输出：

```text
1 2
```

右边 2 个东西，左边 2 个变量，**按位置一一对应**：`a` 拿 1，`b` 拿 2。这就是解包——把一包东西拆开，分发给一排变量。

### 第 2 步：招牌操作——一行交换两个变量

```python
a, b = b, a
print(a, b)
```

输出：

```text
2 1
```

别的语言交换两个变量要绕好几步，Python 一行搞定：右边先把 `b, a` 打包成 (2, 1)，再拆开装回 `a, b`。见到 `a, b = b, a` 就认识：**这行在交换两个变量的值**。

### 第 3 步：用 `*` 接剩下的（见到认识即可）

```python
first, *rest = [10, 20, 30, 40]
print(first)
print(rest)
```

输出：

```text
10
[20, 30, 40]
```

`first` 拿第一个，带 `*` 的 `rest` 把**剩下的全部**接住（装进一个列表）。看到变量名前的 `*`，知道是"剩下的都归它"就够。

## 第二部分：字典遍历的终极答案 `.items()`

### 第 1 步：回忆一下"别扭版"

```python
scores = {"语文": 90, "数学": 85}

for name in scores:
    print(name)
```

输出：

```text
语文
数学
```

直接循环字典，**拿到的只有名字（键）**。想连分数一起打印，得在循环里再取一次：

```python
for name in scores:
    print(name, scores[name])    # 用名字再查一次分数
```

输出：

```text
语文 90
数学 85
```

能跑，但啰嗦。之前的"取货单"困惑就卡在这：循环给你的是货单上的名字，货还得自己再跑一趟去取。

### 第 2 步：`.items()`——名字和分数一起给

```python
for name, score in scores.items():
    print(name, score)
```

输出：

```text
语文 90
数学 85
```

结果一样，但不用"再跑一趟"。`scores.items()` 每圈递给你**一小包**（名字, 分数），`name, score =` 顺手解包——**这正是第一部分学的解包**。

> [!important] 以后字典循环就这么写
> `for 名, 值 in 字典.items():` 是字典循环的标准写法。看到它直接读成：**"把字典里每格的'名字'和'内容'一起拿出来，挨个处理"**。

## 第三部分：enumerate——循环时顺便拿号码

循环列表时想要"第几个 + 内容"两个信息，用 `enumerate`：

```python
fruits = ["苹果", "香蕉", "橘子"]

for i, f in enumerate(fruits):
    print(i, f)
```

输出：

```text
0 苹果
1 香蕉
2 橘子
```

`enumerate(fruits)` 每圈递给你一小包（号码, 内容），又是解包接住。看到 `for i, x in enumerate(列表):` 读成：**"挨个来，顺便告诉我这是第几个"**（号码还是从 0 开始）。

## 最关键的一句

> [!important]
> **解包 = 一排变量按位置接一包东西；`for k, v in d.items():` 字典名字内容一起拿；`for i, x in enumerate(列表):` 号码内容一起拿。**

## 大白话翻译表

| 术语 | 大白话 |
| --- | --- |
| 解包 unpack | 一包东西拆开，一排变量按位置分 |
| `a, b = b, a` | 交换两个变量的值 |
| `*rest` | 带星的变量接住"剩下的全部" |
| `d.items()` | 字典每格的"名字+内容"一起递给你 |
| `enumerate(列表)` | 循环时顺便发号码（从 0 开始） |

## 检查一下

1. `x, y = 10, 20` 之后，`x, y = y, x` 之后，`x` 是几？
2. `for k, v in {"a": 1}.items():` 这一圈里，`k` 和 `v` 分别是什么？
3. 只写 `for k in 字典:`，循环里能直接拿到"内容"吗？
4. `for i, x in enumerate(["甲", "乙"]):` 第一圈 `i` 和 `x` 各是什么？

<details>
<summary>点我看答案</summary>

1. 20（交换了）。
2. `k` 是 `"a"`（名字），`v` 是 `1`（内容）。
3. 不能，拿到的只有名字；要内容得再写 `字典[k]`，或者改用 `.items()`。
4. `i` 是 0，`x` 是 `"甲"`。
</details>
