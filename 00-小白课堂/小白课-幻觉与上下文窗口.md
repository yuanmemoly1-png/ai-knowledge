# 小白课：幻觉与上下文窗口（慢速版）

上一课：[[小白课-RAG开卷考试]]

> [!note] 这节课学什么
> 这节课讲接话人的**两个"生理极限"**——改不掉，只能防：
> - **幻觉**：不懂的问题也硬接，还接得理直气壮
> - **上下文窗口**：他的桌面只有那么大，旧纸条会被挤掉
>
> 两个极限分开慢拆，各讲对策，最后给"怎么验证 AI 说的话"的实操三招。

---

## 第一部分：幻觉

### 第 1 步：幻觉是什么

一句大白话定义：**幻觉 = 模型编造不存在的事实，且语气自信、格式专业，看不出是假的。**

典型场面：

- 让它推荐论文 → 编出标题、作者、期刊齐全但**不存在**的论文
- 让它引用法律条文 → 编出一个条款号，查无此条
- 问它一本不存在的书 → 面不改色给你写内容简介

### 第 2 步：为什么会幻觉

这在前几课已经埋了伏笔，串一遍：

1. 他只会**接话**——天性是"接出最像样的一句"，不是"说出最真实的一句"
2. 他**不是搜索引擎**——没有"查证"这个动作
3. 训练时**流畅自信的回答更容易得高分**——老实说"我不知道"反而不被奖励

三条一叠加：**幻觉不是 bug，是天性。**没有任何一个模型能根治它，只有"轻一点"和"重一点"。

### 第 3 步：幻觉的对策

| 对策 | 做法 | 效果 |
| --- | --- | --- |
| 开卷考试 | 用 RAG 把资料递给他，要求"只根据资料答"（[[小白课-RAG开卷考试]]） | 大幅减轻 |
| 追问来源 | 问"出处是哪里？给我链接"，再给链接去核实 | 逼出部分编造 |
| 自己核实 | 重要信息（法律、医疗、金额）**一律人工查原文** | 最后防线 |

## 第二部分：上下文窗口

### 第 1 步：窗口是什么

一句大白话定义：**上下文窗口 = 他一次性能看到的纸条总量，超出就"看不见"了。**

回忆 [[小白课-Token与计费]]：每轮对话要把全部历史重发。这个"全部"有上限——窗口就是上限，按 token 算。各模型不同：几万到一百万 token 不等。

### 第 2 步：纸条是怎么被挤掉的（真跑一遍）

模拟一张只能放 4 张纸条的桌面：

```python
桌面 = []
上限 = 4
for i in range(1, 7):
    桌面.append(f"第{i}句话")
    if len(桌面) > 上限:
        掉 = 桌面.pop(0)
        print(f"桌面满了，『{掉}』被挤掉了")
    print("桌面上现在：", 桌面)
```

输出：

```text
桌面上现在： ['第1句话']
桌面上现在： ['第1句话', '第2句话']
桌面上现在： ['第1句话', '第2句话', '第3句话']
桌面上现在： ['第1句话', '第2句话', '第3句话', '第4句话']
桌面满了，『第1句话』被挤掉了
桌面上现在： ['第2句话', '第3句话', '第4句话', '第5句话']
桌面满了，『第2句话』被挤掉了
桌面上现在： ['第3句话', '第4句话', '第5句话', '第6句话']
```

看最后两行：**最早的纸条先掉**。这就是长聊天里他"忘了你开头说的话"的真相——不是忘了，是那张纸条根本不在桌上了。

> [!warning] 容易误会的点
> 窗口超限的表现**不是报错，而是"安静地忘记"**。程序不会提醒你"第 1 句话掉了"，他也不会说"我看不见开头了"——他会对看不见的内容**照常接话**（幻觉+1）。长聊天越到后面越要警惕。

### 第 3 步：窗口的对策

- **该开新窗口就开**：一个话题聊完就重开，顺便省 token
- **重要的话重复说**：关键要求（格式、身份、约束）在长对话里**再发一遍**
- **让他做小结**：聊很长时，先让他"总结目前的结论"，带着小结开新窗口
- **塞资料用 RAG**：别把整本书粘进对话框，用上一课的查书法只递相关几页

## 两个极限对照表

| | 幻觉 | 上下文窗口 |
| --- | --- | --- |
| 一句话 | 不懂也敢编 | 超了就忘 |
| 根子 | 只会接话 + 训练奖励自信 | 桌面（窗口）大小有限 |
| 表现 | 编造事实，理直气壮 | 安静地忘记开头 |
| 对策 | RAG、要来源、勤核实 | 开新窗口、重要的话重发 |

## 第三部分：如何验证 AI 说的话（实操三招）

两个极限讲完，落到日常习惯：

1. **要来源**："这个结论的出处是什么？给我原始链接/文件。"——给不出具体出处的，按幻觉处理
2. **交叉问**：把同一个问题换个问法再问一遍（或换个模型问），答案打架就有问题
3. **小事实验，大事查原文**：代码类让他写完**自己跑一遍**（对错立刻见分晓）；事实类**只信官方文档/原文**

> [!tip] 一句口诀
> **AI 说的代码，跑一遍；AI 说的事实，查一遍。**

## 最关键的一句

> [!important]
> **幻觉是"不懂也敢编"，窗口是"超了就忘"——都改不掉；对策是：给资料、要来源、勤核实，长对话记得开新窗口。**

## 检查一下

1. 为什么说幻觉是"天性"而不是 bug？
2. 窗口超限时会发生什么？程序会报错提醒你吗？
3. 长聊天里你开头定的重要规矩"失效"了，可能是什么原因？
4. 验证 AI 回答的三招分别是什么？

<details>
<summary>点我看答案</summary>

1. 因为他的本质是"接最像样的话"，且训练奖励流畅自信的回答——编得自信正是被训练出来的。
2. 最早的对话内容被挤出窗口，他"看不见"了；不会报错，是安静地忘记。
3. 那段规矩被挤出了上下文窗口。对策：重新发一遍，或开新窗口。
4. 要来源（给不出按幻觉处理）、交叉问（换问法/换模型对比）、代码跑一遍、事实查原文。
</details>
