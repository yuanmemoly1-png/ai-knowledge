# 小白课：进阶切片（慢速版）

上一课：[[小白课-程序拆解实战]]

> [!note] 这节课学什么
> 你已经会用 `fruits[0]` 取列表里的**一个**格子。但 AI 写的代码里经常一次取**一段**——比如"取前 3 条消息""倒着看整个列表"。这就是**切片**，写法是 `s[开始:结束]`。
>
> 达标线：**看到 `s[1:3]`、`s[::-1]` 这种写法，能说出它切了哪一段**。不要求背，会读就行。每一步都有真实输出，跟着敲。

---

## 第一部分：最基本的切片

### 第 1 步：取一段 `s[开始:结束]`

```python
scores = [90, 45, 78, 55, 88]
#         0号  1号  2号  3号  4号

print(scores[1:3])
```

输出：

```text
[45, 78]
```

`[1:3]` 的意思是：**从 1 号开始拿，拿到 3 号为止——但 3 号自己不要**。所以拿到的是 1 号和 2 号，共 2 格。

> [!important] 到尾不含尾
> 切片最重要的规则：**开始算数，结束不算数**（"到尾不含尾"）。所以 `s[1:3]` 有 2 格，`s[0:4]` 有 4 格。个数 = 结束 − 开始，不用数。

### 第 2 步：偷懒写法——头尾可以不写

```python
print(scores[:3])    # 开头不写 = 从 0 号开始
print(scores[2:])    # 结尾不写 = 一直拿到最后
```

输出：

```text
[90, 45, 78]
[78, 55, 88]
```

`[:3]` 就是"前 3 个"，`[2:]` 就是"从 2 号到结尾"。AI 代码里"取前几条聊天记录"基本就长这样。

### 第 3 步：负数——从尾巴往回数

号码写负数表示倒数，切片一样能用：

```python
print(scores[-2:])    # 最后 2 个
```

输出：

```text
[55, 88]
```

---

## 第二部分：字符串也能切

字符串就是"一排字"，切片规则**一模一样**：

```python
word = "hello"

print(word[0:3])
print(word[1:])
```

输出：

```text
hel
ello
```

没有新东西要学——**凡是"一排东西"（列表、字符串），切片规则通用**。

## 第三部分：第三个数字是"步子" `s[::2]`

切片其实有三个空位：`s[开始:结束:步长]`。步长默认是 1（挨个拿），写成 2 就是隔一个拿一个：

```python
print(scores[::2])    # 从头到尾，隔一个拿一个
```

输出：

```text
[90, 78, 88]
```

拿到了 0 号、2 号、4 号。

### 最出名的写法：`[::-1]` 反转

步长写成 **-1**，意思是"从尾往头走"——整个东西倒过来：

```python
print(scores[::-1])
print(word[::-1])
```

输出：

```text
[88, 55, 78, 45, 90]
olleh
```

`[::-1]` 是 Python 里"反转"的招牌写法，见到就认识：**开始结束都空着（整个都要），步长 -1（倒着走）**。

## 最关键的一句

> [!important]
> **`s[开始:结束:步长]`：开始算数、结束不算数、步长默认 1；`[:3]` 取前 3 个，`[-2:]` 取最后 2 个，`[::-1]` 整个倒过来。**

## 大白话翻译表

| 术语 | 大白话 |
| --- | --- |
| 切片 slice | 从一排东西里剪一段出来 |
| `s[1:3]` | 从 1 号拿到 3 号前（不含 3 号） |
| `s[:3]` | 前 3 个 |
| `s[2:]` | 从 2 号到结尾 |
| `s[-2:]` | 最后 2 个 |
| 步长 step | 每隔几个拿一个，默认 1 |
| `s[::-1]` | 倒着拿，等于反转 |

## 检查一下

1. `a = [10, 20, 30, 40, 50]`，`a[1:4]` 是哪些数？共几格？
2. 想用切片取 `a` 的前 2 个，怎么写？
3. `a[-1:]` 会得到什么？
4. `"abcdef"[::-1]` 输出什么？

<details>
<summary>点我看答案</summary>

1. `[20, 30, 40]`，共 3 格（4 − 1 = 3，结束 4 号不算）。
2. `a[:2]`。
3. `[50]`——从最后一个拿到结尾，就这一格。
4. `"fedcba"`，整个字符串倒过来。
