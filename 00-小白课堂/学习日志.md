3. `AttributeError`：`sprit` → `split` 拼写
4. `NameError`：`name=程程` 文字忘穿引号外套
5. `TypeError: 'list' object is not callable`：`print` 被当成变量名覆盖了内置功能 → `del print` 恢复；内置名不占用
6. `SyntaxError: expected ':'`（新解锁）：if 行尾漏冒号；且 `count=count+1` 要和 if 保持从属缩进
7. 中文逗号 `，` vs 英文 `,`：split 剪不开 → 写代码切英文输入法

### 晚间追加（函数专题）

**疑问点**

| 疑问 | 通关答案（一句话） |
| --- | --- |
| `result` 和 `add` 为啥轮流出现 | add 是干活的（函数），result 是装成果的盒子；存不存取决于"以后还用不用" |
| 为什么要存变量 | 结果要用多次/结果很"贵"（如调 API）就存；只用一次可不存 |
| `def` 老想不起来 | def = 教电脑一句新口令：括号里起名、收料，里面用名 |
| `return` vs `print` | print 喊一嗓子（没了），return 递出能接住的结果；忘 return 得到 None |
| 参数怎么引用 | def 括号里起什么名，函数里就用什么名；调用时按位置装入 |

**踩坑（新解锁 2 种报错）**

8. `SyntaxError: expected ':'`：if 行尾漏冒号；`count=count+1` 要比 if 多缩进 4 格（从属关系）
9. `SyntaxError: invalid syntax`：字典写成圆括号 `()` → 字典用花括号 `{}`
10. `RecursionError` ⭐：`is_pass` 里误写 `is_pass(score)`，函数自己喊自己约 1000 次被掐断 → 参数 score 直接用，不用再喊函数
