# 小白课：LLM 大语言模型（慢速版）

上一课：无（这是 AI 名词篇第一节，从这里开始就好；Python 篇见 [[小白课堂总览]]）

> [!note] 这节课学什么
> ChatGPT、Kimi、豆包的背后都是同一个东西：**LLM（大语言模型）**。这节课不背定义，只搞清楚四件事：
> - 他**只会接话**——这是他唯一的本领
> - 他**不是搜索引擎**——答案不是查来的，是现场编的
> - 他**没有记忆**——聊完就忘
> - 他会**一本正经说错话**——这叫幻觉
>
> 全篇只用一个比喻：一个被关在房间里、读过全世界的书、**只会从门缝递纸条接话的人**。

---

## 第 1 步：他只会"接话"

一句大白话定义：**LLM 就是一台"接下半句"的机器**。你给他上半句，他算出"最像样"的下半句，一个 token 一个 token 地往外蹦。

先看一个玩具版演示，感受"接话"是怎么回事：

```python
接话表 = {"白日依山": "尽", "今天天气": "不错", "1 + 1 =": " 2"}
print("白日依山" + 接话表["白日依山"])
print("1 + 1 =" + 接话表["1 + 1 ="])
```

输出：

```text
白日依山尽
1 + 1 = 2
```

真正的 LLM 干的就是这件事，只是他的"接话表"不是 3 行，而是读完全世界的书之后练出来的、有上千亿个开关（叫**参数**）的超级大表。你写"白日依山"，他算出下一个字最可能是"尽"——不是他背了这首诗，是"尽"出现在这里的概率最高。

这里出现两个以后天天见的词：

- **训练（training）**：出厂前读书练接话的过程，一次烧掉几千万美元、几个月时间
- **推理（inference）**：你递纸条、他现场接话的过程——**你平时用 AI，全是在推理**

记住一个推论：你用他的时候，他**一个字都没在学**。和他说一万句"你记住了吗"，他本人也不会变聪明——所以"教他新东西"得靠别的招（后面的 [[小白课-RAG开卷考试]] 和 [[小白课-微调Fine-tuning]]）。

> [!important] 为什么要先懂这个？
> 因为他的**所有本事和所有毛病，都是从"接话"这一个动作里长出来的**。后面三步讲的"不是搜索引擎、没有记忆、会幻觉"，全是"只会接话"的副作用。

## 第 2 步：他不是搜索引擎

这是新手最大的误会，单独用一步拆。

| | 搜索引擎 | LLM |
| --- | --- | --- |
| 干活方式 | 去索引里**找到原文**，把链接给你 | **现场编**一句最像样的话 |
| 答案来源 | 网页原文，有据可查 | 没有"来源"这一说 |
| 找不到时 | 老实说"没有结果" | 照样给你编一个（见第 4 步） |

为什么需要分清这个？因为**搜索引擎的答案可以溯源，LLM 的答案不能**。他答得越流畅，越容易让你以为"他查过资料了"——其实他一个网页都没打开过。

> [!warning] 容易误会的点
> "他答得这么顺、这么专业，肯定是真的吧？"——错。**流畅度只说明这句话"像人话"，不说明它"是事实"**。这个坑第 4 步接着讲。

## 第 3 步：他没有记忆

一句大白话：**LLM 本人记性为零**。每次你发一句话，他看到的是"到目前为止的全部聊天记录"，回答完，转头就忘。

那你明明感觉他"记得"你三句话前说的名字，怎么回事？因为每次对话，程序都**把整叠旧纸条重新塞给他**——不是他记得，是你（的程序）每轮都在帮他"复习"。

两个能立刻验证的事实：

1. 在同一个聊天窗口里叫他记住你的名字 → 后面问他，他答得上来（因为记录还在）
2. **新开一个聊天窗口**再问 → 他完全不认识你（旧纸条没塞进来）

> [!warning] 容易误会的点
> 别在聊天里"托付"重要信息："记住我的订单号啊！"——他只在这个窗口、这段对话里"记得"。换个窗口就没了。真要让 AI 长期记事，得靠外部手段，这是 [[小白课-Agent记忆]] 要解决的问题。

## 第 4 步：他会一本正经说错话（幻觉引子）

把前三步合起来，结论就浮出来了：

- 他只会接话 → 遇到不懂的问题，**也照接**
- 他不是搜索引擎 → 接出来的话**没有出处**
- 他接话的标准是"像样" → 编出来的错话也**自信又流畅**

你问他"《三体》作者刘慈欣的《银河往事》讲了什么？"（这本书不存在），他很可能面不改色地给你编一段内容简介。这种现象有个专门的名字——**幻觉（Hallucination）**。

> [!warning] 这节课先记住结论，别记解法
> 幻觉不是 bug，是"接话机"的天性，**没法彻底修好，只能防**。怎么防（开卷考试 RAG、自己核实）是 [[小白课-RAG开卷考试]] 和 [[小白课-幻觉与上下文窗口]] 的内容，现在只要记住：**重要的事，别只听他一面之词。**

## 第 5 步：他能做什么、不能做什么（一分钟边界）

四步讲完，收个尾。把他当成一个"超级会接话、但没记忆、会瞎编的实习生"来用：

**放心交给他的：**

- 写初稿：邮件、文案、代码草稿（你再改）
- 解释概念："用小学生能懂的话讲讲 XX"
- 转换格式：表格转 JSON、中文译英文
- 陪你 brainstorm：列 10 个点子你自己挑

**别直接交给他的：**

- 需要 100% 准确的事实（会幻觉，先核实）
- 需要长期记住你的事（没有记忆）
- 你的私有资料、最新资讯（他不知道，得靠 [[小白课-RAG开卷考试]]）

这张清单比背任何定义都有用——遇到一个新需求，先对照它在左列还是右列。

## 最关键的一句

> [!important]
> **LLM 是一台只会接下半句的机器：答案是编出来的不是查出来的，聊完就忘，不懂也敢答。**

## 大白话翻译表

| 术语 | 大白话 |
| --- | --- |
| LLM 大语言模型 | 读过全世界的书、只会接下半句的机器 |
| 参数 parameter | 接话机里的开关数量，越多越会接 |
| 训练 training | 出厂前读书练接话的过程 |
| 推理 inference | 你递纸条、他现场接话的过程 |
| 幻觉 hallucination | 不懂也硬接，还接得理直气壮 |
