# 小白课：实战 RAG 迷你版（不用向量库）

上一课：[[小白课-实战最小Agent]]

> [!note] 这节课学什么
> RAG 听起来高大上，其实你在 [[小白课-RAG开卷考试]] 里已经懂了：**先翻书，再答题**。
> 这节课用纯 Python 写一个迷你 RAG：**资料切段 → 关键词找出相关段 → 拼进 prompt 让 AI 只根据资料回答**。
> 不用向量数据库、不用新库，检索部分不需要 Key 就能跑（已真实运行验证）；最后问 AI 那步**需替换你的 Key 后运行**。

---

## 第 1 步：为什么需要 RAG

直接问 AI"我们公司请假流程是什么"，它要么瞎编（幻觉），要么说不知道——它没见过你公司的规章。

RAG 的思路：**你先把相关规章翻出来，和问题一起塞给它，命令它"只根据这些资料回答"**。AI 从"闭卷瞎编"变"开卷照抄"。

## 第 2 步：资料切段（split 就够了）

假设有一篇公司规章，用空行分成了 4 段：

```python
doc = """考勤制度：上班时间为早上9点，迟到30分钟以内算迟到，扣半天工资。

请假流程：请假需提前一天在OA系统提交申请，由直属主管审批。

报销规定：出差打车费实报实销，需保留发票，每月25日前提交报销单。

年假规则：入职满一年可享5天年假，满三年可享10天年假。"""

paragraphs = doc.split("\n\n")
print("切成了", len(paragraphs), "段")
```

✅ 看到这个就对了（已真实运行验证）：

```text
切成了 4 段
```

真实项目里这段文字可以从文件读进来——就是你学过的 `with open(...)`。

## 第 3 步：关键词检索——哪段和问题最像

不用向量库，用一个傻子办法：**数问题和每段有多少个相同的字**，相同越多越相关（用到了你学过的推导式和 sort）：

```python
def search(question, paragraphs, top_k=2):
    scored = []
    for p in paragraphs:
        score = sum(1 for char in question if char in p)
        scored.append((score, p))
    scored.sort(key=lambda x: x[0], reverse=True)
    return [p for score, p in scored[:top_k] if score > 0]
```

拆开看：

1. `sum(1 for char in question if char in p)` —— 问题里每个字，在这段出现过就加 1 分
2. `scored.sort(..., reverse=True)` —— 按分数从高到低排队
3. `[:top_k]` —— 只留最相关的 2 段；`if score > 0` —— 一分没有的不要

试一下（已真实运行验证）：

```text
问题：我想请假，怎么操作？
检索到的相关段落：
  - 请假流程：请假需提前一天在OA系统提 ...
  - 年假规则：入职满一年可享5天年假，满 ...
```

✅ 看到这个就对了："请假"两个字把请假段顶到了第一名。

## 第 4 步：拼 prompt——"只根据资料回答"

检索到的段落 + 死命令 + 问题，拼成一大段发给 AI：

```python
question = "我想请假，怎么操作？"
hits = search(question, paragraphs)
context = "\n".join(hits)
prompt = f"请只根据下面的资料回答问题，资料里没有的就说不知道。\n\n【资料】\n{context}\n\n【问题】{question}"

messages = [{"role": "user", "content": prompt}]
answer = client.chat.completions.create(
    model="deepseek-chat", messages=messages).choices[0].message.content
print("AI 回答：", answer)
```

✅ 看到这个就对了（本流程已用假模型真实运行验证）：

```text
AI 回答： 根据资料：请假需要提前一天在OA系统提交申请，由直属主管审批。
```

再试一个资料里没有的问题"公司团建去哪玩？"——一段都检索不到，资料是空的，AI 乖乖说"资料里没有提到这个，我不知道"。**这就是 RAG 治幻觉的原理：没资料就不许编。**

## 第 5 步：这就是 RAG 的骨架

回头看，你刚写的就是 RAG 的三大件：

| 三大件 | 本课的傻办法 | 真实项目的聪明办法 |
| --- | --- | --- |
| 切分 | `split("\n\n")` | 按语义、按长度精细切块 |
| 检索 | 数相同的字 | 向量库算语义相似度（见 [[小白课-Embedding语义坐标]]） |
| 生成 | 拼 prompt 下死命令 | 一样，就是拼 prompt |

> [!important] 向量库只是更聪明的查法
> "数相同的字"找不到同义词（问"休假"就找不到"年假"段）。向量库解决的就是这个问题——但**骨架一模一样**：切 → 查 → 拼。学完本课，你已经懂了 RAG 的 80%，详见 [[RAG检索增强生成]]。

## 最关键的一句

> [!important]
> **RAG = 切分段落 → 检索相关段 → 拼进 prompt 命令"只根据资料回答"；向量库只是把"检索"这步从数字换成语义匹配，骨架不变。**

## 大白话翻译表

| 术语 | 大白话 |
| --- | --- |
| RAG | 开卷考试：先翻资料再答题 |
| 切分 chunk | 把长资料切成小段 |
| 检索 retrieval | 找出和问题最相关的几段 |
| 向量库 | 按"意思像不像"查资料的聪明工具 |
| `top_k` | 只留分数最高的 k 段 |
| 幻觉 | AI 没资料还瞎编，RAG 专治它 |

## 检查一下

1. 迷你 RAG 里，`search` 函数靠什么判断一段文字和问题相关？
2. 为什么要在 prompt 里写"资料里没有的就说不知道"？
3. 问"休假怎么申请"，数字的傻办法可能找不到"年假"段，真实项目用什么解决？
4. RAG 的三大件是什么？

<details>
<summary>点我看答案</summary>

1. 数问题和段落有多少个相同的字，相同越多分越高。
2. 防止幻觉——资料里没有就明说，而不是凭印象瞎编。
3. 向量库（语义检索）：把文字变成"语义坐标"，意思相近就能找到，不要求字面相同。
4. 切分 → 检索 → 生成（拼 prompt 让 AI 只根据资料回答）。
