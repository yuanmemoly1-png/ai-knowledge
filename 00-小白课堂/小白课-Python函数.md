# 小白课：Python 函数（慢速版）

上一课：[[小白课-Python条件与循环]]

> [!note] 这节课学什么
> 你已经会写一行行往下跑的代码了。但代码多了会发现：同一段逻辑要复制粘贴好几次。函数就是**把一段代码打包起个名字，想用就喊名字**。
> 这节课按 5 步走：最小的函数 → 参数 → return → 默认参数 → 完整调用。每一步都跟前面学过的积木一样简单。

---

## 第 1 步：最小的函数（def）

```python
def say_hi():
    print("你好呀")

say_hi()
say_hi()
```

输出：

```text
你好呀
你好呀
```

拆开看：

1. `def say_hi():` —— **定义**一个函数：`def` + 名字 + `()` + 冒号
2. 下面缩进 4 格的行，是这个函数**打包的内容**（规则和老朋友 if、for 一模一样）
3. `say_hi()` —— **调用**：喊名字就执行一遍里面的内容。喊两次，跑两遍

> [!warning] 定义了不等于会跑
> 只写 `def` 那几行，程序**什么都不输出**。定义只是"存好"，必须写一行 `say_hi()` 才真正执行。

## 第 2 步：参数 —— 让函数能接活儿

现在 `say_hi` 只会干同一件事。给它开个"窗口"，每次喊它时递不同的东西进去：

```python
def buy(thing):
    print("去买", thing)

buy("土豆")
buy("西红柿")
```

输出：

```text
去买 土豆
去买 西红柿
```

- 定义时括号里的 `thing` 叫**参数**：一个待填的空位
- 调用时 `buy("土豆")`：把 `"土豆"` 填进空位，函数里所有 `thing` 都变成 `"土豆"`

同一个函数，递不同东西，干不同的活。这就是"打包"的威力。

## 第 3 步：return —— 把结果交出来（本课重点）

print 只是"喊一嗓子"，喊完就没了。想要函数**算出一个结果交给你**，用 `return`：

```python
def add(a, b):
    return a + b

result = add(3, 5)
print(result)
print(add(10, 20))
```

输出：

```text
8
30
```

- `add(3, 5)` 这整个式子，**会被替换成** return 交出来的 `8`
- 所以能写 `result = add(3, 5)`：接住交出来的结果，装进变量
- 这个函数有**两个参数**：`a` 和 `b`，调用时按顺序填

> [!warning] 新手第一大坑：忘了 return
> ```python
> def add(a, b):
>     a + b        # 只算了，没交出来
>
> result = add(3, 5)
> print(result)
> ```
> 输出是 `None`——"什么都没有"。函数不写 return，调用它的结果就是 `None`。以后看到变量莫名其妙是 `None`，先想：**是不是哪个函数忘了 return？** 详见 [[新手报错速查]]。

## 第 4 步：默认参数 —— 给空位预填一个值

```python
def order(dish, count=1):
    print(f"点了 {count} 份{dish}")

order("牛肉面")
order("饺子", 3)
```

输出：

```text
点了 1 份牛肉面
点了 3 份饺子
```

`count=1` 的意思：**调用时没填 count，就默认用 1**；填了就听你的。以后读别人的代码（比如 AI 库的文档）会大量见到这种写法。

## 第 5 步：调用自己写的函数（完整走一遍）

把前面几步合起来，写一个真实有用的小函数：

```python
def make_prompt(question):
    return f"请用大白话解释：{question}"

msg = make_prompt("什么是变量")
print(msg)
```

输出：

```text
请用大白话解释：什么是变量
```

这就是你天天在做的事——把问题包装成一句提示词发给 AI。函数、`return`、f-string，全用上了。

## 最关键的一句

> [!important]
> **`def 名字(参数):` 打包代码，`名字(东西)` 调用；`return` 把结果交出来，没写 return 就只能得到 `None`。**

## 大白话翻译表

| 术语 | 大白话 |
| --- | --- |
| 函数 function | 打包好的一段代码，喊名字就跑 |
| `def` | 定义（存好）一个函数 |
| 参数 parameter | 定义时括号里的空位 |
| 调用 call | 喊名字执行，如 `buy("土豆")` |
| `return` | 把结果交出来，整个调用式子被替换成它 |
| 默认参数 | 空位预填的值，如 `count=1` |
| `None` | "什么都没有"，常因忘写 return |

## 检查一下

1. 只写了 `def hi(): print("嗨")` 没写别的，运行后屏幕上有东西吗？为什么？
2. `def add(a, b): return a + b`，`add(2, 3)` 这个式子整个等于几？
3. 下面这个函数哪里有问题？`def double(x): x * 2`
4. `def f(a, b=10): return a + b`，`f(5)` 等于几？

<details>
<summary>点我看答案</summary>

1. 没有。`def` 只是定义（存好），不写一行 `hi()` 调用它就不会执行。
2. 5——`add(2, 3)` 会被替换成 return 交出来的结果。
3. 忘了 `return`：只算了 `x * 2` 没交出来，调用结果是 `None`。应写 `return x * 2`。
4. 15——`b` 没填，用默认值 10，5 + 10 = 15。
</details>
