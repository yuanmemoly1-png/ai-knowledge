# 小白课：API 服务员（慢速版）

上一课：[[小白课-前端与后端]]

> [!note] 这节课学什么
> 上节课说，前厅（前端）和后厨（后端）之间有个跑腿的**服务员**。这节课把服务员讲透：
> - 服务员手里的**菜单** = 接口文档
> - 点菜的两种方式：**GET**（问问）和 **POST**（下单）
> - 服务员回话的**手势**：状态码
>
> 最后真的用 Python 叫一次"服务员"，亲眼看他回话。

---

## 一句定义

**API 就是前后端之间的服务员：前端把需求写成一张标准格式的单子递给他，他跑去后端办，再把结果端回来。**

## 第 1 步：菜单 = 接口文档

餐厅里服务员不能随便接单——你得照**菜单**点。菜单上写着：有什么菜、叫什么名、多少钱。

API 也一样。每个后端都会公布一份**接口文档**，上面写着：

- 有哪些"菜"可以点（有哪些功能）
- 每道"菜"的**地址**（叫 URL，比如 `/menu`、`/order`）
- 点的时候要**递什么**（参数，比如 `dish=宫保鸡丁`）
- 后端会**回什么**（返回格式）

你以后看到"这个服务提供 API"，翻译过来就是：**这家后厨对外开放了菜单，你的程序也能去点菜。**

## 第 2 步：两种点菜方式——GET 和 POST

菜单上每道菜还标着"点法"，最常见的就两种：

| 点法 | 大白话 | 餐厅例子 |
| --- | --- | --- |
| **GET** | "问一下"，**不改任何东西** | "今天的菜单给我看看" |
| **POST** | "交东西给你办"，**会改动后厨的数据** | "下单一份宫保鸡丁"（库存会少 1） |

记忆口诀：**GET 是伸头看，POST 是递单子。**

- 查菜单、查余额、查天气 → GET
- 下单、登录、发朋友圈 → POST

## 第 3 步：服务员的手势——状态码

服务员端话回来时，先说一个**三位数**，相当于手势，你不用看内容就知道结果好不好：

| 状态码 | 手势 | 大白话 |
| --- | --- | --- |
| **200** | 👌 | 成了，给你 |
| **404** | 摆手 | 没这道菜（地址写错了 / 东西不存在） |
| **500** | 扶额 | 后厨着火了（后端代码崩了，不是你的错） |

规律：**2 开头是好消息，4 开头是你错了，5 开头是他错了。**

## 第 4 步：真叫一次服务员（Python 代码，真能跑）

Python 里叫服务员用 `requests` 库（已装好就能直接用）。我们用 httpbingo.org——一个专门陪人练习的"假餐厅"，它会把你点的东西原样报回来。

先 **GET**（问一问）：

```python
import requests

r = requests.get("https://httpbingo.org/get", params={"dish": "gongbao"})
print("状态码：", r.status_code)
print("后厨收到：", r.json()["args"])
```

输出：

```text
状态码： 200
后厨收到： {'dish': ['gongbao']}
```

- `params=` 后面是"我要问的事"，requests 会自动帮你写进地址
- `r.status_code` 就是服务员的手势，**200 = 成了**
- `r.json()` 把回话变成你学过的**字典**，可以按名字取

再 **POST**（递单子下单）：

```python
r = requests.post("https://httpbingo.org/post", json={"dish": "gongbao", "qty": 1})
print("状态码：", r.status_code)
print("后厨收到：", r.json()["json"])
```

输出：

```text
状态码： 200
后厨收到： {'dish': 'gongbao', 'qty': 1}
```

写法几乎一样，只是 `get` 换成 `post`，`params=` 换成 `json=`（json= 表示"单子内容是个字典"）。

最后看一眼 404 长什么样：

```python
r = requests.get("https://httpbingo.org/get/meiyouzhedaocai")
print("乱点一道不存在的菜：", r.status_code)
```

输出：

```text
乱点一道不存在的菜： 404
```

> [!warning] 新手常见坑
> - **没联网 / 网址打错** 会直接报一长串红色错误（`ConnectionError`），先检查网址和网络。
> - 拿到 4xx/5xx 别慌，先看状态码再读返回内容——排查顺序见 [[新手报错速查]]。

## 第 5 步：这跟 AI 有什么关系？

关系大了：**你调任何大模型（GPT、Kimi、DeepSeek），本质都是 POST 一次 API**——把 prompt 装进字典递过去，服务员把回答端回来。你在 [[小白课-Prompt提示词]] 见过的 `{"role": "user", "content": "你好"}`，就是 POST 单子上的一项。

## 最关键的一句

> [!important]
> **API = 前后端之间的服务员。GET 是"问一下"，POST 是"递单子办事情"；回话先看状态码：2 开头成了，4 开头你错了，5 开头他错了。**

## 大白话翻译表

| 术语 | 大白话 |
| --- | --- |
| API 接口 | 服务员 + 他手里的菜单 |
| 接口文档 | 菜单：有什么菜、怎么点、回什么 |
| URL 地址 | 菜单上每道菜的"编号" |
| 参数 params | 点菜时的要求（"少放辣"） |
| GET / POST | 问一下 / 递单子办事 |
| 状态码 | 服务员的手势：200 成、404 没有、500 后厨崩了 |
| JSON | 单子和回话通用的格式，就是 Python 字典的长相 |
