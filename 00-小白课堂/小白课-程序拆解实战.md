# 小白课：程序拆解实战（慢速版）

上一课：[[小白课-Python文件读写]]

> [!note] 这节课学什么
> 这是 Python 篇的收官课。前六课你集齐了所有积木：变量、字符串、列表字典、条件循环、函数、文件读写。这节课不学新积木，学**怎么把积木搭成完整的程序**：
> - 所有程序的统一骨架：输入 → 处理 → 输出
> - 从零写一个程序的五步法
> - 逐行拆解两个完整程序：词频统计器、猜数字游戏
> - 一个进阶技巧：链式调用

## 第一部分：所有程序都是同一个骨架

不管多复杂的程序——小到今天写的几十行，大到微信、抖音——剥到骨头都长这样：

```text
  输入              处理               输出
┌────────┐      ┌──────────┐      ┌──────────┐
│ 用户打字 │  →   │ 你的代码    │  →   │ 屏幕显示    │
│ 读文件   │      │ 切/数/判断  │      │ 存文件      │
│ API 返回 │      │ 拼提示词    │      │ 发给 AI    │
└────────┘      └──────────┘      └──────────┘
```

你学过的积木各自归位：

| 骨架 | 你学过的积木 |
| --- | --- |
| 输入 | `input()`、读文件 `f.read()` |
| 处理 | 变量、split/join、for + if、函数 |
| 输出 | `print()`、写文件 `f.write()` |

**拿到任何需求，先把它塞进这个骨架**：输入是什么？要输出什么？中间怎么处理？想清这三个，程序就写出来一半了。

## 第二部分：搭程序五步法

拿到一个需求（比如"统计一段文字里每个词出现几次"），按这五步走：

1. **想清楚要什么**：一句话说清输入和输出。"输入一句话，输出每个词出现几次"
2. **拆步骤**：用中文写流程。"切成单词 → 挨个看 → 见过的加 1，没见过的记 1 → 打印"
3. **每步翻成代码**：一步一行（或几行），翻不动的步骤说明有积木没学，回头补课
4. **跑 + 修**：报错就读错误信息，去查 [[新手报错速查]]；能跑但结果不对，就在中间加 `print` 看变量
5. **加功能**：能跑之后再加料——排序、存文件、做成函数

下面两个实战，都是这么搭出来的。

## 第三部分：逐行拆解《词频统计器》

需求：输入一句"苹果 香蕉 苹果 橘子 香蕉 苹果"，输出每个词出现几次。

```python
text = "苹果 香蕉 苹果 橘子 香蕉 苹果"     # 输入

words = text.split()                       # 处理①：切成单词列表
count = {}                                 # 处理②：空字典，准备记账
for w in words:                            # 处理③：挨个看
    if w in count:                         #   账本上见过这个词？
        count[w] = count[w] + 1            #   见过：次数加 1
    else:
        count[w] = 1                       #   没见过：记 1 次

print(count)                               # 输出①：整本账
for w in count:                            # 输出②：一行一条，好看点
    print(w, "出现了", count[w], "次")
```

输出：

```text
{'苹果': 3, '香蕉': 2, '橘子': 1}
苹果 出现了 3 次
香蕉 出现了 2 次
橘子 出现了 1 次
```

逐行过一遍关键处：

- `text.split()` 括号空着 = 按空格切（上节课学过的特例），得到 `['苹果', '香蕉', '苹果', '橘子', '香蕉', '苹果']`
- `count = {}` 造一个空字典当账本——**字典就是记账的最佳容器**：词当键、次数当值
- `if w in count` 判断"这个词在账本里吗"——`in` 这个写法第一次看到，读作"w 在 count 的键里面吗"
- `count[w] = count[w] + 1` 取出旧次数加 1 再放回去——就是 [[小白课-Python列表与字典]] 里"名字已存在就改"

这就是五步法里第 3 步"翻成代码"的真实样子：**每一步中文流程，刚好对应一行代码**。这个"for + if 往字典里计数"的套路，以后分析聊天记录、统计日志、处理 AI 返回的数据，天天用。

## 第四部分：逐行拆解《猜数字游戏》

需求：程序想好一个数字，你猜，它告诉你大了还是小了，猜对为止。

先补两块新积木——**键盘输入**：

```python
s = input()        # 程序停下来等你打字，你敲的内容装进 s
print(type(s))     # 注意：input 拿到的永远是字符串
n = int(s)         # int() 把字符串转成数字
print(n + 1)       # 转成数字才能做算术
```

（你输入 `42` 时，输出是 `<class 'str'>`、`<class 'int'>`、`43`）

> [!warning] input 拿到的是字符串！
> 直接 `input() + 1` 会报 `TypeError`（文字不能加数字，[[小白课-Python变量与print]] 学过）。**凡是拿 input 当数字用，先过一遍 `int()`。**

完整程序：

```python
secret = 42                                # 程序想好的数字

while True:                                # 一直转，直到猜对
    guess = int(input("猜一个 1 到 100 的数字："))
    if guess < secret:
        print("小了，再猜")
    elif guess > secret:
        print("大了，再猜")
    else:
        print("猜对了！")
        break                              # 猜对了：跳出循环
```

真实试玩记录（我输入了 30、50、42）：

```text
猜一个 1 到 100 的数字：30
小了，再猜
猜一个 1 到 100 的数字：50
大了，再猜
猜一个 1 到 100 的数字：42
猜对了！
```

两个新面孔：

- `while True`：条件永远是真 = **故意死循环**，靠里面的 `break` 跳出来。这是"不知道要转几圈"的标准写法
- `break`：**立刻跳出循环**。猜对的那一刻，循环就没必要转了

看骨架：输入（`input`）→ 处理（`if/elif/else` 比较）→ 输出（`print`），包在一个"转到停"的 while 里——全是学过的积木。

## 第五部分：链式调用 —— 一行顶两行

看这一行：

```python
s = "苹果,香蕉,橘子"
print("、".join(s.split(",")))
```

输出：

```text
苹果、香蕉、橘子
```

一行里连干两件事。**从里往外读**：先 `s.split(",")` 切成列表，再把这个列表交给 `"、".join(...)` 粘起来。括号套括号，先算最里面的。

什么时候该拆开写？**当你需要中间结果，或者一行读不懂的时候**：

```python
parts = s.split(",")       # 拆开：先切
result = "、".join(parts)  # 再粘
print(result)
```

两种写法结果一模一样。规则就一条：**自己一个月后能看懂，就是对的写法**。新手阶段建议先拆开，熟了再合并。

## 最关键的一句

> [!important]
> **写程序 = 输入 → 处理 → 输出；搭程序 = 想清楚要什么 → 拆步骤 → 翻成代码 → 跑和修 → 加功能。你学过的每一块积木，都只是往这个骨架上填的肉。**

3. `guess = input()` 之后直接 `guess + 1`，会发生什么？怎么修？
