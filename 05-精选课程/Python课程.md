# Python课程

Python 是 AI 开发的第一语言：LangChain、LangGraph、smolagents、crewAI 等主流框架全部基于 Python。本文精选零基础可学的优质课程，配合 [[Python学习路线]] 使用效果更佳。

> [!warning] 纯小白先看这里
> 如果你是零基础、看文字教程总觉得"跳跃、跟不上"，先读 [[零基础防卡指南]]——文字教程（廖雪峰、官方教程）是"字典"不是"老师"，建议先用视频课（北理工嵩天 MOOC、小甲鱼）当主线，文字教程留作查阅。

## 廖雪峰 Python 教程

**一句话定位**：中文互联网上流传最广的免费 Python 教程，真正的零起点。

**适合谁**：完全没有编程经验、希望用中文学习的第一选择。

**内容特点**：
- 从安装解释器讲起，覆盖基础语法、函数、面向对象、错误处理
- 每节配有可直接运行的代码示例，边读边敲
- 后续章节涉及正则表达式、网络编程、数据库等实用主题

```python
# 教程风格的示例：列表推导式
squares = [x * x for x in range(10)]
print(squares)  # [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
```

**链接**：[廖雪峰 Python 教程](https://liaoxuefeng.com/books/python)

## 哈佛 CS50P

**一句话定位**：哈佛大学官方 Python 入门课，免费、质量极高、作业设计精妙。

**适合谁**：能接受全英文授课、想要体系化训练编程思维的学习者。

**内容大纲**：
- 函数与变量、条件判断、循环、异常处理
- 单元测试（pytest）、文件 I/O、正则表达式
- 面向对象编程

> [!tip]
> 课程配套自动判题系统，提交作业能立即得到反馈，这是自学最稀缺的东西。建议在 [[环境搭建与包管理]] 配好环境后再开始。

**链接**：[CS50's Introduction to Programming with Python](https://cs50.harvard.edu/python/)

## Python 官方中文教程

**一句话定位**：Python 官网自带教程的完整中文翻译，权威、准确、永远最新。

**适合谁**：有其他语言基础想快速上手 Python 的人；也适合作为随手查阅的参考。

**内容特点**：
- 与 Python 版本同步更新，不存在过时问题
- 对标准库和数据结构的讲解最权威
- 缺点是行文偏文档风，不如廖雪峰教程亲切

**链接**：[Python 官方中文教程](https://docs.python.org/zh-cn/3/tutorial/)

## freeCodeCamp

**一句话定位**：免费公益学习平台，完成课程可获得认证证书。

**适合谁**：喜欢视频+闯关式学习、想要证书激励自己的人。

**内容特点**：
- 提供 Python 科学计算、数据分析等方向的认证路径
- 每个认证要求完成 5 个实战项目，不是看完视频就算数
- 全英文界面，但视频配有字幕

**链接**：[freeCodeCamp](https://www.freecodecamp.org)

## B站视频资源

> [!example] B站搜索关键词
> - **小甲鱼《零基础入门学习Python》**：语气轻松幽默，适合完全没接触过编程的人建立兴趣
> - **黑马程序员 Python 系列**：体系完整、时长充足，从基础到就业方向（爬虫、Web、数据分析）都有覆盖

视频课的优势是可以看到完整的敲代码过程，适合跟着做；缺点是节奏慢，建议 1.5 倍速观看，把省下的时间用于自己写代码。

## 学习建议

> [!warning] 只看不练等于没学
> 编程是技能不是知识，看十小时视频不如亲手写一百行代码。

1. **边学边做项目**：学完基础语法后立刻做小项目，比如命令行待办清单、批量重命名文件工具、爬取网页标题的小脚本。
2. **卡壳先查文档**：遇到问题先查 [Python 官方中文教程](https://docs.python.org/zh-cn/3/tutorial/) 和标准库文档，再求助搜索引擎或 AI。
3. **够用就进入下一阶段**：目标是 AI 开发的话，不必把 Python 学到"精通"。掌握 [[基础语法速查]] 和 [[常用数据结构与函数]] 中的内容，就可以进入 [[面向AI开发的Python]]，在 Agent 项目中继续补。
4. **对照路线图自检**：用 [[Python学习路线]] 检查自己的进度，避免在不必要的分支（如 GUI 开发、游戏开发）上消耗时间。
