## 选课建议

> [!note] 零基础先 Python，后 Agent
> AI Agent 开发的所有主流框架（LangChain、LangGraph、smolagents、crewAI）都是 Python 生态。如果连函数、字典、类都不熟悉，直接学 Agent 课程会处处卡壳。推荐路径：
> 1. **第 1 步**：跟着 [[Python课程]] 学 Python 基础语法（约 2-4 周）
> 2. **第 2 步**：读 [[面向AI开发的Python]]，补齐 AI 开发常用的进阶用法
> 3. **第 3 步**：从 [[AI-Agent课程]] 中选一门体系课（如 Microsoft ai-agents-for-beginners）
> 4. **第 4 步**：用 [[中文免费资源]] 中的 Datawhale 项目做实战巩固

如果你只想快速建立对 AI 的整体认知、暂时不写代码，可以先看吴恩达的 *Generative AI for Everyone*（详见 [[AI-Agent课程]]）。
