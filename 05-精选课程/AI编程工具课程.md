# AI 编程工具课程（Cursor / Vibe Coding 中文资源）

> [!note] 说明
> Cursor、Claude Code 这类 AI 编程工具官方几乎没有系统课程，但国内社区已经沉淀出一批**免费中文教程**——包括官方文档的中文翻译、UP 主的实战课、Datawhale 的开源教程。本文全部核实过链接，优先中文、优先免费。

## 一、系统化开源教程（推荐主线）

### 1. 程序员鱼皮《AI 编程指南》⭐
- **定位**：中文圈最完整的 AI 编程免费教程之一。几十万字、上千张图，从 Cursor / Claude Code / TRAE 工具用法，到 Vibe Coding 零基础项目实战、Prompt 技巧、AI 知识百科（Agent / RAG / MCP）都有。
- **适合谁**：零基础想靠 AI 做出完整产品的人；想做项目变现的独立开发者。
- **链接**：[liyupi/ai-guide](https://github.com/liyupi/ai-guide)

### 2. Datawhale Easy-Vibe ⭐
- **定位**：Datawhale 出品的「AI 时代编程第一课」，理念是"会说话就会编程"。三阶段渐进：从打开 Cursor → 自然语言描述需求 → 开发并部署完整应用（含前后端、AI 集成、RAG、MCP）。
- **适合谁**：纯零基础，想有人手把手带一遍完整流程。
- **链接**：[datawhalechina/easy-vibe](https://github.com/datawhalechina/easy-vibe)

### 3. Datawhale Vibe-Vibe
- **定位**：Datawhale 另一套更系统的 Vibe Coding 开源教程，"零基础到全栈实战"，四大板块渐进式设计，有配套在线网站。
- **适合谁**：学完 Easy-Vibe 想继续进阶全栈实战的人。
- **链接**：[datawhalechina/vibe-vibe](https://github.com/datawhalechina/vibe-vibe)

## 二、Cursor 专项教程

### 4. Cursor 中文文档（learn-cursor.com）
- **定位**：把 Cursor 官方文档完整翻译成中文，外加实用指南、真实案例、踩坑 FAQ。
- **适合谁**：正在用 Cursor、需要随手查功能说明的人。配合 [[Cursor实战指南]] 食用最佳。
- **链接**：[Cursor 中文教程](https://learn-cursor.com)

### 5. BookAI.TOP Cursor 教程
- **定位**：中文 Cursor 视频教程（B站/YouTube 累计播放超百万），5 期实战：入门、高级技巧、做带注册登录的 AI 网站、做完整 AI Native App、写本地自动化脚本。
- **适合谁**：喜欢看视频跟做、想直接看到"从 0 到一个能用的产品"全过程的人。
- **链接**：[BookAI.TOP Cursor 教程](https://bookai.top/cursor/intro)

### 6. ExplainThis《Cursor 入门到实战》
- **定位**：图文指南，结构清晰，覆盖 Cursor 核心功能与实战流程。
- **链接**：[ExplainThis Cursor 指南](https://www.explainthis.io/zh-hans/ai/cursor-guide)

## 三、B站视频课

> [!tip] 搜索关键词
> B站直接搜：**「Cursor 教程」**、**「Cursor 零基础」**、**「Claude Code 教程」**。播放量高的成套合集（20 集左右）内容大同小异，选一套跟完即可，不必贪多。

> [!warning] 避坑提醒
> B站上标题写着"748 集""七天从小白到大神"的合集多为营销号搬运拼装，质量参差。优先选上面第一、二节里有名有姓的开源教程和 UP 主原创课程。
