# 中文免费资源

英文课程质量高，但对很多自学者来说语言本身就是门槛。本文精选完全免费的中文优质资源，全部由社区开源或高校公开，可以无障碍系统学习 LLM 应用与 [[Agent智能体]] 开发。

## Datawhale 开源社区系列

Datawhale 是国内最大的开源学习社区之一，以"组队学习 + 开源教程"模式著称。下面四个项目是学习大模型应用开发的核心资源，全部免费、全部中文、全部可动手实操。

### hello-agents（AI Native Agent 教程）

**一句话定位**：从零构建 Agent 的系统性中文教程，不依赖特定框架也能理解 Agent 本质。

**适合谁**：想深入理解 Agent 原理、而不只是调框架 API 的学习者。

**内容特点**：
- 从 LLM 基础、Prompt 讲起，逐步实现 ReAct 循环、工具调用、记忆系统
- 强调"AI Native"思维：如何围绕 LLM 的能力边界设计应用
- 配套代码完整，可逐章运行验证

**链接**：[hello-agents](https://datawhalechina.github.io/hello-agents/)

### deepagents-in-action（LangGraph/Deep Agents 生产级 Agent 课程）

**一句话定位**：面向生产环境的 Agent 实战课，教你怎么把 Demo 变成真正可用的系统。

**适合谁**：已经会用 LangGraph 写基础 Agent（可先学 [[LangGraph状态图]]），想进阶到工程化的开发者。

**内容特点**：
- 基于 LangGraph 与 Deep Agents 构建复杂、长任务的 Agent 系统
- 覆盖子 Agent、持久化、人机协作、错误恢复等生产级主题
- 弥补"教程 Demo"与"真实产品"之间的鸿沟

**链接**：[deepagents-in-action](https://github.com/datawhalechina/deepagents-in-action)

### llm-universe（动手学大模型应用开发）

**一句话定位**：以一个完整项目（个人知识库问答助手）贯穿始终的应用开发教程。

**适合谁**：想通过一个完整项目理解 LLM 应用全貌的初学者。

**内容大纲**：
- 大模型简介与 API 调用（覆盖国内外主流模型）
- Prompt 工程、[[Embedding向量嵌入]] 与向量数据库
- 搭建 [[RAG检索增强生成]] 系统
- 系统评估、优化与前后端部署

**链接**：[llm-universe](https://github.com/datawhalechina/llm-universe)

### llm-cookbook（面向开发者的大模型手册）

**一句话定位**：DeepLearning.AI 经典短课的中文复现版 + 中文原创实践，大模型开发的"菜谱大全"。

**适合谁**：想按专题（Prompt、RAG、评估、Agent）逐个突破的开发者。

**内容特点**：
- 复现了吴恩达团队多门经典课程的代码，并替换为国内可直接调用的模型 API
- 每个 Notebook 独立成篇，可按需取用
- 适合作为 [[AI-Agent课程]] 的配套实操材料

**链接**：[llm-cookbook](https://github.com/datawhalechina/llm-cookbook)

> [!tip] 更多项目
> Datawhale 还开源了 tiny-universe（手写大模型组件）、self-llm（开源模型部署指南）等项目，组织主页见：[github.com/datawhalechina](https://github.com/datawhalechina)

## 台大李宏毅课程

**一句话定位**：中文世界最受欢迎的机器学习公开课，讲解生动、梗多、不催眠。

**适合谁**：想理解 LLM 和生成式 AI **底层原理**（而不仅是应用层调 API）的学习者。

**内容**：
- **机器学习课程**：从回归、梯度下降、神经网络一路讲到 Transformer、自注意力机制
- **生成式 AI 课程**：专门讲 LLM 时代的技术——预训练、微调、提示、RAG、Agent 的原理性解读

> [!note] 与工程课的关系
> 李宏毅的课偏原理和数学直觉，Datawhale 的课偏工程实战，两者互补。建议先学工程课做出东西获得成就感，再回头补原理——看到 [[幻觉Hallucination]]、[[上下文窗口]] 这些概念时会有更深的理解。

**主页**：[李宏毅教授主页](https://speech.ee.ntu.edu.tw/~hylee/index.html)

> [!example] 获取方式
> 课程录像在 B站有搬运，搜索关键词"李宏毅 机器学习"或"李宏毅 生成式AI"即可找到完整合集，按年份选择最新版本。
