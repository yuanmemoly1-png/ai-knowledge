# 微软公开课全集（for-beginners 系列）

> [!note] 这是什么
> 微软在 GitHub 上维护了一整套「XX-for-beginners」开源课程，**全部免费、多语言（含中文翻译）、自带练习和测验**，由微软工程师和全球社区共同维护。每门课通常按"X 周 Y 课"组织，每课含图文讲解 + 视频 + 课前/课后小测 + 作业，非常适合自学打卡。

## 一、AI 主线（和你当前目标最相关）

| 课程 | 规模 | 内容 | 链接 |
| --- | --- | --- | --- |
| Generative AI for Beginners | 21 课 | 生成式 AI 应用开发：提示词、RAG、微调、Agent 入门，代码示例用 GitHub Models 免费额度就能跑 | [GitHub](https://github.com/microsoft/generative-ai-for-beginners) |
| AI Agents for Beginners | 18 课 | Agent 体系课：设计模式（工具使用/规划/多智能体/元认知）、Agentic RAG、可信 Agent、上生产 | [GitHub](https://github.com/microsoft/ai-agents-for-beginners) |
| MCP for Beginners | 体系课 | MCP 协议实战，示例覆盖 Python / TypeScript / .NET / Java / Rust 多语言 | [GitHub](https://github.com/microsoft/mcp-for-beginners) |
| Edge AI for Beginners | 体系课 | 边缘侧 AI：小模型、推理优化、端侧部署 | [GitHub](https://github.com/microsoft/edgeai-for-beginners) |

> [!tip] 学习顺序建议
> `generative-ai-for-beginners` → `ai-agents-for-beginners` → `mcp-for-beginners`，正好对应你库里的 [[Agent开发总览]] 学习路线；详细点评见 [[AI-Agent课程]]。

## 二、打地基（AI 前置知识）

| 课程 | 规模 | 内容 | 链接 |
| --- | --- | --- | --- |
| AI for Beginners | 12 周 24 课 | 经典 AI 入门：搜索、知识表示、神经网络、计算机视觉、NLP，用 PyTorch/TensorFlow 做实验 | [GitHub](https://github.com/microsoft/AI-For-Beginners) |
| ML for Beginners | 12 周 26 课 | 经典机器学习：回归、分类、聚类、NLP、时间序列，以 scikit-learn 为主 | [GitHub](https://github.com/microsoft/ML-For-Beginners) |

## 这个系列的共同特色

- **每课结构统一**：课前小测 → 图文讲解（配手绘风 sketchnote）→ 视频 → 动手练习 → 课后小测 → 作业
- **中文翻译由社区维护**：在仓库的 `translations/` 目录下，覆盖度因课程而异
- **0 成本实操**：AI 类课程普遍接 GitHub Models 免费额度，不用自己掏 API 钱

> [!example] 给你的组合方案
> 以"全栈 + Agent 求职"为目标的最优组合：
> 1. 现在：[[Python学习路线]] + `Web Dev for Beginners`（打全栈地基）
> 2. Python 语法过关后：`generative-ai-for-beginners` → `ai-agents-for-beginners`
> 3. 做项目阶段：`mcp-for-beginners` + [[全栈项目实战]]
> 4. 想补理论：`ML for Beginners` 或 [[斯坦福公开课]] 的 CS229
