# 全栈学习路线

> [!note] 模块简介
> 本模块面向「0 基础、正在学 Python、目标是能独立做完整 Web/App 产品」的自学者。路线起点衔接 [[Python学习路线]]，终点是能一个人完成 [[全栈开发]] 中说的三层（前端 + 后端 + 数据库）并部署上线。预计总用时 6-9 个月（业余每天 1-2 小时的口径）。

## 本模块笔记清单

- [[HTML与CSS入门]] — 网页的结构与样式，浏览器打开就能跑
- [[JavaScript入门]] — 让网页动起来，含 Python 语法对照
- [[FastAPI后端实战]] — 用 Python 写后端 API，内存版 Todo CRUD
- [[前端框架入门]] — React vs Vue、组件化思想、前后端分工
- [[全栈项目实战]] — 把前五篇串成「AI 备忘录」完整项目

## 总体路线图

```text
① Python 基础（04 模块）
  → ② 网页三件套 HTML/CSS/JS
    → ③ Python Web 后端（FastAPI）
      → ④ 数据库与部署
        → ⑤ 前端框架（React / Vue）
          → ⑥ 完整项目实战
```

> [!warning] 先打基础，再用 AI 加速
> [[VibeCoding方法论]] 能让 AI 帮你写代码，但**不能跳过基础**。如果你看不懂 HTML 和 API 是什么，AI 生成的代码出了 bug 你根本改不动，只会陷入「生成-报错-再生成-再报错」的死循环。正确姿势：每个阶段先手动写一遍最小示例，再让 AI 在此基础上加速。

## 分阶段路线图

### 阶段一：Python 基础（2-4 周，在 04 模块完成）

**目标**：能独立写 50 行以内的小脚本，能读懂开源项目的常见写法。

- 学习内容：[[Python学习路线]] 的阶段一、二
- 对应笔记：[[环境搭建与包管理]]、[[基础语法速查]]、[[常用数据结构与函数]]
- 自测标准（能独立写出才算过）：
  - 读取一个 `.txt` 文件，统计词频并输出前 10 名
  - 用 `requests` 调一个公开 API，把返回的 JSON 解析后打印
  - 会用 venv 建虚拟环境、用 pip 装包
- 产出物：一个命令行小工具（如记账本、单词本）

### 阶段二：网页三件套 HTML/CSS/JS（3-4 周）

**目标**：能写出有样式、有交互的单页网页，理解「网页 = 结构 + 样式 + 行为」。

- 学习内容：[[HTML与CSS入门]] → [[JavaScript入门]]
- 自测标准：
  - 能手写一个带导航、列表、表单的静态页面，并用 Flex 布局
  - 能写一个「点击按钮 → fetch 调 API → 把结果显示在页面上」的页面
  - 能说出 JS 的 `let/const`、箭头函数、`async/await` 对应 Python 里的什么
- 产出物：一个纯前端的「天气查询」或「待办清单」页面（数据存内存即可）
- 课外补充：MDN、freeCodeCamp 的 HTML/JS 章节，边查边练

### 阶段三：Python Web 后端 FastAPI（3-4 周）

**目标**：能用 FastAPI 写出带路由、参数校验、增删改查的后端 API。

- 学习内容：[[FastAPI后端实战]]，基础概念见 [[面向AI开发的Python]]
- 前置概念：[[API接口]]、[[前端与后端]]
- 自测标准：
  - 能写出 GET/POST/DELETE 三种路由，用 pydantic 模型校验请求体
  - 能用 uvicorn 启动服务，并在 `/docs` 页面里手动测试每个接口
  - 能用浏览器的 fetch 或 curl 调通自己写的接口
- 产出物：内存版 Todo API（本模块有完整示例）

### 阶段四：数据库与部署（2-3 周）

**目标**：数据能持久化，项目能在服务器上跑起来给别人访问。

- 学习内容：[[数据库入门]]（先用 SQLite，零配置）、[[部署与上线]]
- 配套技能：[[Git与版本控制]]（代码备份与发布的必备工具）
- 自测标准：
  - 能把阶段三的内存 Todo 改成存 SQLite，重启服务数据不丢
  - 能说清开发环境和生产环境的区别，知道域名、服务器、HTTPS 各是什么
- 产出物：一个部署到云服务器、有公网地址可访问的 API 服务

### 阶段五：前端框架 React / Vue（4-6 周）

**目标**：理解组件化思想，能用框架搭建多页面、可维护的前端。

- 学习内容：[[前端框架入门]]
- 自测标准：
  - 能解释「组件」「props」「状态」是什么
  - 能用框架重写阶段二的待办清单，体会比原生 JS 好在哪里
  - 能让框架前端调通自己写的 FastAPI 后端
- 产出物：框架版待办清单前端（连自己的后端 API）

### 阶段六：完整项目实战（4-6 周）

**目标**：把前五阶段串起来，独立交付一个完整产品。

- 学习内容：[[全栈项目实战]]（「AI 备忘录」：前端 + FastAPI + SQLite + LLM 自动摘要）
- 自测标准：
  - 项目有清晰的目录结构，前后端分离，数据入库
  - 部署上线，发给朋友能用
  - 能讲清楚每一层报了错去哪查
- 产出物：一个可对外展示的完整作品（也是第一份求职/接单作品）

## 常见问题

| 问题 | 建议 |
| --- | --- |
| 可以跳过前端只学后端吗？ | 不建议。0 基础阶段至少要会 HTML/JS 基础，否则连 AI 生成的前端都验收不了 |
| React 和 Vue 学哪个？ | 任选其一深入即可，详见 [[前端框架入门]] 的选型建议 |
| 每阶段卡住了怎么办？ | 先看 [[AI编程工具课程]] 学会向 AI 提问，再把报错信息完整发给 AI，比自己硬扛快得多 |
| 学完能找工作吗？ | 本路线目标是「能独立做产品」。求职还需另补面试八股（见 08-求职面试 模块），但完整项目作品是最好的简历 |
