# 全栈项目实战：AI 备忘录

## 我们要做什么

把本模块前五篇串成一个完整产品——**AI 备忘录**，也是 [[全栈开发]] 里三层架构的最小完整闭环：

- 用户在网页上写一条备忘录
- 后端把它存进 SQLite 数据库
- 后端同时调大模型 API，自动生成一句话摘要
- 页面上显示「原文 + AI 摘要」的列表

## 项目架构

```text
┌─────────────────────────────────────────────┐
│ 浏览器（前端）                                │
│ index.html：输入框 + 列表，fetch 调后端       │
└──────────────────┬──────────────────────────┘
                   │ HTTP / JSON（[[API接口]]）
┌──────────────────┴──────────────────────────┐
│ FastAPI 后端（main.py）                       │
│ ├─ POST /notes   新建备忘 → 调 LLM 生成摘要   │
│ └─ GET  /notes   查询全部                    │
└──────┬───────────────────────┬──────────────┘
       │ sqlite3 读写           │ openai SDK 调用
┌──────┴──────┐         ┌───────┴───────┐
│ notes.db     │         │ 大模型 API      │
│ （SQLite）    │         │ （自动摘要）     │
└─────────────┘         └───────────────┘
```

## 关键代码骨架

### 后端 main.py（核心逻辑）

```python
import os
import sqlite3
from fastapi import FastAPI
from fastapi.staticfiles import StaticFiles
from pydantic import BaseModel
from openai import OpenAI

app = FastAPI(title="AI 备忘录")
client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

# 建表（字段：id / 内容 / AI 摘要）
conn = sqlite3.connect("notes.db")
conn.execute("""CREATE TABLE IF NOT EXISTS notes
    (id INTEGER PRIMARY KEY AUTOINCREMENT,
     content TEXT NOT NULL, summary TEXT DEFAULT '')""")
conn.commit()
conn.close()

class NoteCreate(BaseModel):
    content: str

def make_summary(content: str) -> str:
    resp = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user",
                   "content": f"用一句话（20 字内）总结：{content}"}],
    )
    return resp.choices[0].message.content

@app.post("/notes", status_code=201)
def create_note(note: NoteCreate):
    summary = make_summary(note.content)
    conn = sqlite3.connect("notes.db")
    cur = conn.execute(
        "INSERT INTO notes (content, summary) VALUES (?, ?)",
        (note.content, summary),
    )
    conn.commit()
    note_id = cur.lastrowid
    conn.close()
    return {"id": note_id, "content": note.content, "summary": summary}

@app.get("/notes")
def list_notes():
    conn = sqlite3.connect("notes.db")
    rows = conn.execute(
        "SELECT id, content, summary FROM notes ORDER BY id DESC"
    ).fetchall()
    conn.close()
    return [{"id": r[0], "content": r[1], "summary": r[2]} for r in rows]

# 托管前端页面：访问 / 就打开 static/index.html
app.mount("/", StaticFiles(directory="static", html=True), name="static")
```

### 前端 static/index.html（fetch 部分）

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>AI 备忘录</title>
</head>
<body>
  <h1>AI 备忘录</h1>
  <form id="note-form">
    <input id="content" type="text" placeholder="记点什么..." required>
    <button type="submit">保存</button>
  </form>
  <ul id="note-list"></ul>

  <script>
    const list = document.querySelector("#note-list");

    const loadNotes = async () => {
      const resp = await fetch("/notes");
      const notes = await resp.json();
      list.innerHTML = "";
      for (const note of notes) {
        const li = document.createElement("li");
        li.textContent = `${note.content} —— AI 摘要：${note.summary}`;
        list.appendChild(li);
      }
    };

    document.querySelector("#note-form").addEventListener("submit", async (e) => {
      e.preventDefault();
      const input = document.querySelector("#content");
      await fetch("/notes", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ content: input.value }),
      });
      input.value = "";
      await loadNotes();
    });

    loadNotes();
  </script>
</body>
</html>
```

运行：`uvicorn main:app --reload`，浏览器打开 `http://127.0.0.1:8000` 即可使用。

> [!warning] 两个注意点
> - SQL 一律用 `?` 占位符传参（上面写法），不要 f-string 拼接，否则有 SQL 注入风险——这是 [[数据库入门]] 里强调的安全红线。
> - API Key 放 `.env` 并用环境变量读取，绝不写死在代码里，见 [[面向AI开发的Python]]。
> - 前端由 FastAPI 同源托管，所以无需 [[FastAPI后端实战]] 里的 CORS 配置；前后端分开部署时才需要。

## 部署思路

按 [[部署与上线]] 的路线，最小方案：

1. 代码推上 GitHub（先配好 [[Git与版本控制]]，`.env` 加进 `.gitignore`）。
2. 租一台最便宜的云服务器，装好 Python，克隆代码。
3. 服务器上装依赖、配好环境变量，用 `uvicorn main:app --host 0.0.0.0` 启动。
4. 想长期稳定运行，再加进程守护（如 systemd）和域名 + HTTPS。

## 做完后的扩展方向

- **用户系统**：加注册登录，每人只看自己的备忘录（涉及密码哈希、登录态，是下一个学习台阶）
- **改用前端框架**：用 React 或 Vue 重写 `index.html`，体会 [[前端框架入门]] 说的组件化
- **微信小程序版本**：后端一行不用改，再写一个调同样 API 的小程序前端，见 [[微信小程序开发入门]]
- **更强的 AI 能力**：把单条摘要升级成自动分类、每周回顾，甚至接入 [[Agent开发总览]] 的思路做成智能助理
