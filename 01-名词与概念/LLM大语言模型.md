# LLM 大语言模型

## 定义

LLM（Large Language Model，大语言模型）是用海量文本数据训练出来的神经网络，核心能力是**根据上文预测下一个 [[Token与分词|Token]]**。这个看似简单的"接龙"能力，在参数规模达到百亿、千亿级别后，涌现出了翻译、写作、推理、编程等通用能力。

可以把它理解为一个读过互联网上几乎所有公开文字的"超级预测机"：你给它一段文字，它计算接下来最可能出现的词是什么，一个接一个地生成，就形成了回答。

## 发展简史

| 时间 | 里程碑 | 意义 |
| --- | --- | --- |
| 2017 | Google 发表论文《Attention Is All You Need》 | 提出 **Transformer** 架构，成为之后所有主流 LLM 的地基 |
| 2018 | OpenAI 发布 GPT-1；Google 发布 BERT | 预训练 + 微调范式确立 |
| 2020 | GPT-3（1750 亿参数） | 证明"规模即能力"，少样本（few-shot）学习成为可能 |
| 2022.11 | ChatGPT 发布 | RLHF 对齐 + 对话形态，LLM 进入大众视野 |
| 2023 | GPT-4、Claude、Llama 开源 | 多模态、长上下文、开源生态爆发 |
| 2024-2025 | DeepSeek-R1、o 系列推理模型 | "思考型"模型兴起，推理时计算（inference-time compute）成为新范式 |

> [!note] Transformer 为什么重要
> 它用 Self-Attention（自注意力）机制让模型在处理每个词时都能"看到"整段上下文，并且可以大规模并行训练。想深入了解数学和代码实现，可以看 [[从零实现LLM专题]]。

## 主流模型对比

| 模型 | 出品方 | 开源/闭源 | 特点 | 适用场景 |
| --- | --- | --- | --- | --- |
| GPT 系列 | OpenAI | 闭源 | 综合能力标杆，生态最成熟 | 通用对话、Agent 开发 |
| Claude 系列 | Anthropic | 闭源 | 长文本、代码能力强，指令遵循好 | 编程、长文档分析 |
| Gemini 系列 | Google | 闭源 | 原生[[多模态]]，超长上下文 | 视频理解、超大文档 |
| DeepSeek 系列 | 深度求索 | 开源权重 | 中文强、推理模型 R1 性价比高 | 中文应用、低成本部署 |
| Qwen（通义千问） | 阿里 | 开源权重 | 中文生态好，尺寸覆盖全 | 国内业务、私有化部署 |
| Llama 系列 | Meta | 开源权重 | 开源社区事实标准，衍生模型极多 | 二次训练、研究 |

> [!tip] 选模型的实用建议
> 入门学习直接用 API 调用闭源模型（GPT/Claude/DeepSeek）即可；需要私有化部署或二次训练时再考虑 Qwen、Llama 这类开源模型。具体 API 申请方式见 [[常用工具清单]]。

## 能力边界

**擅长的：**

- 文本生成与改写：写作、翻译、摘要、润色
- 代码：补全、解释、调试、生成脚本（见 [[AI辅助开发总览]]）
- 结构化理解：从长文中抽取信息、分类、情感分析
- 推理与规划：配合 [[Prompt与提示词工程]] 中的 CoT 技巧效果更好

**不擅长或有硬限制的：**

- **会编造事实**：即 [[幻觉Hallucination]]，不能无条件信任
- **知识有截止日期**：训练数据之后的时事它不知道，需要 [[RAG检索增强生成]] 补充
- **上下文有限**：一次只能处理有限长度的文本，见 [[上下文窗口]]
- **无法主动行动**：裸模型只会输出文字，要做事得靠 [[Agent智能体]] 和 [[FunctionCalling函数调用]]

## 一个最小调用示例

```python
from openai import OpenAI

client = OpenAI()  # 通过环境变量 OPENAI_API_KEY 提供密钥

resp = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "用一句话解释什么是 LLM"}],
)
print(resp.choices[0].message.content)
```
