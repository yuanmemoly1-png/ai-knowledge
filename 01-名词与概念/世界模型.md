# 世界模型（World Model）

> [!note] 一句话定义
> **世界模型 = 让 AI 在"脑子里"学会世界运转的规律**（空间、物理、因果），从而能在内部模拟"如果我这样做，接下来会发生什么"。如果说 LLM 学的是"文字怎么接下去"，世界模型学的是"世界怎么演化下去"。

## 为什么 2025-2026 它突然火了

- LLM 的短板被看清：它只会"接话"，**不懂物理、不懂空间**——知道"杯子会碎"这句话，但并不真正理解重力
- 2026 年，业界把世界模型视为通往 AGI 的下一条主线（甚至超过 LLM 的声量）：
  - **DeepMind Genie 3**：实时生成可交互的 3D 世界（你能在 AI 生成的世界里走动）
  - **World Labs（李飞飞）**：从单张图片生成可探索的 3D 空间（Marble）
  - **AMI Labs（Yann LeCun 离开 Meta 后创立，2026 年种子轮 10.3 亿美元）**：押注"非生成式"路线（JEPA 架构），认为自回归 LLM 路线到不了 AGI
  - **Sora** 类视频模型被 OpenAI 称为"世界模拟器"

## 和 LLM 的本质区别

| | LLM | 世界模型 |
| --- | --- | --- |
| 学什么 | 下一个词是什么 | 下一个**状态**是什么 |
| 理解对象 | 语言统计规律 | 物理/空间/因果规律 |
| 典型能力 | 聊天、写作、编程 | 预测演化、规划动作、模拟推演 |
| 代表作 | GPT、Claude、Kimi | Genie 3、Marble、V-JEPA |

> [!example] 一个直观对比
> 问 LLM"杯子从桌上推下去会怎样"→ 它背诵"会碎"。
> 世界模型则在内部**模拟**杯子下落、碰撞、破碎的过程——它"看见"了因果，而不只是复述过因果。

## 历史渊源

这个概念并不新：2018 年 David Ha 和 Schmidhuber 的论文《World Models》就让它出圈过一次（AI 在"梦"里学开车）；2024-2026 年随着视频生成和具身智能爆发，它成为兵家必争之地。

## 和我有什么关系（学习/求职视角）

- **做 Agent 应用开发**：暂时不用深入，但要知道这个风向——Agent + 世界模型 = 能在模拟环境里先"排练"再行动的智能体，是下一个产品形态
- **想走训练/研究方向**：世界模型是 2026 最热的选题之一（四大技术路线：渲染器、仿真器、JEPA 类、视频生成派）
- **面试谈资**：[[AI面试八股文]] 里的"前景与趋势"类开放题，聊世界模型是加分项
