# 低代码与 Workflow 平台

## 工作流 Workflow 是什么

**工作流（Workflow）** 是把一个多步骤任务画成一张"流程图"：节点是步骤（调 LLM、查数据库、发邮件…），连线是数据流向，按图自动执行。

比如"每天早上总结我的待办并发到微信"这个任务，拆成工作流就是：

```
定时触发 ──▶ 读取待办数据 ──▶ 调 LLM 生成总结 ──▶ 发送到微信
(8:00)        (查数据库)        (写 Prompt)         (调接口)
```

## 低代码 / 无代码是什么

- **无代码（No-Code）**：完全不写代码，纯拖拽节点、填表单就拼出应用。
- **低代码（Low-Code）**：拖拽为主，关键环节允许插一小段代码（通常是 Python/JavaScript）兜底。

对 AI 应用来说，这类平台把"调 LLM + 连知识库 + 接外部工具"做成了现成节点，**不用写后端就能拼出一个能跑的 [[Agent智能体]]**。

## 三大平台对比

| 维度 | Dify | Coze（扣子） | n8n |
| --- | --- | --- | --- |
| 定位 | LLM 应用开发平台 | 字节跳动的 AI Bot 搭建平台 | 通用自动化工作流工具（AI 是其中一类节点） |
| 部署 | 开源自部署 / 官方云服务 | 纯云端，国内版+海外版 | 开源自部署 / 官方云服务 |
| 上手难度 | 中（概念接近开发者思维） | 最低（拖拽 + 大量现成模板） | 中（节点多、概念偏自动化） |
| 发布渠道 | Web 应用、API、嵌入网站 | 一键发布到抖音/飞书/微信等字节生态 | 主要是 API 和定时触发 |
| 代码扩展 | 支持 Python/JS 代码节点 | 支持代码节点和插件 | 支持 Code 节点，自由度最高 |
| 适合 | 想认真做 AI 应用的个人/团队 | 快速搭 Bot、吃字节生态流量 | 把 AI 接进各种 SaaS 的自动化流程 |

> [!tip] 零基础怎么选
> 想最快看到成果选 **Coze**；想做正经 AI 产品、将来可能迁移到自己服务器选 **Dify**；需求是"把 A 工具和 B 工具连起来自动化"（顺便用下 AI）选 **n8n**。

> [!example] 动手感受一下：在 Dify/Coze 里搭一个"读书笔记 Bot"
> 不写一行代码，大致四步：
> 1. **新建应用**：选一个对话型应用模板。
> 2. **写人设 Prompt**：告诉模型"你是读书助手，回答要引用书里的原文"，见 [[Prompt与提示词工程]]。
> 3. **挂知识库**：上传几本书的 PDF/EPUB 摘录，平台自动完成切分和向量化——这就是 [[RAG检索增强生成]] 的可视化版本。
> 4. **发布**：生成一个网页链接或嵌入代码，分享给朋友就能用。
>
> 全程 10 分钟左右。亲手拖一遍，比读十篇概念文章更能理解 RAG 和 Agent 是怎么回事。

## 低代码 vs 写代码做 Agent

| 维度 | 低代码平台 | 自己写代码 |
| --- | --- | --- |
| 出活速度 | 半天到一天搭出原型 | 按周计 |
| 灵活度 | 受平台节点能力限制，复杂逻辑拼不动 | 无上限，想怎么做就怎么做 |
| 数据控制 | 数据过平台的手（自部署可缓解） | 完全在自己手里 |
| 可维护性 | 逻辑复杂后流程图会变成"意大利面" | 代码可测试、可版本管理（见 [[Git与版本控制]]） |
| 成本 | 平台订阅费 + 模型调用费 | 服务器费 + 模型调用费 |
| 学到的东西 | 平台操作（迁移会打折） | 可迁移的编程和架构能力 |

> [!note] 务实的策略
> - **验证想法阶段**：用低代码平台，半天拼出原型给真人用，确认需求存在。
> - **认真做产品阶段**：迁移到代码实现（Python + FastAPI + Agent 框架），获得完全的控制力，路线见 [[Agent开发总览]]。
> - 两者不是对立关系：很多团队长期用 n8n 做内部自动化，同时用代码做核心产品。

## 为什么这对 AI 开发很重要

1. **低代码平台是最好的"Agent 概念教具"**：RAG、工具调用、多步推理这些概念，在 Dify/Coze 里拖一遍节点就直观理解了，再去看 [[Agent开发总览]] 会顺畅很多。
2. **它定义了"够用"的基准线**：如果一个 Agent 用 Coze 十分钟能搭出来，就别花一周写代码；反过来，平台拼不动的需求，就是你必须学会写代码的理由。
3. **非技术同事也能参与**：运营、产品可以在平台上自己改 Prompt、调流程，不用排队等开发。

> [!warning] 常见误区
> - **平台锁定**： workflow 在平台之间不通用，Dify 的流程图导不到 n8n。重度依赖前先想清楚迁移成本。
> - **忽视账单**：工作流跑起来后每个节点都可能调 LLM，循环节点配置不当会一夜刷爆 API 额度，务必先用小数据量测试。
> - **用低代码做所有事**：涉及复杂数据处理、高并发、精细权限控制的场景，平台的拖拽会很快到极限，该写代码就写代码。
