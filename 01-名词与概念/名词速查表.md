# 名词速查表

> [!note] 模块简介
> 本模块是「AI 开发学习」知识库的名词词典，目标是让零基础读者在动手写代码之前，先把 AI 领域最高频的 13 个核心概念、以及 9 个开发向工程名词搞清楚。每个名词都有一篇独立笔记，包含定义、原理、代码示例或对比表格，以及和其他模块笔记的双链。

## 名词一览表

| 名词 | 一句话解释 | 详细笔记 |
| --- | --- | --- |
| LLM（大语言模型） | 用海量文本训练、能理解和生成自然语言的巨型神经网络 | [[LLM大语言模型]] |
| Token（词元） | 模型处理文本的最小单位，计费与上下文长度都按它计算 | [[Token与分词]] |
| Prompt（提示词） | 发给模型的输入指令，写好它是使用 AI 的第一项技能 | [[Prompt与提示词工程]] |
| Embedding（向量嵌入） | 把文本变成一串数字向量，让语义可以被数学计算 | [[Embedding向量嵌入]] |
| RAG（检索增强生成） | 先从知识库检索资料、再让模型基于资料回答的技术 | [[RAG检索增强生成]] |
| 微调（Fine-tuning） | 在预训练模型基础上用专属数据继续训练，改变模型行为 | [[微调Fine-tuning]] |
| 幻觉（Hallucination） | 模型一本正经地编造不存在的内容 | [[幻觉Hallucination]] |
| 上下文窗口 | 模型一次能"看到"的文本总量，超出部分会被遗忘 | [[上下文窗口]] |
| Agent（智能体） | 能自主规划、调用工具、多步执行任务的 LLM 应用形态 | [[Agent智能体]] |
| Function Calling（函数调用） | 让模型输出结构化 JSON 来请求程序执行某个函数 | [[FunctionCalling函数调用]] |
| MCP（模型上下文协议） | Anthropic 提出的开放协议，统一模型与外部工具的连接方式 | [[MCP模型上下文协议]] |
| 多模态 | 模型同时处理文本、图像、音频、视频等多种输入输出 | [[多模态]] |
| 世界模型 | 让 AI 学会世界运转规律（物理/空间/因果）、能内部模拟推演的下一代模型方向 | [[世界模型]] |
| 温度（Temperature） | 控制输出随机性的参数，越高越发散、越低越稳定 | [[幻觉Hallucination]] |

## 开发向名词（工程基础）

以下 9 个名词是做 AI 应用绕不开的通用开发概念，建议在学完上面的 AI 名词后补充。

| 名词 | 一句话解释 | 详细笔记 |
| --- | --- | --- |
| 全栈开发 | 一个人覆盖前端、后端、数据库全部技术层的开发方式 | [[全栈开发]] |
| 前端与后端 | 前端是用户看到的界面，后端是服务器上跑的逻辑，两者靠 API 通信 | [[前端与后端]] |
| API（接口） | 程序与程序之间约定好的对讲窗口，调 LLM 就是在调 API | [[API接口]] |
| SDK / 框架 / 库 | 别人写好拿来用的代码：库是工具箱、框架是流水线、SDK 是全家桶 | [[SDK框架与库]] |
| 数据库 | 负责数据持久化、高效查询、并发读写的软件，AI 应用还离不开向量数据库 | [[数据库入门]] |
| Git（版本控制） | 给代码持续存档的工具，vibe coding 时最重要的防翻车手段 | [[Git与版本控制]] |

## 推荐学习顺序

> [!tip] 三步走
> 1. **打地基**：先读 [[LLM大语言模型]] → [[Token与分词]] → [[Prompt与提示词工程]]，理解模型是什么、怎么吃文本、怎么下指令。
> 2. **学增强**：再读 [[Embedding向量嵌入]] → [[RAG检索增强生成]] → [[微调Fine-tuning]] → [[幻觉Hallucination]] → [[上下文窗口]]，掌握让模型"知道更多、答得更准"的手段。
> 3. **进进阶**：最后读 [[Agent智能体]] → [[FunctionCalling函数调用]] → [[MCP模型上下文协议]] → [[多模态]]，进入 Agent 开发的大门。

## 学习建议

- **不要背定义**：每个概念都动手跑一遍笔记里的代码示例，理解会牢固得多。Python 还没学的先去 [[Python学习路线]] 和 [[环境搭建与包管理]]。
- **带着问题学**：比如读 RAG 之前先想"模型不知道我公司内部文档怎么办"，带着问题读效率更高。
- **善用双链**：每篇笔记结尾都有「相关笔记」，顺着双链在模块之间跳转，能把孤立概念连成知识网络。
- **学完去实践**：概念学完后建议直接进入 [[Agent开发总览]] 或 [[AI辅助开发总览]]，在项目中巩固。
