# 训练、推理与采样参数

## 训练 vs 推理

[[LLM大语言模型]] 的一生分两个阶段，搞混它们是很多误解的根源：

| 维度 | 训练 Training | 推理 Inference |
| --- | --- | --- |
| 干什么 | 用海量语料调整模型参数，让模型"学会"语言规律 | 模型参数固定不动，根据输入生成输出 |
| 类比 | 上学读书、备考 | 上考场答题 |
| 成本 | 天价（成千上万张 GPU 跑几个月） | 便宜（一次请求几厘到几分钱） |
| 谁在做 | 模型厂商（OpenAI、阿里、DeepSeek…） | **你**——每次调 API 都是在做推理 |
| 结果 | 产出一个模型文件 | 产出一段文本 |

> [!note] 关键结论
> 普通开发者**几乎只做推理**（调 API），顶多做 [[微调Fine-tuning]]（在训练好的模型上小修小补）。你的 Prompt、参数都作用在推理阶段，不会反过来改变模型本身。

## 推理时最常调的三个参数

调用模型 API 时，除了模型名和消息，最常调的就是这三个**采样参数**：

```python
resp = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "给咖啡店起个名字"}],
    temperature=0.2,    # 随机性
    top_p=0.9,          # 候选词范围
    max_tokens=200,     # 输出长度上限
)
```

### 1. temperature（温度）：控制随机性

模型每生成一个 [[Token与分词]]，都是从一堆候选词的概率分布中"抽"一个。temperature 决定抽得有多野：

| 取值 | 效果 | 适合场景 |
| --- | --- | --- |
| 0 ~ 0.3 | 几乎总选最可能的词，输出稳定、可复现 | 信息提取、分类、代码生成、事实问答 |
| 0.7 ~ 1.0 | 适度发散 | 日常对话、文案 |
| 1.0 以上 | 抽风模式，可能出现怪词 | 头脑风暴、诗歌创作 |

同一个 Prompt"给咖啡店起个名字"的效果对比：

> [!example] 温度对比示例
> - **temperature=0.1**：连问三次都得到"晨光咖啡""街角咖啡"这类稳妥常规的名字，几乎不变。
> - **temperature=1.2**：可能蹦出"咖啡因逃逸计划""豆子的平行宇宙"——惊喜和惊吓并存。

### 2. top_p（核采样）：控制候选范围

只从累积概率达到 p 的**最小候选词集合**里抽。`top_p=0.1` 表示只考虑概率最高的前 10% 的词，效果接近低温；`top_p=1.0` 表示所有词都有可能。

> [!tip] temperature 和 top_p 别同时调
> 两个都是控制随机性的，效果重叠。官方建议**只调一个，另一个保持默认**。新手只动 temperature 就够了。

### 3. max_tokens：输出长度上限

限制模型最多生成多少个 token（计费单位，见 [[Token与分词]]）。设小了回答会被截断（话说到一半戛然而止）；设大了不省钱——模型按实际生成量计费，max_tokens 只是天花板。注意它只限**输出**，输入长度受 [[上下文窗口]] 限制。

## 为什么调低 temperature 能减少幻觉

[[幻觉Hallucination]] 的一大来源就是随机抽样：概率分布里排第二、第三的词有时是事实错误的选项，高温给了它们"中奖"机会。把 temperature 压到 0~0.2，模型几乎每次都选概率最高的词，也就是它"最有把握"的答案——**输出更保守，编造的余地更小**。

但要注意：

> [!warning] 低温不是幻觉的解药
> temperature=0 只能保证"同样输入给同样输出"，**不能保证输出是对的**——模型最有把握的答案也可能是错的。真正对抗幻觉要靠 [[RAG检索增强生成]]（给资料）、要求引用来源、人工核查。低温只是"少添乱"，不是"变聪明"。

## 选型速查：不同场景怎么设

| 场景 | temperature | max_tokens | 理由 |
| --- | --- | --- | --- |
| 从合同里提取日期金额 | 0 | 100 | 要精确、要稳定、答案短 |
| 客服问答（带 RAG） | 0.1~0.3 | 500 | 基于资料作答，少发挥 |
| 营销文案 / 起名 | 0.8~1.0 | 300 | 要创意、要多样性 |
| 代码生成 | 0~0.2 | 按需调大 | 代码讲究正确，不要惊喜 |
