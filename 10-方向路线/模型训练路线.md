# 模型训练路线（0 基础 → 后训练工程）

> [!note] 这条路线通向哪
> 大模型训练方向：微调工程师、后训练工程师、训练数据工程。**先泼冷水**：预训练研究岗要求硕博+论文，对双非基本关闭；现实路径是"数据工程 → 微调/后训练"（详见 [[大模型训练方向]]、[[双非出路与防坑指南]]）。全程约 10-14 个月，比 Agent 路线更吃数学和耐心。

## 路线全图

```text
阶段0  Python + 数学（1-2 月）
  ↓
阶段1  PyTorch 与深度学习（1-2 月）
  ↓
阶段2  系统课打理论（2-3 月，可与阶段1并行）
  ↓
阶段3  从零实现 LLM——"识字关"（1-2 月）
  ↓
阶段4  微调实战（1 月）
  ↓
阶段5  后训练深入（长期）
```

## 阶段 0：Python + 数学（1-2 月）

| 项 | 内容 |
| --- | --- |
| Python | [[小白课堂总览]] Python 篇 7 课（同 Agent 路线，地基共用） |
| 数学 | [[PyTorch与数学基础]] 的清单：线性代数（向量、矩阵乘法）、微积分（导数、链式法则）、概率（期望、常见分布） |
| **自测** | 能手算两个 2×2 矩阵相乘；说清"导数告诉你什么" |

## 阶段 1：PyTorch 与深度学习（1-2 月）

| 项 | 内容 |
| --- | --- |
| 学什么 | [[PyTorch与数学基础]]（PyTorch 最小技能集）+ 李沐《动手学深度学习》前 6 章（d2l.ai） |
| **自测** | 不看示例写出训练循环：`forward → loss → backward → optimizer.step()` |
| **产出** | 用 PyTorch 训练一个手写数字分类小网络（d2l 的入门实验） |

## 阶段 2：系统课打理论（2-3 月）

| 项 | 内容 |

## 阶段 3：从零实现 LLM（1-2 月）⭐ 识字关

| 项 | 内容 |
| --- | --- |
| 学什么 | [[从零实现LLM专题]]：跟 rasbt/LLMs-from-scratch 逐章敲（数据处理→注意力→GPT 架构→预训练→微调） |
| 配套 | [[Raschka教授资源全集]]；Karpathy nanoGPT（[[从零实现LLM专题]] 内有对比） |

| **意义** | 没手写过，训练框架的代码对你永远是天书——这关绕不过 |

## 阶段 4：微调实战（1 月）

| 项 | 内容 |
| --- | --- |
| 学什么 | [[微调Fine-tuning]]（LoRA/QLoRA/SFT/DPO 概念）→ 用 **LLaMA-Factory** 完整跑一次：LoRA 微调一个开源小模型 + 一次 DPO |
| 资源 | [[大模型训练方向]] 资源表：LLaMA-Factory、Datawhale self-llm、tiny-llm-zh |
| **产出** | 一个微调前后效果对比的小实验报告（几条 case 就够） |

## 阶段 5：后训练深入（长期）

- 读 [[Raschka教授资源全集]] 的 reasoning-from-scratch：推理模型是怎么被 RL 训出来的
- 读 verl（字节 RL 后训练框架）的训练流程，理解 GRPO/PPO 在工程里怎么落地
- 关注 [[大模型训练方向]]：数据工程是最现实的切入口（可接数据标注实习经验）
