# 主路线：从 0 基础到 AI 职业（一条脊柱走到底）

> [!note] 怎么用这篇
> 这是全库的**总路线**：把 Python、Agent 开发、模型训练、接单/FDE 串成一条线，每阶段有自测和产出，过了才进下一阶段。其他攻略（[[Agent开发工程师路线]]、[[模型训练路线]]）是这条脊柱上某几段的放大镜。
> **觉得乱的时候，回到这一页，找到你的当前位置，接着走。**

## 脊柱全图

```text
阶段0  Python 地基（练习场 50 题）        ← 你在这里（py-5 函数）
阶段1  Python 进阶 + 全栈基础（4-6 周）
阶段2  AI 概念打通（1-2 周）
阶段3  Agent 开发实战（4-6 周）
阶段4  交付能力成型：两套模板（4-8 周）
阶段5  训练技能加成：微调（2-4 周，溢价技能）
阶段6  出口：接单 / 求职 / FDE
```

## 三条铁律

1. **一次只走一个阶段**，后面的阶段只收藏不开工
2. **自测不过不进阶**——跳阶段是"觉得乱"的根源
3. **每天闭环**：默写 10 分钟 + 主线 40 分钟 + 费曼复述 5 分钟（[[每日学习清单]]）
