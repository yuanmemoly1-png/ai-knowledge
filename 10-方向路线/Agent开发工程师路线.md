# Agent 开发工程师路线（0 基础 → 能交付）

> [!note] 这条路线通向哪
> 两个出口任选：**Agent/应用开发岗求职**，或**团队技术支持接单**（队友接单、你交付）。全程约 6-9 个月（每天 1-2 小时），每阶段有自测，过不了不进下一阶段。

## 路线全图

```text
阶段0  Python 地基（4-6 周）
  ↓
阶段1  AI 概念打通（1-2 周）
  ↓
阶段2  亲手写出第一个 Agent（2-3 周）
  ↓
阶段3  框架与工程化（4-6 周）
  ↓
阶段4  攒作品 / 交付模板（4-8 周）
  ↓
阶段5  求职 或 接单变现
```

## 阶段 0：Python 地基（4-6 周）

| 项 | 内容 |
| --- | --- |
| 学什么 | [[小白课堂总览]] Python 篇 7 课（变量→字符串→列表字典→条件循环→函数→文件读写→[[小白课-程序拆解实战]]） |
| 工具书 | [[基础语法速查]]、[[常用数据结构与函数]]（卡住时查，不用背） |

| **自测** | 不看笔记独立写出：读 txt 统计词频前 10（[[Python学习路线]] 阶段一标准） |

## 阶段 4：攒作品 / 交付模板（4-8 周）

> 两个出口，选一个主走：

**出口 A：接单技术支持**
- 按 [[AI职业全景]] 的单子类型表，攒 **2 个可复用模板**：
  1. RAG 知识库问答模板（[[RAG检索增强生成]] + [[工具调用实战]]）
  2. Agent 工作流自动化模板（[[LangGraph状态图]] / [[低代码与Workflow平台]]）
- 缺前端就补 [[全栈学习路线]] 的 ①② 阶段

**出口 B：求职**
- 按 [[AgentGuide项目拆解]] 的"8 阶段产出"做 2 个项目，用"简历三维表达法"包装
