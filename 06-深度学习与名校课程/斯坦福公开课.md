# 斯坦福公开课

斯坦福的 CS 课程以「主页公开全部资料」著称：讲义、作业、课程笔记甚至视频都可以免费获取。本笔记按学习顺序整理与 AI 相关的七门课。

> [!note] 使用方式
> 斯坦福课程主页通常包含 syllabus（教学大纲）、lecture notes（讲义）、assignments（作业）。视频部分在 YouTube 或课程主页，按学期年份找最新版。部分年份页面会迁移，主页打不开时搜索「课程号 + stanford + 年份」。

## 课程索引

### CS229 机器学习（Andrew Ng）

- 主页：[cs229.stanford.edu](https://cs229.stanford.edu)
- 主题：经典机器学习的数学化讲解——线性/逻辑回归、SVM、朴素贝叶斯、聚类、EM 算法、强化学习初步。
- 先修要求：线性代数、概率论、多元微积分（见 [[PyTorch与数学基础]]）。
- 资料形态：完整讲义（notes 质量极高）+ 作业 + 历年视频。
- 特点：数学推导重，是「知其所以然」的 ML 课；Andrew Ng 版本流传最广。
- 适合：想打牢 ML 理论基础的学习者。只想快速上手可先用 [[Raschka教授资源全集]] 的 machine-learning-book。

### CS230 深度学习

- 主页：[cs230.stanford.edu](https://cs230.stanford.edu)
- 主题：深度学习通用课——MLP、CNN、RNN、优化方法、项目实战，相当于 CS229 的深度学习续篇。
- 先修要求：CS229 或同等 ML 基础。
- 资料形态：讲义 + 作业 + 视频（含 Andrew Ng 授课版本）。
- 适合：已有 ML 基础，想系统过一遍深度学习知识体系。

### CS231n 计算机视觉（CNN 经典课）

- 主页：[cs231n.stanford.edu](https://cs231n.stanford.edu)
- 课程笔记：[cs231n.github.io](https://cs231n.github.io)
- 主题：图像分类、CNN 架构演进（AlexNet→ResNet）、目标检测、图像生成、注意力机制。
- 先修要求：Python、基础线性代数；PyTorch/TF 会随课程教。
- 资料形态：公开课程笔记（被奉为经典教材）+ 作业（手写反向传播是招牌作业）+ YouTube 有 2016/2017 完整录像。
- 特点：手写 numpy 版反向传播与 CNN，是理解自动求导背后原理的最佳训练。
- 适合：所有人，即使不做 CV——它对「理解神经网络如何学习」帮助极大。

### CS224n NLP 与深度学习

- 主页：[web.stanford.edu/class/cs224n](https://web.stanford.edu/class/cs224n/)
- 主题：词向量（Word2Vec/GloVe）、RNN/LSTM、seq2seq、注意力、Transformer、预训练语言模型。
- 先修要求：Python、机器学习基础。
- 资料形态：讲义 + 作业（含手写 Word2Vec 与句法分析）+ YouTube 有完整录像。
- 适合：想理解 [[Embedding向量嵌入]] 和 Transformer 来龙去脉的学习者，是通往 LLM 的桥梁课。

### CS224u 自然语言理解

- 主页：[web.stanford.edu/class/cs224u](https://web.stanford.edu/class/cs224u/)
- 主题：自然语言推理、语义理解、模型评估与鲁棒性，比 CS224n 更偏「理解」与前沿研究。
- 先修要求：CS224n 或同等 NLP 基础。
- 资料形态：讲义 + 代码 notebook + 项目。
- 适合：CS224n 学完后想深入 NLU 方向。

### CS336 Language Modeling from Scratch

- 主页：[stanford-cs336.github.io/spring2025](https://stanford-cs336.github.io/spring2025/)
- 主题：大语言模型从零构建——Tokenizer、Transformer 实现、训练、并行与扩展、数据工程、对齐。
- 先修要求：熟练 PyTorch、扎实的深度学习基础。
- 资料形态：讲义 + 硬核作业（作业本身就是「从零实现 LLM」）。
- 详细对比见 [[从零实现LLM专题]]。
- 适合：目标是 LLM 训练/Infra 工程师的进阶者。

### CS25 Transformers United 研讨课

- 主页：[web.stanford.edu/class/cs25](https://web.stanford.edu/class/cs25/)
- 主题：Transformer 各领域应用的研讨课（seminar），邀请一线研究者演讲，覆盖 LLM、视觉、生物、机器人等方向。
- 先修要求：了解 Transformer 基本原理。
- 资料形态：讲座视频（YouTube）为主，轻作业。
- 特点：门槛最低的斯坦福课，适合当作「追踪 Transformer 前沿应用」的视频播客。
- 适合：已有基础、想开阔眼界了解 [[多模态]] 与前沿应用。

## 选课建议

```text
ML 理论：CS229
  ↓
DL 体系：CS230（或直接用李沐 d2l 替代）
  ↓
按兴趣分流：
  ├── NLP/LLM：CS224n → CS224u → CS336
  ├── CV：CS231n
  └── 前沿视野：CS25（随时可看）
```

> [!tip] 性价比最高的组合
> 中文自学者常见路线：李沐 d2l（替代 CS229/230）→ CS224n 视频（理解 Transformer 起源）→ CS336 或 [[从零实现LLM专题]] 中的 LLMs-from-scratch（动手实现）。
