# 深度学习课程总览

本模块面向想系统自学深度学习、理解 LLM 底层原理的学习者。市面上的 AI 应用开发教程大多只教「调 API」，而本模块收集的是能让你真正理解模型内部机制的名校公开课与名师开源资源——从数学基础到手写 Transformer，再到从零实现一个完整的 GPT。

> [!note] 为什么需要深度学习基础？
> 只会调用 API 的开发者容易在遇到幻觉、Token 超限、微调效果不佳等问题时无从下手。理解 Embedding、注意力机制、预训练与微分的原理，是从「AI 使用者」进阶为「AI 开发者」的分水岭。

## 推荐学习路线

```text
数学/Python 基础
      ↓
机器学习（ML 经典算法与思维）
      ↓
深度学习（MLP → CNN → RNN → Transformer）
      ↓
LLM 原理（Tokenizer、预训练、微调、RLHF）
      ↓
从零实现（手写 GPT / 手写推理模型）
      ↓
方向选修（CV / RL / 高效推理 / Agent）
```

> [!tip] 时间投入参考
> - 每天 1-2 小时：走完「数学基础 → 深度学习 → LLM 原理」约需 6-9 个月。

> - 不要试图全部学完：选定一条主线，其余资源按需查阅。

> [!warning] 常见误区
> 1. **屯课不学**：收藏十几门课却一门没看完，不如精读一门并做完作业。
> 2. **跳过代码**：只看视频不动手，等于没学。每门课至少要复现核心代码。
> 3. **轻视数学**：不需要数学系水平，但矩阵乘法、链式法则、贝叶斯必须过关，见 [[PyTorch与数学基础]]。
