# PyTorch 与数学基础

数学与 PyTorch 是进入深度学习之前的两块垫脚石。本笔记回答两个问题：**数学到底要学到什么程度**（具体到知识点），以及 **PyTorch 怎么学最快**。

## 核心资源

### 李沐《动手学深度学习》（d2l）

- 主页：[zh.d2l.ai](https://zh.d2l.ai)
- 定位：免费中文书 + 视频，PyTorch 版，中文自学者的事实标准入门教材。
- 内容：从线性回归手写实现讲起，覆盖 MLP、CNN、RNN、注意力、Transformer、优化算法；每节都是「原理 + 可运行代码」。
- 特点：所有代码免费在线可跑（含 Colab），李沐的讲解兼顾直觉与工程细节。
- 用法：通读前 10 章（到注意力机制），即可衔接 [[从零实现LLM专题]]。

### PyTorch 官方教程

- 主页：[pytorch.org/tutorials](https://pytorch.org/tutorials/)
- 内容：60 分钟快速上手（Deep Learning with PyTorch: A 60 Minute Blitz）、张量、自动求导、数据加载、训练循环、保存与部署。
- 用法：当参考手册——d2l 学主线，遇到不熟的 API 来官方教程查。

### 3Blue1Brown

- 主页：[www.3blue1brown.com](https://www.3blue1brown.com)
- 内容：用动画讲透数学直觉——《线性代数的本质》《微积分的本质》《神经网络》三个系列与本模块直接相关。
- 特点：不教计算技巧，教「几何直觉」；看完《神经网络》系列（4 集），你会真正理解梯度下降在做什么。
- 用法：学每个数学板块前先看对应系列，建立直觉后再补计算。

### 《深度学习》（花书，Goodfellow 等）

- 主页：[www.deeplearningbook.org](https://www.deeplearningbook.org)
- 定位：深度学习领域最权威的教科书，免费在线阅读。
- 特点：理论性强、覆盖全面，但偏学术、无代码。
- 用法：**不建议通读**，当作工具书——遇到概念（如某种正则化、优化算法）想深挖时查对应章节。

## 数学基础清单

深度学习对数学的要求是「理解概念 + 会算基础题」，不是数学系证明水平。按优先级整理如下：

### 线性代数（最重要）

必须掌握：

- 向量与矩阵的运算：加减、数乘、**矩阵乘法**（重点，注意维度匹配 `(m,k)×(k,n)→(m,n)`）
- 转置、逆矩阵的概念（知道什么时候不可逆即可）
- 点积（内积）的几何意义：相似度——这正是 [[Embedding向量嵌入]] 检索的原理
- 矩阵-向量乘法的视角：线性变换（3Blue1Brown 线性代数系列讲的就是这个）
- 特征值/特征向量：了解概念即可，不必会手算

加分项（进阶）：

- SVD 分解、PCA（理解降维）
- 矩阵求导的常用公式（读论文时会遇到）

### 微积分

必须掌握：

- 导数与偏导数的含义：函数在某方向的变化率
- **链式法则**：反向传播的全部数学基础，必须熟练
- 梯度的几何意义：函数增长最快的方向 → 梯度下降就是反方向走
- 常见函数的导数：`x^n`、`e^x`、`ln(x)`、`sigmoid`、`ReLU` 的分段导数

加分项：

- 多元函数的雅可比矩阵（理解即可）
- 泰勒展开（理解优化算法时会用到）

> [!example] 链式法则 = 反向传播
> 设 `L = f(g(x))`，则 `dL/dx = f'(g(x)) · g'(x)`。神经网络就是把几十层这样的复合函数逐层求导——PyTorch 的 `loss.backward()` 替你自动完成这件事。

### 概率论与统计

必须掌握：

- 条件概率与**贝叶斯公式**
- 常见分布：正态分布、均匀分布、伯努利分布
- 期望、方差、协方差
- **极大似然估计（MLE）**：理解「训练 = 最大化数据的似然」
- 交叉熵：分类任务损失函数的来源，理解「-log(正确类别的概率)」
- 过拟合/欠拟合、训练集/验证集/测试集的划分思想

加分项：

- KL 散度（理解 RLHF、蒸馏时会用到）
- 贝叶斯推断的基本思想

### 学习检验标准

| 检验问题 | 对应知识 |
| --- | --- |
| 能手算两个 2×2 矩阵相乘并说清维度规则 | 线性代数过关 |
| 能写出 `y = sigmoid(wx + b)` 对 `w` 的导数 | 微积分过关 |
| 能解释为什么分类用交叉熵而不用均方误差 | 概率论过关 |

## PyTorch 最小技能集

开始任何深度学习课程前，以下代码应当能看懂并默写大意：

```python
import torch
import torch.nn as nn

# 1. 张量：深度学习的基本数据结构
x = torch.tensor([[1.0, 2.0], [3.0, 4.0]])
w = torch.randn(2, 3, requires_grad=True)   # 可求导的参数

# 2. 前向传播
y = x @ w                       # 矩阵乘法
loss = y.pow(2).mean()          # 均方误差

# 3. 反向传播：自动求导
loss.backward()
print(w.grad)                   # d(loss)/d(w)

# 4. 优化器更新参数
optimizer = torch.optim.SGD([w], lr=0.01)
optimizer.step()                # w ← w - lr * grad
optimizer.zero_grad()           # 清空梯度，准备下一轮

# 5. 用 nn.Module 搭一个线性层
model = nn.Linear(in_features=2, out_features=3)
out = model(x)                  # 等价于 x @ W.T + b
```
