# 其他名校与名师

除斯坦福、MIT、CMU 外，全球还有一批质量极高且完全开放的课程与名师资源。本笔记按「体系课 → 中文资源 → 实战派」组织。

## 名校体系课

### NYU 深度学习（Yann LeCun & Alfredo Canziani）

- 主页：[atcold.github.io/pytorch-Deep-Learning](https://atcold.github.io/pytorch-Deep-Learning)
- 主题：图灵奖得主 Yann LeCun 参与开设的深度学习课，以 PyTorch 为教学框架，覆盖 MLP、CNN、RNN、注意力、自监督学习、能量模型（EBM，LeCun 的特色视角）。
- 先修要求：Python、机器学习基础。
- 资料形态：讲义网站（多语言，含中文翻译版）+ notebook + YouTube 完整录像。
- 特点：能量模型视角独树一帜；Alfredo Canziani 的可视化讲解非常出彩。
- 适合：学完入门课后想换「大师视角」重看一遍深度学习。

### UC Berkeley CS285 深度强化学习（Sergey Levine）

- 主页：[rail.eecs.berkeley.edu/deeprlcourse](https://rail.eecs.berkeley.edu/deeprlcourse/)
- 主题：深度强化学习标准课——MDP、Q-learning、策略梯度、Actor-Critic、模型学习、离线 RL。
- 先修要求：深度学习基础、概率论。
- 资料形态：YouTube 完整录像 + 讲义 + 作业（实现 RL 算法）。
- 特点：RL 领域最流行的公开课，Sergey Levine 的讲义逻辑严密。
- 适合：想理解 RLHF（大模型对齐的核心技术之一）或做机器人/决策方向的学习者。

### UC Berkeley LLM Agents 课程（CS 194/294-196，2024 秋）

- 主页：[llmagents-learning.org](https://llmagents-learning.org)
- 主题：大语言模型 Agent 专题——推理、规划、工具使用、多 Agent 系统、评估，讲师含一线业界研究者。
- 先修要求：了解 LLM 基本原理。
- 资料形态：讲座视频 + slides。
- 适合：与本库的 [[Agent开发总览]] 模块互为补充——那边教工程实现，这门课讲研究视角。

### Princeton COS 597G Understanding Large Language Models（Danqi Chen）

- 主页：[cs.princeton.edu/courses/archive/fall22/cos597G](https://www.cs.princeton.edu/courses/archive/fall22/cos597G/)
- 主题：研究生研讨课——预训练、Prompt、上下文学习（In-context Learning）、指令微调、对齐，以论文精读为主线。
- 先修要求：NLP 与深度学习基础。
- 资料形态：syllabus + 论文清单 + 部分 slides。
- 特点：论文清单本身就是一份极佳的「LLM 必读文献地图」，主讲人 Danqi Chen 是指令微调方向的重要研究者。
- 适合：想读论文、做研究的学习者。

### Cornell CS4780 机器学习（Kilian Weinberger）

- 主页：[cs.cornell.edu/courses/cs4780/2018fa](https://www.cs.cornell.edu/courses/cs4780/2018fa/)
- 主题：机器学习标准课——从感知机到 SVM、树模型、集成方法、聚类，讲解风格偏直觉化。
- 先修要求：基础数学、Python。
- 资料形态：YouTube 有完整录像 + 讲义 + 作业。
- 特点：Kilian 讲课幽默清晰，被认为是「讲得最好懂的 ML 课」之一；可作 CS229 的替代/补充。
- 适合：觉得 CS229 数学太重的学习者。

## 中文资源

### 台大李宏毅 机器学习 / 生成式 AI

- 主页：[speech.ee.ntu.edu.tw/~hylee/index.html](https://speech.ee.ntu.edu.tw/~hylee/index.html)
- 主题：机器学习、深度学习、生成式 AI（近年重点：LLM 原理、微调、对齐）。
- 资料形态：YouTube 完整录像（中文授课），B 站有大量搬运（B站搜索「李宏毅」）。
- 特点：中文圈最流行的 ML/DL 课程，讲解生动、用动漫例子讲概念，每年更新；生成式 AI 系列对理解 ChatGPT 类模型非常友好。
- 适合：中文学习者入门首选之一，与李沐 d2l（见 [[PyTorch与数学基础]]）并称中文两大入门资源。

## 实战派与科普向

### fast.ai

- 主页：[course.fast.ai](https://course.fast.ai)
- 主题：「自上而下」教学法——第一课就训练出可用的图像分类器，再逐层向下揭开原理；覆盖 CV、NLP、表格数据、推荐系统。
- 先修要求：只需 Python 基础，刻意不要求数学先行。
- 资料形态：免费视频 + 配套书《Deep Learning for Coders with fastai and PyTorch》+ fastai 库。
- 特点：与学院派路线相反，主张「先做出东西再理解原理」；fastai 库封装度高，能快速出成果。
- 适合：实践导向、学理论容易放弃的开发者。

> [!tip] 学院派 vs fast.ai
> 两条路线没有优劣：学院派（CS229/CS231n）先原理后应用，适合想走远的人；fast.ai 先应用后原理，适合需要快速建立正反馈的人。也可以并行：用 fast.ai 保持兴趣，用学院课补底层。

### 哈佛 CS50 AI with Python

- 主页：[cs50.harvard.edu/ai](https://cs50.harvard.edu/ai/)
- 主题：AI 通识课——搜索、知识表示、逻辑、优化、传统 ML、神经网络、NLP，用 Python 小项目驱动。
- 先修要求：基础编程。
- 资料形态：免费视频 + 作业（CS50 系列以制作精良著称）。
- 适合：编程经验少、想要平缓入门曲线的完全新手；偏经典 AI，深度学习部分较浅。

### DeepMind x UCL 强化学习讲座

- 获取方式：YouTube 搜索『DeepMind x UCL RL Lecture Series』。
- 主题：DeepMind 研究员主讲的 RL 系列讲座——从 MDP 基础到深度 RL、AlphaGo 背后的方法。
- 资料形态：视频讲座。
- 适合：作为 [[其他名校与名师]] 中 Berkeley CS285 的补充，或想听「AlphaGo 团队视角」讲 RL 的学习者。
