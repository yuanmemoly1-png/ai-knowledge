# AgentGuide 项目拆解（抖音"死磕这个项目"的真相）

> [!note] 来源
> 抖音账号「AI算法工程师Ray」反复推荐的"想找 Agent 方面的工作，建议死磕这个项目"，指的是开源仓库 **[AgentGuide](https://github.com/adongwanai/AgentGuide)**（约 7.6k stars）。作者阿东，自称一线大模型算法工程师，定位"对标 JavaGuide 的 AI Agent 学习指南"。本笔记基于其 README 全文拆解。

## 一句话定位

**从"什么是 Agent"到"拿 Offer"的一站式求职指南**：学习路线 + 简历级项目 + 1500+ 面试题库，全部围绕一个目标——让你从"我学过什么"变成"我做出了什么"。

## 仓库结构拆解

```text
① 求职新范式：1-2-5 框架（做出什么 > 学过什么）
② 第一步：选岗位（算法线 vs 开发线 vs 通吃）
③ 第二步：拿 Offer 方法论（两种岗位完全不同的简历写法）
④ 第三步：学习路线（算法岗 10-15 周 / 开发岗 8-12 周）
⑤ 第四步：实战项目（8 个简历级项目，每个配双岗简历写法）
⑥ 第五步：技术栈 L1-L3（概念 → 框架手撕 → RAG/上下文工程/微调/评估）
⑦ 第六步：面试冲刺（1500+ 题库、面经、LaTeX 简历模板）
```

## 精华提炼：对你最有价值的 5 个点

### 1. 求职新范式："做出什么 > 学过什么"
> 工具不再是壁垒，**你用工具做出的东西才是**。简历对比：
> - ❌「参与开发了一个 AI 客服系统」
> - ✅「基于 LangGraph + MCP 构建多 Agent 客服系统，工具调用成功率 94%，响应时长从 3.2s 降至 0.8s，日处理 10 万+ 对话」

### 2. 简历三维表达法
一个 Agent 项目要从三个维度写：**架构表达**（loop/工具注册/上下文裁剪/权限）+ **业务表达**（场景/用户路径）+ **结果表达**（评测集规模、通过率、成本优化）。这正好呼应 [[AI面试八股文]] 里"项目 > 八股"的判断。

### 3. 8 阶段产出 Todo List（从 50 行代码到可投递项目）

| 阶段 | 产出物 |
| --- | --- |
| Stage 1 | 50-150 行最小 Agent（对应 [[工具调用实战]]） |
| Stage 2 | 一个资料研究助手（RAG + Memory） |
| Stage 3 | 可调试的 Harness demo（对应 [[Agent-Harness脚手架]]） |
| Stage 4 | research → write → review 多智能体小系统 |
| Stage 5-6 | 可复用 SKILL / MCP 工具、browser agent |
| Stage 7-8 | 20 条 eval case + 一个别人能 clone 跑的 Agent 项目 |

### 4. 面试深水区 6 问（比八股更深一层）
Agent Loop 停止条件怎么设计？上下文和成本怎么平衡？工具选错怎么修？记忆什么时候该遗忘？评测集怎么来？可靠性六件套（幂等/超时/重试/成本护栏/权限分级/可观测）？

### 5. 岗位选择决策
算法线（论文/实验/创新，HC 少竞争烈）vs 开发线（系统/落地/业务指标，**岗位最多**）——对你的情况，**开发线（上下文工程开发方向）是最优解**，和 [[AI面试八股文]] 的岗位分类一致。

## 诚实评价（值不值得"死磕"）

> [!tip] 值得用，但别被宣传语绑架
> - ✅ 体系完整、求职导向强、题库和项目写法是实打实的干货，README 里"说几句实话"那几段（"语言不是门槛，设计才是""判断力才是壁垒"）是真懂行的话
> - ⚠️「8-10 周拿 Offer」对有经验的转行者成立，**对 0 基础的你不是现在的节奏**——它是你 3-6 个月后的主线，不是明天的任务
> - ⚠️ 8 个实战项目的详细教程多数还挂着"即将推出"，仓库在连载中；账号"资源简介自取"有引流成分，但仓库本身免费开源，取其精华即可
