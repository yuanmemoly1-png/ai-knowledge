# AI 职业全景（不只有开发岗）

> [!note] 给谁说
> 想进 AI 行业但不想/不只会写代码的人。AI 行业是一个完整生态，写代码只是其中一环。本篇把主要方向铺开，帮你在"入场"时选对第一块立足点。

## 七大方向全景图

| 方向 | 干什么 | 门槛 | 学历敏感度 | 代码要求 |
| --- | --- | --- | --- | --- |
| 🔬 研究与训练 | 预训练/后训练/推理优化 | 极高 | 极高（硕博+论文） | 极高 |
| 🛠️ 应用开发 | Agent/RAG 系统、AI 产品后端 | 中高 | 低（看作品） | 高 |
| 📊 数据与评测 | 训练数据生产、数据工程、模型评测 | 低-中 | 低 | 低→中（越走深越高） |
| 📋 产品与运营 | AI 产品经理、增长运营、创作者运营 | 中 | 低（看理解和表达） | 低（看得懂即可） |
| 🤝 解决方案与交付 | 售前、解决方案工程师、客户交付 | 中 | 中 | 中（能演示能改 demo） |
| 🛰️ FDE 前置部署 | 驻进客户现场，把 AI 从场景一路交付到生产 | 高 | 中低（看交付作品） | 高 |
| 🚀 独立开发者/内容 | 一人产品、AI 自媒体、知识付费 | 自雇 | 无 | 中（vibe coding 可起步） |

## 逐个说透

### 🔬 研究与训练
行业金字塔尖，薪资天花板最高（60-200 万），但入口最窄：顶会论文、名校硕博几乎是硬门票。详见 [[大模型训练方向]]。**对双非 0 基础：不作首选，可作长期理想。**

### 🛠️ 应用开发
岗位最多、学历最不敏感的技术岗。核心证据是可运行的项目。学习路径就是本库主线：[[Python学习路线]] → [[Agent开发总览]] → [[AgentGuide项目拆解]]。**你当前的主线。**

### 📊 数据与评测（被低估的入口）
- 干什么：构造 SFT/RLHF 训练数据、设计评测集、给模型输出打分、清洗和质检数据流水线
- 为什么是被低估的入口：**门槛最低、直接站在行业内部**，能近距离看到模型怎么被"喂"出来——你谈的那个数据标注实习就是这个方向的最底层
- 上升路径：标注员 → 数据工程/评测工程 →（补代码能力）→ 应用开发或训练数据策略
- 对接 [[微调Fine-tuning]]：标过数据的人学 SFT/RLHF 是有体感的

### 📋 产品与运营
- AI 产品经理：定义"AI 能做什么、该做成什么样"，需要懂模型能力边界（幻觉、上下文、成本），**不写代码但必须懂技术语言**——本库 01 模块就是为此准备的
- AI 运营/增长：热点嗅觉 + 内容能力，[[VibeCoding变现案例]] 里叶孤城的流量打法就是这一侧的能力
- 适合：表达好、对用户敏感、坐不住写代码的人

### 🤝 解决方案与交付
- 干什么：把 AI 产品卖给企业并落地：写方案、做 PoC 演示、驻场交付
- 要求：技术能聊（唬得住客户）+ 方案能写 + 能改 demo；to B 大厂（华为、阿里云、字节火山）需求量大
- 适合：技术中等但沟通强的人，薪资结构里提成占比高

### 🛰️ FDE 前置部署工程师（Forward Deployed Engineer，AI 落地工程师）

- **是什么**：源自 Palantir 的岗位模式，2024 年起被 OpenAI、Anthropic、谷歌云带火，国内字节（豆包 FDE）、蚂蚁数科、智谱都在招。岗位发布量 2025→2026 一年暴涨 7 倍以上。**注意 F 是 Forward（前线）不是 Front-End（前端）**
- **干什么**：驻进客户业务现场，从"识别 AI 能解决什么问题"开始，一路负责到系统在生产环境跑起来——**按业务结果结算，不按工时**。交付物典型是：RAG/Agent 系统、MCP 服务、子智能体（Anthropic 的 FDE JD 明确写 MCP、sub-agents、agent skills）
- **薪资参考**：Anthropic 基础年薪 20-30 万美金（含 25% 差旅）；字节豆包 FDE 月薪 3.5-7 万 × 15 薪
- **和"解决方案岗"的区别**：解决方案偏售前（写方案+演示），**FDE 偏交付（真写代码、真上线）**，工程师含量更高
- **需要的知识点**（本库对应笔记）：
  - 工程硬功：[[Python学习路线]]、[[API接口]]、[[数据库入门]]、[[部署与上线]]、[[全栈学习路线]]
  - AI 交付核心：[[RAG检索增强生成]]、[[Agent开发总览]]、[[Agent-Harness脚手架]]、[[MCP协议实战]]（FDE JD 点名技能）
  - 交付方法：[[VibeCoding方法论]]（快速出原型）、[[用AI开发App全流程]]、[[Agent评估与调试]]（生产化）
  - 软能力：把客户口语需求翻译成技术方案（AI 可辅助）、快速读懂一个陌生行业的业务流程、驻场沟通（约 25% 时间出差）
- **和你的关系**：你们"队友接单、你做技术支持"的模式就是 **FDE 的民间版**——这条路的正规军出口就是它。你的短板（沟通）在 FDE 里绕不开，但可以靠"队友商务+你技术驻场"的分工缓解

### 🚀 独立开发者/内容创作者
- 一人公司：vibe coding 做产品 + 热点流量运营，见 [[VibeCoding变现案例]] 和 [[个人开发者收钱指南]]
- 风险提示：幸存者偏差严重，**适合当副业验证，不适合当第一份饭**

## 你的定位建议（22 岁、0 基础、有团队：队友接单、你做技术支持）

你的角色 = **团队的技术担当**。方向收敛为：主线 🛠️ 应用开发，侧线 📊 数据与评测，了解 📋 产品（只为更好交付），🔬 训练作为远期溢价技能。

### 接单市场上最常见的 AI 单子（按出现频率）

| 单子类型 | 对应本库笔记 |
| --- | --- |
| 1. RAG 知识库 / 智能客服（企业资料问答，最多） | [[RAG检索增强生成]] |
| 2. 工作流自动化 Agent（报表、爬虫、内容生成） | [[Agent开发总览]]、[[低代码与Workflow平台]] |
| 3. 小程序 / 网站 + AI 功能 | [[全栈学习路线]]、[[微信小程序开发入门]] |
| 4. 数据清洗 / 标注服务 | 标注实习的经验直接变现 |
| 5. LoRA 微调私有化部署（溢价最高） | [[微调Fine-tuning]]、[[大模型训练方向]] |

### 技术支持的成长节奏

```text
现在-3 个月 → Python + 全栈地基（[[每日学习清单]] 主线不变）
3-6 个月   → 做出 2 个可复用交付模板：RAG 知识库模板 + Agent 工作流模板
              （接单拼的就是复用：同一套骨架，换客户的数据就是新单）
6 个月+    → 跑通第一单全流程：需求 → 报价 → 交付 → 验收
远期       → 补 LoRA 微调能力，接溢价单
正规军出口 → 字节/智谱/蚂蚁等公司的 🛰️ FDE 岗位（见上方 FDE 一节）
```

> [!tip] 沟通不强没关系
> 技术支持的沟通不是"侃"，是**把客户的口语需求翻译成技术方案**——这件事 AI 能帮大忙：把客户的微信/语音记录丢给 AI，让它输出需求清单、功能拆分和报价结构。短板外包给 AI，长板（技术）才是团队要你的原因。

> [!important] 核心心法
> **先入场，再选座。** 纠结"哪个方向最好"不如先拿到任何一张 AI 行业的门票——行业内的信息密度和行业外是两个世界，进去之后转岗比你想象的容易。
