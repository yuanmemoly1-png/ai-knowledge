# Obsidian 使用指南

这份知识库是基于 Obsidian 构建的。Obsidian 的核心思想是：**知识不是孤立的文件，而是一张相互连接的网**。花十分钟掌握下面的功能，你浏览和沉淀知识的效率会完全不同。软件可在 [官网](https://obsidian.md) 免费下载。

## 核心功能

### 双链与反向链接

双链（`[[笔记名]]`）是 Obsidian 的灵魂。本知识库里你会看到大量 `[[Token与分词]]` 这样的链接：

- 点击链接直接跳转到对应笔记；按住 `Ctrl` 点击可在新面板打开。
- 悬停在链接上可以直接预览内容，不用跳转。
- **反向链接（Backlinks）**：打开一篇笔记，右侧面板的「反向链接」会列出**所有引用了它的笔记**。比如打开 [[Token与分词]]，你能看到哪些笔记讨论过它——这就是知识网络的入口。
- 输入 `[[` 时会自动补全已有笔记名，写笔记时随手建链。

### 关系图谱 Graph View

- 快捷键 `Ctrl + G` 打开全局关系图谱：每个点是一篇笔记，每条线是一个双链。
- 你能直观看到哪个模块笔记最密集、哪些概念是「枢纽节点」（被链接最多的往往是核心概念，值得优先学）。
- 也可以用「局部关系图」只看当前笔记的邻居，适合探索某个主题的上下文。

### 全局搜索

- 快捷键 `Ctrl + Shift + F` 打开全局搜索，搜任何关键词都能定位到具体笔记的具体行。
- 忘了某个概念在哪篇笔记里？直接搜，比逐个翻文件夹快得多。
- 支持 `tag:#标签` 语法按标签过滤（见下文）。

### 标签体系

本知识库统一使用 YAML frontmatter 里的 `tags`，例如：

```yaml
---
tags: [名词解释, Agent开发]
created: 2026-08-02
---
```

主要标签及其含义：

| 标签 | 覆盖内容 |
| --- | --- |
| `名词解释` | 基础概念类笔记（01 模块为主） |
| `Agent开发` | Agent 架构、框架、实战（02 模块） |
| `AI辅助开发` | Cursor、Claude Code 等工具实战（03 模块） |
| `Python` | Python 语言学习（04 模块） |
| `课程资源` | 精选课程与名校公开课（05、06 模块） |
| `工具资源` | 工具、社区、资讯（本模块） |

在全局搜索里输入 `tag:#名词解释`，就能一次性列出所有概念笔记。

### Daily Notes

- 核心插件里开启「日记」后，快捷键可以快速创建当天的日记笔记（默认按日期命名）。
- 推荐用法：**把 Daily Note 当作学习日志的入口**——今天学了什么、卡在哪、明天计划，顺手用 `[[]]` 链接到正在学的笔记。一个月后回看，学习轨迹一目了然。

## 推荐社区插件

社区插件需在「设置 → 第三方插件」中关闭安全模式后，从社区市场搜索安装。以下三个是公认的高价值插件：

| 插件 | 用途 |
| --- | --- |
| Dataview | 把笔记当作数据库查询，例如自动生成「所有带 `课程资源` 标签的笔记清单」，适合做动态索引页 |
| Templater | 强大的模板插件，新建笔记时自动填充 frontmatter 和固定结构，保持格式统一 |
| Excalidraw | 手绘风格的画图插件，适合画 Agent 架构图、流程图，图可以直接嵌进笔记 |

> [!tip] 新手建议
> 先别急着装插件。核心功能（双链、图谱、搜索）已经足够支撑学习；等你真的觉得「这个需求原生功能满足不了」时，再装对应插件。

> [!example] 推荐的学习闭环
> 1. 从 [[主页]] 或某个模块 MOC 进入，确定当前学习主题。
> 2. 顺着笔记里的双链延伸阅读，用反向链接发现关联内容。
> 3. 用 Daily Note 记录当天收获，并链接到所学笔记。
> 4. 定期打开 Graph View 俯瞰自己的知识网络，找出还没连接的「孤岛」。
