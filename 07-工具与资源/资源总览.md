# 资源总览（MOC）

工欲善其事，必先利其器。本模块是 AI 开发学习之旅的「装备库」：涵盖开发过程中常用的工具、活跃的社区与资讯渠道，以及如何用好这份 Obsidian 知识库本身。

> [!tip] 使用建议
> 不要试图一次装齐所有工具。建议「用到什么装什么」：开始学 Python 时装好 VS Code 和 Git，开始调 API 时再注册模型平台账号，工具随学习进度逐步解锁。

## 推荐学习顺序

1. **先读 [[Obsidian使用指南]]** —— 花十分钟了解双链和 Graph View，之后浏览整个知识库的效率会完全不同。
2. **再看 [[常用工具清单]]** —— 对照自己当前的学习阶段，勾选需要安装的工具（最小起步组合：VS Code + Git + 一个模型 API 账号）。
3. **收藏 [[社区与资讯]]** —— 挑 2-3 个渠道固定关注，养成每周刷一次的习惯，避免信息过载。
