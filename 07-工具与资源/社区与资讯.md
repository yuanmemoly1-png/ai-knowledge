# 社区与资讯

AI 领域变化以「周」为单位，固定关注几个高质量渠道，比到处刷碎片化信息有效得多。下面按「平台型社区 → 论文与前沿 → 中文资讯」分类。

> [!tip] 信息摄入建议
> 建议固定组合：Hugging Face（找模型和数据）+ 一个中文资讯源（机器之心或量子位）+ 每周逛一次 GitHub Trending。渠道超过 5 个就容易变成信息焦虑。

## 平台型社区

### Hugging Face

- 链接：[huggingface.co](https://huggingface.co)
- 定位：AI 领域的「GitHub」，最大的开源模型与数据集托管平台。
- 你能用它做什么：
  - **找模型**：Models 区托管了数百万个开源模型（LLM、图像、语音），每个模型页面都有使用说明和在线试玩。
  - **找数据集**：Datasets 区是训练与评测数据的最大集散地。
  - **在线体验**：Spaces 区是别人部署好的 AI Demo，点开网页就能玩。
  - **免费课程**：官方的 LLM Course、Deep RL Course 质量很高，见 [[AI-Agent课程]]。

### Datawhale

- 链接：[github.com/datawhalechina](https://github.com/datawhalechina)
- 定位：国内最大的开源学习社区，专注 AI 与数据科学。
- 亮点：把「大模型原理、Prompt 工程、Agent 开发」做成了系统的中文开源教程，全部免费，特别适合中文初学者入门。很多教程配套组队学习活动。

### LINUX DO 社区

- 链接：[linux.do](https://linux.do)
- 定位：活跃的中文技术论坛，AI 话题讨论氛围浓。
- 亮点：能快速获取 API 平台优惠活动、新工具测评、踩坑经验等「接地气」的信息，适合日常闲逛。

## 论文与前沿

### arXiv

- 链接：[arxiv.org](https://arxiv.org)
- 定位：全球最大的论文预印本平台，AI 新成果几乎第一时间发在这里（`cs.AI`、`cs.CL`、`cs.LG` 分区最相关）。
- 使用建议：论文原文对新手偏硬核，不必逐篇精读。可以先在中文资讯渠道看到某篇论文的解读，感兴趣再回 arXiv 找原文。配合「arXiv + AI 总结工具」食用效果更佳。

### Ahead of AI 博客

- 链接：[magazine.sebastianraschka.com](https://magazine.sebastianraschka.com)
- 定位：Sebastian Raschka 教授的个人技术博客。
- 亮点：每月盘点 AI 领域最重要的研究进展，筛选眼光毒辣、解读深入浅出。他的系统课程资源见 [[Raschka教授资源全集]]。

## 中文资讯与开源热榜

### GitHub Trending

- 定位：GitHub 官方的「今日热门仓库」榜单。
- 用途：看最近什么开源项目火了——新框架、新 Agent、新工具往往先在 Trending 上冒头。按周（Weekly）维度看噪音更少。在 GitHub 网站顶部导航即可进入 Trending 页面。

### 机器之心

- 定位：国内老牌 AI 垂直媒体。
- 用途：论文解读、行业动态、技术综述，偏技术深度，适合有一定基础后阅读。可在其官网或微信公众号关注。

### 量子位

- 定位：AI 科技媒体，风格更轻快。
- 用途：快速了解「今天 AI 圈发生了什么」——新品发布、融资、产品测评。适合通勤时刷，获取资讯快讯。可在其官网或微信公众号关注。
