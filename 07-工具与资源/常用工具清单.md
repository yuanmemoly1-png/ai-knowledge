# 常用工具清单

AI 开发需要的工具按用途分为五大类。每个工具给出一句用途说明和获取方式，按需取用即可。

> [!warning] 安装原则
> 工具不在多而在精。零基础起步只需要：一个代码编辑器（VS Code）+ Git + 一个模型 API 平台账号。其余工具等你真正遇到对应场景再装。

## 一、AI 编程工具

这类工具把 LLM 嵌入开发流程，可以对话式写代码、改 Bug、解释项目。

| 工具 | 一句话用途 | 获取方式 |
| --- | --- | --- |
| Cursor | 内置 AI 的代码编辑器，适合对话式编程和 Vibe Coding | 官网下载桌面客户端 |
| Claude Code | 在终端里运行的 AI 编程 Agent，能读写文件、执行命令 | 命令行安装（需 Node.js 环境） |

> [!note]
> 两者的详细对比与实战用法见 [[AI编程工具对比]]、[[Cursor实战指南]] 和 [[ClaudeCode与终端Agent]]。

## 二、模型 API 平台

调用大模型的入口。注册账号后获取 API Key，就能在代码里调用模型。

| 平台 | 一句话用途 | 获取方式 |
| --- | --- | --- |
| OpenAI | GPT 系列模型，生态最成熟，文档与教程最丰富 | 官网注册，获取 API Key |
| DeepSeek | 国产高性价比模型，推理能力强，价格低 | 官网开放平台注册 |
| 通义千问 | 阿里云出品，中文能力好，企业级服务稳定 | 阿里云百炼平台开通 |
| 智谱 GLM | 清华系国产模型，提供免费额度适合练手 | 智谱开放平台注册 |

> [!tip] 本地跑模型：Ollama
> 不想花钱调 API？用 [Ollama](https://ollama.com) 可以在自己电脑上跑开源模型（如 Qwen、Llama 系列），一行命令启动，数据完全不出本机：
> ```bash
> ollama run qwen3
> ```
> 缺点是吃显存/内存，小模型效果弱于云端大模型。

调用 API 的基本代码模式（以 OpenAI 兼容接口为例，国内平台大多兼容）：

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="平台提供的接口地址",  # 各平台文档里都有
)

response = client.chat.completions.create(
    model="模型名",
    messages=[{"role": "user", "content": "用一句话解释什么是 Token"}],
)
print(response.choices[0].message.content)
```

## 四、代码工具

| 工具 | 一句话用途 | 获取方式 |
| --- | --- | --- |
| Git | 版本控制工具，管理代码历史、回滚改错的代码 | 官网下载安装包，装完命令行输入 `git --version` 验证 |
| GitHub | 代码托管与开源社区，找项目、抄作业、存代码都在这里 | 官网注册账号 |
| VS Code | 最流行的免费代码编辑器，插件生态极全 | [官网下载](https://code.visualstudio.com) |

> [!example] 装完 Git 后必做的两件事
> ```bash
> git config --global user.name "你的名字"
> git config --global user.email "你的邮箱"
> ```
> 这决定了你每次提交代码时的署名。
