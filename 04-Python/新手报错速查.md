# 新手报错速查（我的错题本）

> [!note] 用法
> 报错不吓人，它是 Python 在跟你说话。这本错题本按"报错类型 → 翻译 → 真实案例 → 修法"整理，**每修一个新报错就往里添一条**——攒得越多，排错越快。

## 报错三步读法（万能流程）

```text
① 直接看最后一行（错误类型 + 原因）
② 看它指出的行号和那行代码
③ 对照下表对号入座
```

## 已解锁的报错（亲历）

### 1. IndentationError: unexpected indent —— 行首多空格

```python
>>>  my_name="huyucheng"     # ← print/赋值前面多了个空格
IndentationError: unexpected indent
```

- **原因**：行首空格在 Python 里是语法（表示从属关系），顶层代码前面不能有空格
- **修法**：删掉行首空格。复制粘贴代码后第一件事就是检查行首
- **口诀**：**行首不空格，除非在块中**（if/for/def 里才空 4 格）

### 2. SyntaxError: unterminated f-string literal —— 引号没关门

```python
>>> print(f"我有{3}个苹果)   # ← 少了关闭的 "
SyntaxError: unterminated f-string literal
```

- **原因**：`"` 开了门没关，Python 等到行尾都没等到
- **修法**：数一遍引号配对，开了几个 `"` 就关几个
- **口诀**：**先关引号，再关括号**

### 3. AttributeError: 'str' object has no attribute 'sprit' —— 方法名拼错

```python
>>> a.sprit(",")   # ← split 拼成了 sprit
AttributeError: 'str' object has no attribute 'sprit'
```

- **原因**：工具箱里没有叫这个名字的工具，方法名必须一个字母不差
- **修法**：对照正确拼写（split / join / replace / len）

### 4. NameError: name '程程' is not defined —— 文字忘加引号

```python
>>> name=程程      # ← 文字没穿引号外套，被当成变量名了
NameError: name '程程' is not defined
```

- **原因**：不带引号的词 = 变量名；Python 找不到叫"程程"的盒子
- **修法**：文字要加引号 `name = "程程"`
- **口诀**：**字要穿衣（引号），盒子（变量名）不穿**

### 5. TypeError: 'list' object is not callable —— 变量名抢了内置功能

```python
>>> print = ["苹果", "香蕉"]   # 某一行把 print 当变量名用了
>>> print(fruits)
TypeError: 'list' object is not callable
```

- **原因**：`print` 被你的列表"盖住"了，列表不能当功能调用
- **修法**：`del print`（删掉变量，打印功能恢复），或重启解释器
- **口诀**：**内置功能的名字别占用**（print / list / str / len / dict / type / sum），起名用 `my_list` 这类带前缀的

### 6. RecursionError: maximum recursion depth exceeded —— 函数自己喊自己

```python
def is_pass(score):
    if is_pass(score) >= 60:   # ← 函数里又喊了自己，无限循环
RecursionError: maximum recursion depth exceeded
```

- **原因**：函数内部误调用自己（本想用参数 `score`，却写成 `is_pass(score)`），Python 喊到约 1000 次强制掐断
- **修法**：**参数就是送到手边的料，直接用**——`if score >= 60:`
- **口诀**：**括号里起名，括号里收料，里面直接用名**

### 7. ValueError: empty separator —— split 的空剪刀

```python
x = phrase.split("")     # ← 引号里什么都没有
ValueError: empty separator
```

- **原因**：split 必须告诉它"按什么切"，空字符串不能当切点
- **修法**：按空格切 `split(" ")`；或不写参数 `split()`（自动按空白切）
- **口诀**：**剪刀不能是空的**

## 隐形坑：中文标点双胞胎

```python
a = "苹果，香蕉，橘子"   # 中文逗号 ，
a.split(",")            # 英文剪刀 , → 剪不开！原样返回
```

新版 Python 会直接报"身份证号"：`SyntaxError: invalid character '：' (U+FF1A)`——看到 `U+FFXX` 就知道是全角标点混进来了：

| 编码 | 凶手 |
| --- | --- |
| `U+FF1A` | 中文冒号 `：` |
| `U+FF0C` | 中文逗号 `，` |
| `U+FF08 / U+FF09` | 中文括号 `（）` |
| `U+201C / U+201D` | 中文引号 `""` |
| `U+FF1B` | 中文分号 `；` |

| 你以为打的 | 实际打的 | 后果 |
| --- | --- | --- |
| `,` | `，` | split 剪不开、语法错误 |
| `"` | `"` `"` | 字符串报错 |
| `(` `)` | `（` `）` | 函数调用报错 |
| `;` | `；` | 语法错误 |

**口诀：写代码，切英文输入法**（中文输入法下按 Shift 可临时切英文标点）

### 8. KeyError —— 字典没有"0 号格"

```python
ledger = {"奶茶": 30}
ledger[0]        # KeyError: 0
```

- **原因**：字典按**名字**取，没有号码格；`0` 不是任何一格的键
- **修法**：用键名取（`ledger["奶茶"]`）；循环里 `for i in ledger:` 后用 `ledger[i]`
- **口诀**：**列表认号码，字典认名字**——拿号码去字典取东西，必报 KeyError

### 9. AttributeError 变种 —— 方法用错容器

```python
ledger.append("电影票")    # AttributeError: 'dict' object has no attribute 'append'
```

- **原因**：`append` 是**列表**的方法，字典没有；把列表的动作用在字典上
- **修法**：记住容器分工——**列表加格用 `append()`，字典加格用赋值 `d["新名"] = 值`**
- **扩展**：同类错误还有对字符串用 append、对字典用 split……看到 AttributeError 先想"这个方法是不是这个容器的"

### 10. 套路坑：累加器写成"一次加完"

```python
for i in ledger:
    total = ledger[0] + ledger[1] + ledger[2]   # ❌ 全写死在循环里
```

- **问题**：累加器是"每圈加一格"，不是"把全部一次写完"（而且数据变了就崩）
- **正确**：`total = 0` 先归零，循环里 `total = total + ledger[i]`
- **口诀**：**先归零，每圈加一格**

## 预告：以后大概率会遇到的

| 报错 | 一句话含义 | 常见场景 |
| --- | --- | --- |
| `IndexError` | 抽屉编号超出范围 | 列表只有 3 格却取第 5 格 |
| `FileNotFoundError` | 文件路径写错 | open() 找不到文件 |

> [!tip] 心态
> 每种报错修过一次，以后就是秒修。**报错次数 ≈ 经验值**。
