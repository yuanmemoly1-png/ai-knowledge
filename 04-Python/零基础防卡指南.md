# 零基础防卡指南（纯小白版）

> [!note] 先说结论
> 你卡壳不是你的问题，是**教程排布的问题**。廖雪峰、官方教程这类文字教程是按"知识体系"排的，不是按"小白的认知顺序"排的——它们默认你已经知道什么是终端、什么是文件路径、什么是"运行"。纯小白需要的是**更慢、更细、有人带**的入口，加上一个随问随答的 AI 私教。这篇给你一套不卡壳的学法。

## 一、诊断：你为什么总被卡住

| 卡壳场景 | 真正原因 |
| --- | --- |
| 第一章"配置环境"就卡住 | 教程一句"添加到 PATH"带过，没人告诉你 PATH 是啥、在哪勾选 → 看 [[环境搭建与包管理]] |
| 概念能看懂，合上书就写不出 | 只看不练，眼睛会了手不会 |
| 教程突然跳到一个没讲过的用法 | 文字教程默认你会"自己补中间步骤" |
| 报错一屏红字直接劝退 | 没人教你"报错只看最后一行"这个基本功 |

## 二、资源重新分级：别一上来就用"字典"当教材

### 保姆级（当主线，手把手带）

> [!tip] 先想清楚你适合哪种学法（2026-08 更新）
> 有人的大脑适合"听人讲"，有人适合"自己读+动手推"。**如果你发现纯文字+亲手敲代码更快（本库主人就是这样），直接把 [[小白课堂总览]] 的 24 节慢速课当主线**，每课代码都带真实输出，视频课只作某个点卡住时的补充。两种学法没有高下，能坚持的才是好的。

1. **北理工嵩天《Python语言程序设计》**（中国大学 MOOC，免费）
   - 国内最经典的大学 Python 入门课，老师是真正在课堂上教零基础的，节奏慢、概念掰得很碎、每周有编程作业
   - 获取：中国大学 MOOC（慕课）搜"Python语言程序设计 嵩天"
2. **小甲鱼《零基础入门学习Python》**（B站）
   - 语气轻松、演示完整敲代码过程，适合完全没碰过编程的人建立兴趣（已在 [[Python课程]] 收录）
3. **夜曲编程**（百词斩旗下，手机/网页）
   - 卡片式学习，把概念做成图卡和比喻，坐地铁都能刷；适合作为"第一课"建立最基础的直觉

### 进阶级（当字典查，不要当主线）

- **廖雪峰教程**、**Python 官方中文教程**：质量极高但密度大，**适合"学到哪卡到哪"时当工具书查**，不适合纯小白从头硬啃
- **CS50P**：哈佛课很好但全英文+作业强度高，等你写出过 50 行脚本再上

> [!warning] 关键认知
> 之前给你整理的课一门都不差，只是**顺序错了**：文字教程是"字典"，视频课才是"老师"。先用视频课建立手感，再回头查文字教程，卡壳率直接减半。

## 三、你最大的外挂：AI 私教工作流

你就有现成的 AI（比如正在跟你说话的这个），它**永不耐烦、随问随答**——这是十年前学编程的人没有的条件。三个模板直接复制用：

> [!example] 模板 1：逐行解释
> 「我是纯小白，刚学 Python 第 X 天。请逐行解释下面这段代码，每行用一个生活里的比喻，不要用没解释过的术语：（贴代码）」

> [!example] 模板 2：报错求救
> 「我运行这段代码报错了。代码：…… 报错信息：…… 请用最简单的话告诉我：错在哪一行、为什么错、怎么改。」

> [!example] 模板 3：出题陪练
> 「我刚学完 Python 的列表和 for 循环。请给我出 3 道由易到难的练习题，先别给答案。我做完发给你，做错了只给提示，不要直接公布答案。」

## 四、卡壳自救 SOP（贴在桌边）

```text
① 报错先只看最后一行（真正的错误原因就在那里）
② 看不懂 → 整段复制给 AI，用模板 2 求救
③ 改完重新跑通 → 把这段代码亲手重敲一遍（不许复制粘贴）
④ 用费曼技巧：把"这段代码是干嘛的"讲给 AI 听，让它挑你讲错的地方
⑤ 同类练习再做一道 → 卡住超过 20 分钟就求助，不死磕
```

## 五、防卡学习法（比选什么课更重要）

1. **所有代码亲手敲**：复制粘贴=没学。敲错出 bug 恰恰是长本事的过程
2. **每学一节，做一个"5 行小玩意"**：学了 print 就打印自己的名片，学了列表就做个购物清单——小到什么程度都行，关键是"这是我写的"
3. **每天 30-60 分钟 > 周末突击 5 小时**：编程靠肌肉记忆，频率比时长重要
4. **允许自己慢**：[[Python学习路线]] 里"阶段一 1-2 周"是参考值，你花 3-4 周完全正常，**慢不是落后，弃学才是**
