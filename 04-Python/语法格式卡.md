# 语法格式卡（写代码时摊在手边）

> [!note] 用法
> 不用背。写代码时这张卡开着，**"我想干什么 → 抄格式 → 换内容"**。格式错报错时去 [[新手报错速查]]。

## 装东西

```python
name = "小明"              # 变量：装一个东西
nums = [90, 45, 78]        # 列表：装一堆，按号码取
scores = {"小明": 90}      # 字典：装一堆，按名字取
```

## 取东西（永远是 `[]`）

```python
nums[0]              # 列表按号码取（从 0 数）→ 90
nums[-1]             # 最后一个 → 78
scores["小明"]        # 字典按名字取（名字穿引号）→ 90
scores[name]         # name 是变量（盒子），不穿引号
```

## 挨个来（for）

```python
for x in nums:           # 列表：每圈 x 是"东西本身"
    print(x)

for name in scores:      # 字典：每圈 name 是"名字"
    print(scores[name])  # 要内容就用名字去取

for i in range(5):       # 没东西可挨：造号码 0~4，转 5 圈
    print(i)
```

## 选路（if / elif / else）

```python
if s >= 90:
    print("优秀")
elif s >= 60:
    print("及格")
else:
    print("不及格")
```

> ⚠️ 三件宝：**冒号 `:`、缩进 4 格、比较用 `==`**（`=` 是装东西）

## 重复到停（while）

```python
n = 1
while n <= 3:
    print(n)
    n = n + 1        # 忘了这行 = 死循环（Ctrl+C 救命）
```

## 说人话（f-string）

```python
print(f"{name} 考了 {scores[name]} 分")
# f = 填空开关（每句话各自要带）
# {} = 空位，里面放什么就填什么，还能放算式 {a + 1}
```

## 字符串四件套

```python
len(s)                  # 数：长度
s.split(",")            # 切：按符号切开 → 列表
",".join(parts)         # 粘：列表粘成字符串
s.replace("旧", "新")    # 换
```

## 经典套路（背这两个就够）

```python
# 计数器：先归零，满足条件就 +1
count = 0
for name in scores:
    if scores[name] >= 60:
        count = count + 1
print(f"及格人数：{count}")
```

```python
# 记账：字典当账本，见过的就 +1
count = {}
for w in words:
    if w in count:
        count[w] = count[w] + 1
    else:
        count[w] = 1
```

## 人肉动作 → Python 零件（解题翻译表）

> 新题五步法第 ④ 步专用：先在纸上把人肉过程写出来，再逐行对照翻译成代码。

| 人肉时你在做什么 | Python 零件 |
| --- | --- |
| 一个个看过去 | `for x in 容器:` |
| 重复固定次数 | `for i in range(N):` |
| 一直重复到某个条件为止 | `while 条件:`（别忘了改条件） |
| 看第 N 个 / 按名字找 | `列表[N]` / `字典["名字"]` |
| 判断"是不是……" | `if 条件:` |
| 二选一 / 多选一 | `if … else:` / `if … elif … else:` |
| 数"有几个" | `count = 0` + `count = count + 1` |
| 求总和 | `total = 0` + `total = total + x` |
| 找最大（或最小） | 先假设第一个是最大，挨个比，更大就换人 |
| 收集符合条件的 | 空列表 + `列表.append(x)` |
| 记"见过几次" | 空字典 + `if w in count: +1 else: =1` |
| 把文字切开再处理 | `s.split("符号")` |
| 报结果 | `print(f"...{变量}...")` |

## 写程序的通用框架（三步）

```text
① 数据就位：装进合适的容器（单个用变量 / 按号码用列表 / 按名字用字典）
② 流程架子：for 挨个来 + if 看情况
③ 输出结果：f-string 说人话
```

## 格式错误急救

| 症状 | 多半是 |
| --- | --- |
| `IndentationError` | 行首多空格，或 if/for 后没缩进 |
| `SyntaxError: unterminated` | 引号没关门 |
| `NameError` | 文字忘加引号 / 变量名拼错 |
| `AttributeError` | 方法名拼错（sprit → split） |
| 剪不开/没反应 | 中文标点混进来了（，。；（）） |

更多见 [[新手报错速查]]。
