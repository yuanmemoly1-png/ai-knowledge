# Python 学习路线

> [!note] 模块简介
> 本模块面向「想进入 AI 开发」的自学者，覆盖从零搭建环境到能写 AI 应用所需的核心 Python 能力。目标不是成为 Python 全栈专家，而是用最短路径掌握 AI 开发中最常用的那 20% 语法与工具，能看懂、能改、能写 [[Agent开发总览]] 里的代码。


## 分阶段路线图

### 阶段一：语法基础（1-2 周，纯小白放宽到 3-4 周）

> [!warning] 纯小白注意
> 如果你完全没碰过编程、看文字教程总被卡住，**先读 [[零基础防卡指南]]**：换用视频课当主线 + AI 私教模板 + 卡壳自救 SOP，比硬啃文字教程顺畅得多。

**目标**：能独立写出 50 行以内的小脚本，处理字符串、列表、文件。

- 学习内容：[[环境搭建与包管理]] + [[基础语法速查]]
- 自测标准：
  - 能写一个脚本，读取一个 `.txt` 文件，统计每个单词出现次数并输出前 10 名
  - 能说出 `list` 和 `dict` 的区别，会用推导式
- 课外补充：[[Python课程]] 中选一门入门课跟着练，不要只看不动手

> [!tip] 学习建议
> 语法阶段最大的坑是「看懂了但不会写」。每个示例都亲手敲一遍，改几个参数再跑一遍，比看三遍视频有效。

### 阶段二：进阶语法（1 周）

**目标**：看懂开源 AI 项目里的常见写法（装饰器、`*args/**kwargs`、生成器、异常处理）。

- 学习内容：[[常用数据结构与函数]]
- 自测标准：
  - 能解释 `*args` 和 `**kwargs` 的作用，并能写一个使用它们的函数
  - 能看懂 `sorted(data, key=lambda x: x["score"], reverse=True)` 这类代码
- 这一阶段不需要死磕：多线程底层、元类、描述符等在 AI 应用开发中很少直接用，遇到再查

### 阶段三：AI 方向专项（2-3 周）

**目标**：能调用大模型 API、管理密钥、做结构化输出、并发请求、起一个 API 服务。

- 学习内容：[[面向AI开发的Python]]
- 自测标准：
  - 能用 openai SDK 完成一次带结构化输出的调用，API Key 从 `.env` 读取
  - 能用 asyncio 并发调 10 次 API 并统计耗时
  - 能用 FastAPI 起一个 `/chat` 接口，接收问题返回模型回答
- 完成后即可进入：[[Agent开发总览]] → [[LangChain入门]] → [[工具调用实战]]

## 常见问题

| 问题 | 建议 |
| --- | --- |
| 要不要先学爬虫/数据分析？ | 不必。AI 开发主线用不到完整的爬虫和 pandas 体系，用到再补 |
| 需要学多深？ | 能读懂 GitHub 上 LangChain 示例代码的程度即可开始 Agent 学习 |
| Python 2 还要学吗？ | 不要。2020 年起官方已停止维护，全部用 Python 3.10+ |
