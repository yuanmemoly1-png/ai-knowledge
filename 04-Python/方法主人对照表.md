# 方法主人对照表（用之前先问：主人是谁）

> [!note] 用法
> `AttributeError` 九成的根源：把方法用在了错的主人身上。写代码前的反射动作：**先看手上的东西是什么类型，再决定能用哪些方法。** 本表按"主人"分组，碰到不熟的方法先查这里。

## 🧵 字符串 str 的方法（一串文字）

| 方法 | 干什么 | 例子 |
| --- | --- | --- |
| `split("符号")` | 切 → 列表 | `"a,b".split(",")` |
| `join(列表)` | 粘 → 字符串（主人是"胶水"） | `",".join(parts)` |
| `replace("旧","新")` | 换 | `s.replace("a","b")` |
| `strip()` | 去首尾空白 | `" hi ".strip()` |
| `lower() / upper()` | 小写 / 大写 | `s.lower()` |
| `startswith() / endswith()` | 判断开头/结尾 | `s.startswith("http")` |
| `s[i]` / `s[a:b]` | 取一个字符 / 切片 | `"hello"[0]` → `'h'` |

## 🗃️ 列表 list 的方法（一排号码格）

| 方法 | 干什么 | 例子 |
| --- | --- | --- |
| `append(x)` | 末尾加一格 | `fruits.append("桃")` |
| `remove(x)` | 按内容删 | `fruits.remove("桃")` |
| `insert(i, x)` | 插到 i 号位 | `fruits.insert(0, "桃")` |
| `pop()` | 拿走最后一格 | `fruits.pop()` |
| `sort()` | 就地排序 | `nums.sort()` |
| `lst[i]` / `lst[a:b]` | 按号码取 / 切片 | `fruits[-1]` |

## 📇 字典 dict 的方法（一排名字格）

| 方法 | 干什么 | 例子 |
| --- | --- | --- |
| `d[key]` | 按名字取 | `scores["语文"]` |
| `d[key] = v` | 加格或改格（一体） | `scores["英语"] = 88` |
| `del d[key]` | 删一格 | `del scores["语文"]` |
| `key in d` | 有没有这格 | `"语文" in scores` |
| `d.items()` | 名字内容一起遍历 | `for k, v in d.items():` |
| `d.get(key, 默认)` | 安全取 | `d.get("物理", 0)` |

## 🔢 数字 int/float 的操作

| 操作 | 干什么 | 例子 |
| --- | --- | --- |
| `+ - * /` | 四则（`/` 得小数） | `7 / 2` → `3.5` |
| `//` `%` `**` | 整除 / 余数 / 乘方 | `7 % 2` → `1` |
| `int() / float()` | 文字转数字 | `int("42")` |

## 🌍 通用功能（不挑主人，谁都能用）

| 功能 | 干什么 | 例子 |
| --- | --- | --- |
| `len()` | 数数量（串/列表/字典都行） | `len(fruits)` |
| `type()` | 看类型 | `type(x)` |
| `str()` | 转成文字 | `str(42)` |
| `in` | 在不在里面 | `"a" in "abc"`、`1 in [1,2]`、`"k" in d` |
| `print()` | 打印 | 都会 |
| `for x in ...` | 挨个来 | 串/列表/字典/range 都行 |
| `sorted()` | 排序（返回新列表，不改原身） | `sorted(nums)` |

## ⚠️ 高频撞车对照（错题本实证）

| 你想干的 | 错用 | 正确 |
| --- | --- | --- |
| 字典加一格 | `d.append(...)` ❌ | `d["新名"] = 值` |
| 切列表 | `lines.split(",")` ❌ | 先 `for line in lines:` 领出来，再 `line.split(",")` |
| 字典取物 | `d[0]` ❌ | `d["名字"]`（字典没有号码格） |
| 列表排序不改原身 | `sorted()` 返回新列表；`lst.sort()` 就地改 | 按需求选 |

> [!important] 核心反射
> **写方法前问自己：我手上这是什么类型？** 字符串用串的方法、列表用列的方法、字典用典的方法。报错 `AttributeError` 就是答案：你找错主人了。
