# 环境搭建与包管理

> [!note] 本笔记解决什么
> 在 Windows 上装好 Python，学会用 venv 隔离项目环境、用 pip/uv 装包、配好 VS Code，10 分钟进入可写代码的状态。

## 1. 安装 Python（Windows）

1. 打开官网 [https://www.python.org/downloads/](https://www.python.org/downloads/) 下载最新稳定版（建议 3.11 或 3.12）。
2. 运行安装程序，**第一屏务必勾选 `Add python.exe to PATH`**，再点 Install Now。

> [!warning] 不勾选 Add to PATH 的后果
> 命令行里输入 `python` 会提示找不到命令，只能手动配环境变量或重装。这是新手最常见的第一个坑。

3. 验证安装：打开 PowerShell 或 CMD，输入：

```bash
python --version
# 输出类似：Python 3.12.4
```

> [!tip] Windows 商店占位符问题
> 如果输入 `python` 弹出了微软商店，在「设置 → 应用 → 应用执行别名」里关掉「应用安装程序」的两个 python 别名即可。

## 2. venv 虚拟环境

每个项目独立一套依赖，避免 A 项目要 `openai==1.x`、B 项目要 `openai==0.x` 打架。

```bash
# 在项目目录下创建虚拟环境（目录名 .venv 是社区惯例）
python -m venv .venv

# Windows PowerShell 激活
.venv\Scripts\Activate.ps1

# Windows CMD 激活
.venv\Scripts\activate.bat

# 激活后命令行前面会出现 (.venv) 前缀
# 退出虚拟环境
deactivate
```

> [!warning] PowerShell 禁止运行脚本？
> 激活时报「禁止运行脚本」错误，以管理员身份打开 PowerShell 执行一次：
> `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`

## 3. pip 常用命令

```bash
# 安装包
pip install openai

# 安装指定版本
pip install openai==1.40.0

# 升级包
pip install --upgrade openai

# 卸载
pip uninstall openai

# 查看当前环境装了哪些包
pip list

# 导出依赖清单（团队协作/部署时用）
pip freeze > requirements.txt

# 按清单安装
pip install -r requirements.txt
```

## 4. uv：更快的新工具

[uv](https://docs.astral.sh/uv/) 是 Astral 公司（Ruff 的作者）用 Rust 写的包管理器，速度比 pip 快 10-100 倍，一个工具替代 pip + venv。

```bash
# Windows PowerShell 安装 uv
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

# 创建虚拟环境
uv venv

# 装包（语法和 pip 几乎一致，激活 .venv 后使用）
uv pip install openai
```

> [!tip] 新手怎么选
> 先用 pip + venv 跑通流程（教程里几乎都是这套），熟练后再迁移到 uv，两者命令几乎一一对应。

## 5. VS Code 配置

1. 安装 [VS Code](https://code.visualstudio.com/)。
2. 扩展商店搜索并安装官方 **Python** 扩展（发布者 Microsoft），Pylance 会一并装好，提供类型提示和自动补全。
3. 打开项目文件夹后，按 `Ctrl+Shift+P` → 输入 `Python: Select Interpreter` → 选择项目里的 `.venv` 解释器。
4. 新建 `hello.py`，输入下面代码，点右上角运行按钮：

```python
import sys
print("Python 版本:", sys.version)
print("解释器路径:", sys.executable)  # 应指向项目下的 .venv
```

> [!example] 验证环境是否配对
> 输出的解释器路径必须包含 `.venv`，说明 VS Code 用的是项目虚拟环境而不是全局 Python。路径不对会导致「pip 装了包但运行时报 ModuleNotFoundError」。

## 常见报错速查

| 报错 | 原因 | 解决 |
| --- | --- | --- |
| `python 不是内部或外部命令` | 没勾选 Add to PATH | 重装并勾选，或手动加环境变量 |
| `ModuleNotFoundError` | 包装到了别的环境 | 确认终端已激活 `.venv` 再 pip install |
| `pip 版本过旧` 警告 | pip 自身旧 | `python -m pip install --upgrade pip` |
