# 常用数据结构与函数

> [!note] 为什么单独讲这章
> AI 项目的代码里，80% 的数据操作是 dict 和 list（API 返回的 JSON 本质就是嵌套 dict/list），80% 的函数技巧是默认参数和 `*args/**kwargs`。掌握这章，读开源项目代码会顺很多。

## 1. 四大数据结构对比

| 类型 | 写法 | 有序 | 可重复 | 可修改 | 典型用途 |
| --- | --- | --- | --- | --- | --- |
| list 列表 | `[1, 2, 3]` | 是 | 是 | 是 | 消息列表、批量结果 |
| dict 字典 | `{"a": 1}` | 是（3.7+） | 键唯一 | 是 | API 响应、配置 |
| set 集合 | `{1, 2, 3}` | 否 | 否 | 是 | 去重、求交集 |
| tuple 元组 | `(1, 2, 3)` | 是 | 是 | 否 | 坐标、多返回值 |

```python
# list 常用操作
msgs = ["hi", "hello"]
msgs.append("hey")        # 尾部追加 → ['hi', 'hello', 'hey']
msgs.insert(0, "first")   # 指定位置插入
msgs.pop()                # 弹出最后一个 → 'hey'
len(msgs)                 # 3
msgs[0], msgs[-1]         # 第一个、最后一个

# dict 常用操作（AI 开发最重要）
resp = {"model": "gpt-4o", "usage": {"tokens": 128}}
resp["model"]                        # 取值
resp.get("stream", False)            # 键不存在返回默认值，不报错
resp.keys(), resp.values()           # 所有键 / 所有值
resp["usage"]["tokens"]              # 嵌套取值 → 128
resp.update({"temperature": 0.7})    # 合并更新

# set 去重
tags = ["ai", "llm", "ai", "agent", "llm"]
unique = list(set(tags))   # 去重（顺序不保证）

# tuple：函数返回多个值时自动打包
def min_max(nums):
    return min(nums), max(nums)

lo, hi = min_max([3, 1, 4])   # 解包 → lo=1, hi=4
```

> [!tip] 取值用 `[]` 还是 `.get()`？
> 处理大模型返回的 JSON 时，字段可能缺失。`resp["choices"]` 缺键会直接抛 `KeyError`；`resp.get("choices", [])` 返回默认值更安全。

## 2. 函数定义进阶

```python
# 默认参数：不传时用默认值
def chat(prompt, model="gpt-4o", temperature=0.7):
    return f"[{model}|T={temperature}] {prompt}"

print(chat("你好"))                        # 用默认模型
print(chat("你好", temperature=0))         # 关键字传参

# *args：接收任意多个位置参数，打包成 tuple
def total(*nums):
    return sum(nums)

print(total(1, 2, 3, 4))   # 10

# **kwargs：接收任意多个关键字参数，打包成 dict
def build_request(**options):
    defaults = {"model": "gpt-4o", "stream": False}
    defaults.update(options)
    return defaults

print(build_request(stream=True, temperature=0.2))
# {'model': 'gpt-4o', 'stream': True, 'temperature': 0.2}

# 解包传参：把 dict 当关键字参数传进去（调 SDK 常见）
params = {"model": "gpt-4o", "temperature": 0}
chat("你好", **params)

# lambda：一次性匿名函数，常配合 sorted/map 用
add = lambda a, b: a + b
print(add(2, 3))   # 5
```

> [!warning] 默认参数的坑
> 不要用可变对象做默认值：`def f(items=[])` 的列表会在多次调用间共享，越调越长。正确写法：`def f(items=None)`，函数体内 `items = items or []`。

## 3. 常用内置函数

```python
words = ["apple", "banana", "kiwi", "cherry"]

# map：对每个元素套用函数，返回迭代器
lengths = list(map(len, words))          # [5, 6, 4, 6]

# filter：按条件过滤
long_words = list(filter(lambda w: len(w) > 4, words))  # ['apple', 'banana', 'cherry']

# zip：并行打包多个序列
models = ["gpt-4o", "kimi-k2"]
prices = [2.5, 0.5]
for m, p in zip(models, prices):
    print(f"{m}: ${p}/百万token")

# enumerate：遍历时同时拿索引
for i, w in enumerate(words, start=1):
    print(f"{i}. {w}")

# sorted：排序，key 指定排序依据
docs = [
    {"title": "RAG 入门", "score": 0.92},
    {"title": "Agent 设计", "score": 0.85},
    {"title": "Prompt 技巧", "score": 0.97},
]
ranked = sorted(docs, key=lambda d: d["score"], reverse=True)
print(ranked[0]["title"])   # Prompt 技巧（RAG 检索结果按相关度排序就是这个写法）

# any / all / sum / max / min
scores = [0.9, 0.7, 0.8]
any(s > 0.85 for s in scores)    # True：存在高分
all(s > 0.5 for s in scores)     # True：全部合格
sum(scores) / len(scores)        # 平均分
```

> [!example] 实战：RAG 检索结果处理
> ```python
> results = [
>     {"content": "向量数据库...", "score": 0.91},
>     {"content": "无关内容", "score": 0.3},
>     {"content": "Embedding 是...", "score": 0.88},
> ]
> # 过滤低分、按分数排序、取前 2 条的 content
> top = [r["content"] for r in
>        sorted((r for r in results if r["score"] > 0.5),
>               key=lambda r: r["score"], reverse=True)[:2]]
> print(top)  # ['向量数据库...', 'Embedding 是...']
> ```

## 4. itertools 简述

标准库里的迭代器工具箱，处理批量数据时很好用，知道这几个就够：

```python
from itertools import chain, islice, groupby, batched

# chain：把多个列表接成一个
list(chain([1, 2], [3, 4]))          # [1, 2, 3, 4]

# islice：迭代器切片（大数据流只取前几个）
list(islice(range(100), 5))          # [0, 1, 2, 3, 4]

# groupby：按 key 分组（需先排序）
data = ["gpt-4o", "gpt-4o-mini", "claude-sonnet"]
for vendor, group in groupby(data, key=lambda m: m.split("-")[0]):
    print(vendor, list(group))

# batched：分批（Python 3.12+），批量调 API 限速场景常用
items = list(range(7))
for batch in batched(items, 3):
    print(batch)   # (0,1,2) (3,4,5) (6,)
```
